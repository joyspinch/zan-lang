# Zan ·《开端》/ THE START
### 10 秒 · 固定机位 · 无缝循环 · 品牌短片脚本 v2

> **v2 修订**：取消全部运镜。镜头锁死，叙事交给画面本身——
> 四份重写被吸进一枚 Z，七个平台再从这枚 Z 放射出去，最后碎片飞回原位。
> 机位不动的好处：构图可以精确到像素，观众不会因为镜头运动而看不懂发生了什么。

---

## 0. 为什么这样拍（痛点 → 画面证据）

| 现实痛点 | 画面证据（不靠字幕也能读出来） | 字幕 |
|---|---|---|
| 跨平台碎片化 | 四块语言窗口各占一角，**同一个 App**（同一份 MY TASKS、同样四行任务），只有边框颜色不同 | 一个想法，四种写法。 |
| 每平台一套语言 / 工具链 | 每块窗口顶部写着语言 + 平台：C#/WINDOWS、KOTLIN/ANDROID、SWIFT/IOS、JAVASCRIPT/WEB；底部是 `4 PLATFORMS · 0 REUSE` | 4 LANGUAGES · 6 TOOLCHAINS · 1 PRODUCT |
| 学习与维护成本 | 四份代码同时在场，一眼看到"同一件事被写了四遍" | 每加一个平台，就多一次重写。 |
| 复用率为零 | 四块窗口的代码块并排：`class App` / `struct App`，逻辑一样，语法不同 | — |
| **Zan 的答案** | 四块窗口的颜色被抽成粒子流汇入中心那枚 Z；Z 点亮，七个平台从同一点放射展开，没有分叉的工具链 | 一门语言。／一次编写，原生抵达。 |

**色彩即论点**：前半段是四种语言各自的颜色（紫 / 靛 / 橙 / 黄），后半段只剩 Z 的深蓝砖 + 薄荷青 + 一点火花金。观众不需要读字就知道哪种状态更贵。

## 1. 全局规格

| 项 | 值 |
|---|---|
| 时长 | **10.000 s**，`t = now % 10`，纯时间函数，无跨帧累积状态 |
| 机位 | **固定**：`(0, 2.90, 14.6)`，注视 `(0, 2.45, 0)`，FOV 42°，无位移、无变焦、无滚转 |
| 画幅 | 16:9 母版，浏览器自适应 |
| 技术 | 单 HTML，Three.js **r160** ESM + importmap，零外部模型/贴图/字体 |
| 后处理 | UnrealBloom → 胶片颗粒 / 暗角 / 极轻色散 → OutputPass |
| 交互 | 空格暂停、`?t=3.2` 定帧（验收用）、`?hud=0` 隐藏角标 |
| 无障碍 | `prefers-reduced-motion` 时停在落版帧 |

**为什么 10 秒够**：全片只有一个动作——"四份变成一份，一份再变成七份"。没有镜头运动需要理解，观众可以把注意力全部放在因果上。

## 2. 构图（固定机位，全部按 16:9 落位）

```
┌──────────────────────────────────────────────┐
│  ZAN / THE START             10.000s · LOOP  │
│                                              │
│   ┌────────────┐      ┌────────────┐         │
│   │ C#  WINDOWS│      │KOTLIN ANDR.│         │
│   │  MY TASKS  │      │  MY TASKS  │         │
│   └────────────┘      └────────────┘         │
│                    ╔════════╗                │
│   ┌────────────┐   ║   Z    ║   ┌──────────┐ │
│   │SWIFT   IOS │   ║  (砖)  ║   │JS    WEB │ │
│   │  MY TASKS  │   ╚════════╝   │ MY TASKS │ │
│   └────────────┘                └──────────┘ │
│  一个想法，                                   │
│  四种写法。                                   │
└──────────────────────────────────────────────┘
```

- **中心**：Zan 的 app 砖（圆角砖 4.2 + 白色 Z + 右上火花），永远面向镜头。
- **四角**：四块 4.7×5.4 的语言窗口，组成 2×2，全部正对镜头（不与中心砖穿插）。
- **左下**：字幕区（压暗层保证可读）。
- **环形**：七个平台节点在 Z 外围半径 3.85 的同心圆上，标签在 4.95。

## 3. 时间轴

| 时间 | 画面 | 字幕 |
|---|---|---|
| 0.0–3.4 | 四块窗口静态在场，轻微呼吸；Z 暗着；尘埃漂浮 | `ZAN / 00 现在的跨平台` → **一个想法，四种写法。** → `4 LANGUAGES · 6 TOOLCHAINS` |
| 2.6–3.9 | 窗口边框开始失饱和，颜色被抽成粒子 | **每加一个平台，就多一次重写。** |
| 3.45–4.75 | 四块窗口螺旋收缩、褪色，粒子流全部汇入 Z | `ZAN / 01 如果` → **只写一次？** |
| 4.45–4.95 | Z 点亮：薄荷青描边 + 右上金火花；一圈脉冲环扩散 | **一门语言。** |
| 5.45–6.4 | 七个平台节点依次从 Z 放射点亮（间隔 0.11s） | — |
| 6.15–7.1 | 七个平台名全部就位，光束从 Z 连到每个节点 | **一次编写，原生抵达。** |
| 7.35–7.9 | 平台节点收回、标签退场 | `NATIVE EVERYWHERE · LLVM AOT · ARC` |
| 7.7–9.2 | 只剩 Z；品牌落版 | `zan.` **让想象，原生运行。** |
| 8.95–10.0 | **反向**：四块窗口从 Z 飞回四角，颜色回流；Z 冷却变暗 | （无字） |
| 10.0 → 0.0 | 与 0.0 帧完全同构 | — |

**循环原理**：最后 1.05 秒是吸收的逆过程，所以 t=10 的每一帧状态都等于 t=0。
不需要白闪、不需要淡入淡出，也没有任何东西突然出现或消失。

## 4. 文字系统

| 层级 | 字号（1080p） | 字体 | 用法 |
|---|---|---|---|
| 眉标 | 10.5px / 0.19em | 等宽 | `ZAN / 00 现在的跨平台` |
| 主句 | clamp(30–55px) / 600 | 无衬线（Segoe UI / 微软雅黑） | 一个想法，／四种写法。 |
| 结论 | 同主句，薄荷青 | 同上 | 一门语言。／原生抵达。 |
| 微标 | 10px / 0.235em，45% | 等宽 | `4 LANGUAGES · 6 TOOLCHAINS` |
| 字标 | 68px 高的手绘 SVG | 内联路径 | `zan.` |

- 两行主句**分行落位**（top 36 / 100），绝不重叠。
- 同屏最多一组文字；淡入 0.30s、淡出 0.26s，不做打字机。
- 字幕区带一层左下角径向压暗，保证大字压在窗口上依然可读。

## 5. 技术落点

- **相机**：常量 `CAM_POS / CAM_TGT`，每帧只做 `lookAt`，不产生任何位移量。
- **朝向**：中心砖与四块窗口组 `quaternion.copy(camera.quaternion)`——永远正对镜头，因此任何时刻都不穿插、比例恒定。
- **吸收曲线**：`absorbAt(t)` 在 3.45–4.75 由 0 到 1，8.95–10.0 由 1 回 0；窗口位置/透明度/去饱和全部由它驱动，天然闭合。
- **点火曲线**：`ignite(t)` 在 4.45–4.95 点亮、8.95–9.98 冷却，Z 的辉光、火花、平台亮度都挂在它上面。
- **验收**：`?t=0.02` 与 `?t=9.98` 两帧应当几乎逐像素相同。
