# RA2 高清版演示 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `examples/game/ra2/` 用 Zan 实现一个读取原版 RA2 资源（`data/ra2.mix` 等）的高清等距 RTS 演示，支持地形渲染、单位选取/移动/交战与简单 AI。

**Architecture:** 自包含分层：`formats/`（纯解析，无 SDL）→ `assets/`（VFS + 纹理缓存）→ `sim/` + `render/` → `game/` → `main.zan`。格式解析器从 `stdlib/Game/Rts/Formats` 移植副本并扩展 MIX/地图解码。

**Tech Stack:** Zan（`build/zanc` 多文件编译）、SDL3 stdlib 绑定、`System.Security.Cryptography.BigInt`（RSA）、`System.IO.File`。

**Spec:** `docs/superpowers/specs/2026-07-26-ra2-hd-design.md`

## 关键工程约定（每个任务都适用）

**编译方式** — zanc 的 `--auto-stdlib` 只按 `using X.Y;` 到 `stdlib/X/Y/` 找文件，示例自己的多文件必须显式列在命令行：

```bash
build/zanc examples/game/ra2/main.zan \
  examples/game/ra2/formats/*.zan examples/game/ra2/assets/*.zan \
  examples/game/ra2/sim/*.zan examples/game/ra2/render/*.zan \
  examples/game/ra2/game/*.zan \
  --auto-stdlib -o build/ra2.exe
```
（Git Bash 会展开 `*.zan`。此命令写进 `examples/game/ra2/build.sh` 与 README。）

**语言要点**（照抄现有 stdlib 风格）：
- `string` 兼作字节缓冲；`buf[i]` 得到 char，用 `& 0xFF` 取无符号值；写入用 `buf[i] = (char)v;`
- 分配缓冲：`[DllImport("crt")] static extern string calloc(int count, int size);` + `free`
- 32 位无符号量用 `long` 承载（见 `BinaryReader.ReadU32`）
- 泛型只有内建 `List<T>` / `Dictionary<K,V>`，以及 `System.Collections` 的 HashSet/Queue/Stack
- 类用静态工厂：`static Foo Create(...)`

**测试方式** — conformance 测试是"编译并运行，stdout 与 `.out` 金文件逐行比对"（`tests/run_case.cmake`，由 `CMakeLists.txt:450` 自动 glob）。因此每个测试写 `tests/conformance/<name>.zan` + `<name>.out`。单独跑一个：

```bash
cmake --build build --target zanc && ctest --test-dir build -R conformance_ra2_ -V
```

测试必须是**清洁室**的：数据在测试里合成，不嵌入任何原版资产（沿用 `tests/conformance/rts_shp_parse.zan` 的写法）。

**真实资源探针**放 `_scratch/`，不入库。

- [ ] **Step 1: 写失败测试（标准测试向量）**

`tests/conformance/ra2_blowfish.zan` — 用 Eric Young 的公开向量，key/明文/密文都是常数，不含任何游戏数据：

```zan
// Blowfish ECB against published test vectors (Eric Young's vector set).
using System;
using Ra2.Formats;

namespace T;

class Program {
    [DllImport("crt")] static extern string calloc(int count, int size);

    static string Hex(string buf, int len) {
        string digits = "0123456789abcdef";
        string outp = "";
        int i = 0;
        while (i < len) {
            int b = buf[i] & 0xFF;
            outp = outp + digits[b >> 4] + digits[b & 15];
            i = i + 1;
        }
        return outp;
    }

    static void Check(string keyHex, string plainHex, int n) {
        string key = calloc(9, 1);
        string blk = calloc(9, 1);
        int i = 0;
        while (i < 8) {
            key[i] = (char)Program.Nib(keyHex, i);
            blk[i] = (char)Program.Nib(plainHex, i);
            i = i + 1;
        }
        Blowfish bf = Blowfish.Create(key, 8);
        bf.EncryptBlock(blk, 0);
        Console.WriteLine("enc" + Convert.ToString(n) + "=" + Program.Hex(blk, 8));
        bf.DecryptBlock(blk, 0);
        Console.WriteLine("dec" + Convert.ToString(n) + "=" + Program.Hex(blk, 8));
    }

    static int Nib(string hex, int byteIndex) {
        int hi = Program.HexVal(hex[byteIndex * 2]);
        int lo = Program.HexVal(hex[byteIndex * 2 + 1]);
        return (hi << 4) | lo;
    }

    static int HexVal(string c) {
        int v = c[0] & 0xFF;
        if (v >= 48 && v <= 57) { return v - 48; }
        return (v - 97) + 10;
    }

    static void Main() {
        Program.Check("0000000000000000", "0000000000000000", 1);
        Program.Check("ffffffffffffffff", "ffffffffffffffff", 2);
        Program.Check("3000000000000000", "1000000000000001", 3);
    }
}
```

`tests/conformance/ra2_blowfish.out`（6 行，`encN=` 为 16 位小写 hex 密文，
`decN=` 为解回的明文 hex）：
```
enc1=4ef997456198dd78
dec1=0000000000000000
enc2=51866fd5b85ecb8a
dec2=ffffffffffffffff
enc3=7d856f9a613063f2
dec3=1000000000000001
```
> 注意：写测试时先把 `.out` 留空跑一次，把**实际**输出与公开向量核对

> key=3000000000000000 plain=1000000000000001 → cipher=7D856F9A613063F2），

- [ ] **Step 3: 实现 `formats/Blowfish.zan`**

标准 Blowfish：18 个 P-box 子密钥 + 4×256 S-box，用固定的 π 十六进制初始向量表。
公开 API：

```zan
class Blowfish {
    static Blowfish Create(string key, int keyLen);
    void EncryptBlock(string buf, int offset);   // 就地加密 8 字节
    void DecryptBlock(string buf, int offset);   // 就地解密 8 字节
    void DecryptBuffer(string buf, int offset, int length); // ECB，按 8 字节块
}
```

实现要点：
- P/S 初始表体积大（1042 个 32 位常数），存进 `List<int>`，由一个
  `static string PiHex()` 返回的十六进制长字符串解析初始化，避免 1042 行字面量。
- 32 位运算：Zan 的 `int` 是 32 位有符号，异或/加法天然回绕；`F()` 里做
  加法后用 `& 0xFFFFFFFF` 无意义（已是 32 位），但右移必须用逻辑右移：
  `(x >> 8) & 0x00FFFFFF` 形式手写，不能依赖 `>>>`。
- 子密钥生成：P[i] ^= key 循环字；然后用全 0 块迭代加密填充 P 与 S。

## Task 4: Westwood RSA 密钥恢复

加密 MIX 头里的 80 字节是用 Westwood 的固定公钥"加密"的 Blowfish 密钥：
把 80 字节切成 2 个 40 字节块，每块作大端整数做 `c^e mod n`（e=0x10001），
各产出 39 字节，拼接后取前 56 字节作 Blowfish 密钥。

**Files:**
- Create: `examples/game/ra2/formats/WsKey.zan`
- Test: `tests/conformance/ra2_wskey.zan` + `.out`

- [ ] **Step 1: 写失败测试**

测试不依赖原版文件：验证 `WsKey.Modulus()` 解出的模数位长与前几个字节，
并做一次自洽验证 —— 构造已知明文 m，算 `c = m^d mod n` 不可行（无私钥），
因此改为验证 **RSA 运算本身**：用测试内合成的小模数验证 `WsKey.ModPowBytes`
（薄封装 BigInt.ModPow）的字节序处理，再断言真实模数的指纹：

```zan
using System;
using Ra2.Formats;

namespace T;

class Program {
    static void Main() {
        // Fingerprint of Westwood's published public modulus (bit length and
        // first/last byte), so a decoding regression is caught without
        // embedding any game data.
        Console.WriteLine("bits=" + Convert.ToString(WsKey.ModulusBitLength()));
        Console.WriteLine("first=" + Convert.ToString(WsKey.ModulusByteAt(0)));
        Console.WriteLine("exp=" + Convert.ToString(WsKey.Exponent()));
        // Round-trip the byte<->BigInt conversion on a synthetic value.
        Console.WriteLine("roundtrip=" + WsKey.SelfTestRoundTrip());
    }
}
```

- [ ] **Step 3: 实现 `formats/WsKey.zan`**

```zan
using System;
using System.Security.Cryptography;
using System.Collections.Generic;

namespace Ra2.Formats;

// Recovers the Blowfish key stored in an encrypted MIX header. Westwood
// wrapped it with a fixed public key (e = 0x10001); the string below is that
// published public key, not a secret.
class WsKey {
    static string KeyString() {
        return "AihRvNoIbTn85FZRYNZRcT+i6KpU+maCsEqr3Q5q+LDB5tH7Tz2qQ38V";
    }
    static int Exponent() { return 65537; }
    static BigInt Modulus();              // base64-decode KeyString, skip ASN.1 prefix
    static int ModulusBitLength();
    static int ModulusByteAt(int index);
    static string SelfTestRoundTrip();    // returns "ok"
    // 80-byte header key source -> 56-byte Blowfish key (caller frees).
    static string Decrypt(string src, int offset);
}
```

要点：
- `KeyString()` 是 base64（用 `System.Security.Cryptography.Base64.Decode`），
  解出的 blob 前几个字节是长度前缀，模数从偏移 2 起、长度由第 1 字节给出
  （实现时打印解码结果核对，写进注释）。
- `Decrypt`：每 40 字节 → `BigInt.FromBytesBE` → `BigInt.ModPow(c, e, n)` →
  导出为 39 字节大端 → 写入输出缓冲；两块共 78 字节，返回前 56 字节。

- [ ] **Step 3: 实现 `formats/Mix.zan`**

```zan
class MixEntry {
    int Id(); long Offset(); long Size();
}

class MixArchive {
    // path 打开磁盘档案；FromBuffer 打开内嵌子档案。
    static MixArchive Open(string path);
    static MixArchive FromBuffer(string data, int length, string label);
    static int HashName(string name);         // TS/RA2 CRC32 变体
    int Count();
    bool Contains(string name);
    string ReadFile(string name, List<int> outLen);   // 未找到返回 ""
    string ReadEntry(MixEntry e, List<int> outLen);
    MixArchive OpenNested(string name);       // 子 MIX（如 cache.mix）
    void Close();
}
```

实现要点：
- 头部：`flags = ReadU32`。若 `flags & 0x00020000`：读 80 字节 → `WsKey.Decrypt`
  → `Blowfish.Create(key,56)`；解密第一个 8 字节块得 count(u16)+datasize(u32)+
  条目表前 2 字节；再解密 `ceil((count*12 - 2)/8)` 块得到完整条目表；
  数据区起点 = 4 + 80 + 已解密块数*8。若无加密位：`flags` 的低 16 位其实就是
  count（旧格式无 flags 字段）——判定规则：若 `flags & 0xFFFF0000` 只含
  0x00010000/0x00020000 位则为新格式，否则回退旧格式，从偏移 0 读
  count(u16)+datasize(u32)+条目表。
- `HashName`（TS/RA2 CRC 变体，OpenRA `PackageEntry` 同算法）：
  ```
  l = name.Length; a = l >> 2;
  if ((l & 3) != 0) {
      name += (char)(l - (a << 2));
      i = 3 - (l & 3);
      while (i-- > 0) name += name[a << 2];
  }
  return CRC32(ASCII(uppercase(name)));
  ```
  CRC32 用标准多项式 0xEDB88320 反射实现，写在 `Mix.zan` 内的 `static int Crc32`。
- 条目按 id 升序，用二分查找；同时建 `Dictionary<int,int>` id→索引加速。
- `ReadFile` 走 `File.ReadBytes(path, dataStart + offset, size)`；内嵌子档案走缓冲切片。
