# 03 UI 控件与皮肤系统

> 对应原文：`window.md`、`skin.md`(689)、`api_window/api_Layout/api_ListView/api_bagBox/api_itemBox/api_skillBox/api_quickBox/api_mapBox/api_showBox/api_modelBox/api_button/api_checkBox/api_comboBox/api_editBox/api_label/api_image/api_progressBar/api_richTextBox/api_scrollbar/api_slider/api_tabWidget` 等

## 1. UI 体系结构

DM3 的 UI 分三层：

1. **窗口（Window）**：顶层容器，`类型="窗口"`，可拖动/置顶/独占遮罩/开关动效音效，皮肤化。
2. **控件（Control）**：窗口内声明的功能性控件（按钮/背包格子/地图框…），窗口配置中 `控件 = {...}` 数组。
3. **节点（Node）**：绘制原子（文本/精灵/矩形/圆形/动画/模型/艺术字），可挂到窗口、控件、角色、地图上，见 04 篇。

窗口内还可以定义 `组件`（自定义组件/Prefab，见 02 篇第 8 节）。

## 2. 窗口（api_window / window.md）

- 关键配置：`x/y/宽度/高度`、`边框宽度/边框色/圆角半径/圆角边数`、`背景色`、`置顶`、`可移动`、`可穿透`、`默认可视`、`背景遮罩透明度`(>0 即独占模式全屏遮罩)、`底图`+`九宫`、`皮肤`("无" 跳过默认皮肤)
- `开关动效 = {开=0..n,关=0..n}`、`开关音效`
- **事件（5 个）**：`创建/打开/关闭/点击/自定义事件`
- 控件可配 `控件皮肤`（局部覆盖全局皮肤）

## 3. 皮肤系统（skin.md）

- 在 App.lua `控件皮肤` 中**全局声明**，项目内所有窗口控件默认套用；单个控件可用 `皮肤="皮肤名"` 指定或 `"无"` 跳过。
- 声明式皮肤项（13 类）：`窗口`、`按钮`（支持三层按钮：常态/悬停/按下三色）、`选择框`、`信息框`、`对话框`、`滚动条`、`组合框`、`输入框`、`选择夹`、`列表框`、`菜单`、`气泡`、`血条`。
- 皮肤要素：`底图`(九宫 {左,上,右,下})、字体/间距/文本色数组、描边色、关闭按钮、标题样式、开关动效/音效。资源同样走资源表标识。

示例（RPG 模板 App.lua 节选）：

```lua
控件皮肤 = {
  窗口 = {背景色=RGBA(20,20,20,200), 底图="默认皮肤|窗口底图", 九宫={60,60,60,60},
          关闭按钮={底图="默认皮肤|窗口关闭按钮",三层按钮=true,x=-28,y=5},
          标题={字体="宋体14粗",颜色=RGBA(220,220,220,255)}},
  通用血条 = {背景="默认皮肤|A_背景", 前景="默认皮肤|A_血条", 字体="宋体12"},
},
```

## 5. 事件约定

控件事件统一在各自 `系统事件` 中声明，命名模式：
- `创建` —— 控件实例化
- `点击/按下/弹起/改变` —— 交互
- `拖拽开始/拖拽中/拖拽结束` —— 拖拽源
- `放下/拿起` —— 格子类控件接收拖拽（配合 `引擎.鼠标道具`）
- `自定义事件` —— 事件总线

> 格子类控件与道具系统联动：拖拽拿起道具后，`引擎.鼠标道具` 变为该道具对象，点击目标格子触发 `放下` 事件，从而实现穿戴/交换/丢弃。
