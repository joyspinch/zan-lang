# 05 网络存储与服务端

> 对应原文：`server.md`(1048)、`dmclient.md`(742)、`wsclient.md`(434)、`sqlite.md`(228)

## 1. 服务端 Server.lua（`App.exe -s game`）

- 入口文件 `Server.lua`，类型 `DmTcpServer`；配套客户端组件 **DmTcpClient**。
- **消息模型**：服务端↔客户端之间直接收发 **Lua table**，以每连接唯一通信标识 `cid` 定位；`server.发送(conn.cid, {cmd="系统提示", text="..."})`。消息包上限默认 2MB（`消息长度` 可调，超限断开）。
- **服务端可用组件**：`Sqlite`、`地图`、`角色` —— 即服务端也用同一套组件描述世界。

```lua
local Server = {
  名称 = "服务端 v0.1", 端口 = 17173,
  扩展组件 = {}, 扩展脚本 = {},
  系统事件 = {
    启动 = function(server) end,
    关闭 = function(server) end,
    连接 = function(server, conn) end,      -- conn.cid, 客户端 token 在此取得
    消息 = function(server, conn, tbl) end, -- 业务消息主入口
    断开 = function(server, conn) end,
    命令 = function(server, cmd) end,       -- 控制台输入
  },
}
return Server
```

**属性**：`系统信息`（连接数等统计）。**方法**：`发送`、断开管理等。

## 2. DmTcpClient（dmclient.md）

```lua
{ 类型="DmTcpClient", 名称="客户端", ip="127.0.0.1", 端口=17173,
  token=0,      -- 传给服务端连接事件做鉴权
  系统事件 = { 创建/进入/消息/断开/进入地图/自定义事件 } }
```

- **自动心跳 + 自动重连**。
- 属性：`cid`(通信标识)、`已连接`。
- 方法：`连接`、`发送(table)`、`断开`、**`进入地图`/`退出地图`**（把客户端视角挂到服务端地图组件）、`加入事件/删除事件`。
- 事件 `进入地图` / `自定义事件`：服务端地图/角色变化推送到客户端后本地分发。

> 该模型为"帧同步前的状态同步"风格：服务端权威跑地图与角色逻辑，客户端通过 table 消息收发状态；引擎把服务端的 地图/角色 组件与客户端渲染层对接。

## 3. WebSocketClient（wsclient.md）

- `类型="WebSocketClient"`，`地址 = "ws://..."`，自动重连。
- 事件：`创建/连接/消息/断开`。推荐对接阿里云云函数或任意 WebSocket 服务端（文档给了 node.js `ws` 服务端示例）。
- 用途：与外部 HTTP/WS 生态（登录服、支付回调、聊天）对接，而不必走 DmTcp 自有协议。

## 4. Sqlite 组件（sqlite.md）

```lua
{ 类型="Sqlite", 名称="数据库", 系统事件={ 创建=function(db) end } }
```

- 服务端扩展组件（`扩展组件 = {"SqliteDB.lua"}`）。
- 方法：`打开`（文件路径）、执行 SQL（查询/执行/事务封装）、`关闭`。
- 典型用途：账号、角色存档、背包落库。
- 客户端单机侧则用 `引擎.存档/读档`（序列化 table）做轻量持久化。

## 5. 联机架构小结

```
[客户端工程]                                [服务端工程]
App.lua                                     Server.lua (DmTcpServer :17173)
  ├ DmTcpClient组件 ──── table消息/cid ────►  ├ 扩展组件: 地图/角色/Sqlite
  ├ 地图组件(渲染)                            ├ 系统事件: 连接/消息/断开
  └ WebSocketClient ──► 外部WS(云函数/登录)
```

- 单机模式：一切在客户端进程内（引擎.存档/读档）。
- 联机模式：服务端权威（地图刷怪/掉落/Sqlite 落库），客户端只做表现与输入。
- 平台模式：微端打包进"游戏盒子"，账号/金币/排行榜由盒子平台接管（引擎.平台信息）。
