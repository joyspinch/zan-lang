# 02 游戏玩法组件

> 对应原文：`app.md`(963)、`npc.md`(991)+`api_npc.md`(2034)、`skill.md`(1162)+`api_skill.md`、`buff.md`(369)+`api_buff.md`、`item.md`(489)+`api_item.md`、`map.md`(575)+`api_map.md`(1364)、`levelattr.md`、`prefab.md`(891)

## 1. App.lua —— 工程入口（app.md）

每个项目必有 `App.lua`，返回一个大 table：

| 配置块 | 说明 |
| --- | --- |
| 窗口项 | `游戏标题/屏幕宽度/高度/屏幕帧率(默认60)/垂直同步/背景颜色/屏幕适配(0-3)/重复按键` |
| `资源表` | 全局 `{标识,文件}` 数组；`dmstore_` 前缀自动从在线资源库下载 |
| `默认字体` | 必填：字体/间距/行距/文本色/描边色 |
| `信息框/对话框/技能气泡/道具气泡/状态气泡/道具格子/控件皮肤` | 全局 UI 皮肤（详见 03 篇） |
| `掉落物` | 物品落地显示：影子底图、闪烁动画、字体、背景色 |
| `状态图标` | 屏幕上 buff 图标的排布（x/y/列数/间距/置顶…） |
| `装备套装` | `部件` + 按激活件数索引的 `效果`，例：3 件套 → {攻击,防御} |
| `扩展属性` | 例 `{攻击=0,防御=0}`，**一处声明，角色/道具/技能/状态全部自动获得** |
| `扩展组件` | 组件 .lua 文件数组（地图/角色/道具/技能/窗口…），可 `return {配置1,配置2}` 合并 |
| `扩展脚本` | 纯逻辑 lua，先于组件初始化执行 |
| `菜单` | 右键菜单树（名称/标题/可视/选中/禁用/子菜单），`-` 为分割线 |
| `系统事件` | 16 个回调（见下） |

**屏幕适配**：0 无 / 1 窗口拉伸画面缩放 / 2 拉伸同步宽高 / 3 无边框透明窗口（背景颜色作透明关键色）。

**系统事件（16 个）**：`启动`(可收命令行参数，返 false 结束程序)、`游戏开始`、`游戏关闭`、`焦点变化`、`状态变化`、`宽高变化`、`鼠标按下/弹起`、`键盘按下/弹起`、`菜单`、`超链接`、`道具气泡提示`、`技能气泡提示`、`系统提示`、`自定义事件`。

**内置 10 基础属性**：`hp mp maxhp maxmp 命中 躲避 暴击 暴伤 移动速度 攻击速度`
- 命中率 = 攻方命中 ÷ (攻方命中 + 守方躲避) × 100
- 暴击率 = 随机(1,100) ≤ 暴击；暴伤默认 150（1.5 倍）
- 移动/攻击速度为百分比增减益

## 2. 角色组件（npc.md / api_npc.md）

`类型="角色"`、`名称` 全局唯一。核心配置分组：

- **成长/数值**：等级、经验值、`成长`（引用成长组件自动获得等级属性）、hp/maxhp/mp/maxmp、命中/躲避/暴击、任意扩展属性
- **AI 行为**：`智能等级`、`主动攻击`、`自动战斗`(主角)、`自动反击`、`锁定目标`、`视野范围`、`保持距离`(远程风筝)、`巡逻范围`(整数或 table 路线)、`禁止移动/禁止攻击`、`攻击间隔/移动间隔`(毫秒)、`跑动`(一次 2 格)
- **外观**：`外观`（地图动画/图片/**3D glTF 模型**+动作映射表+光影/镜头参数）、`内观`(角色框内显示)、`外观次序`、`角色大小`、`影子效果`、`动作模式`(8 方向/2 方向)、`移动帧速`
- **战斗表现**：`血条效果`、`掉血效果`、`名称效果`、`光影效果`、包围盒(鼠标焦点与技能命中位置)、出生/死亡效果、五组音效数组（出现/攻击/命中/受伤/死亡，随机播放）
- **掉落**：`掉落` 表、`掉落几率` 增幅百分比
- **社交机制**：`威望`（低威望无法发现/攻击高威望目标；威望变动清零仇恨）、`仇恨信息`（对象属性）
- **重生**：`重生间隔`(<0 不重生)、`重生范围`、`尸体保留时间`、`尸体可见`
- **宠物**：`宠物信息`，方法 `添加宠物`

**角色对象方法（26 个）**：`添加技能/删除技能/发动技能/结束技能`、`重置目标`、`添加状态/检测状态/取出状态/删除状态`、`添加宠物`、`更新外观/更新内观`、`移动到/边走边打到/瞬移`、`受伤`(主动扣血)、`重生`、`执行`、`刷新`、`销毁`、`注册帧事件`、`添加节点/取出节点/清除节点`、`加入事件/删除事件`。

**角色对象属性（45 个）**：坐标 x/y/z、阵营、等级/经验/升级经验、`属性表`(模板变量默认数据源)、目标、装备、技能、图标名、优先级、附加(自定义变量)、属性表/掉落表/掉落几率 等运行时读写。

**系统事件（11 个）**：`创建/出生/移动/受伤/死亡/倒地/点击/升级/目标变化/获得经验/移动完成`。

## 3. 技能组件（skill.md / api_skill.md）

`类型="技能"`。示例：

```lua
{
  类型="技能", 名称="普通攻击", 攻击距离=1, 动作="攻击", 间隔=2000,
  目标阵营="敌方",      -- 友方/敌方/不限
  目标位置=0,           -- 0 角色目标 1 鼠标格子 2 先角色后格子 3 自身
  优先级=1,             -- 自动释放时越大越优先，-1 禁用
  伤害延迟=500,
  伤害范围={类型=1,范围={{0,0,100}}},
  伤害公式="a.攻击 ^ 2 / ( a.攻击 + b.防御 ) * (0.8 + math.random()*0.2)",
}
```

- **目标选择**：阵营 × 目标位置 × 攻击距离/最小距离；消耗 hp/mp/怒气/仇恨。
- **伤害范围/命中范围**：格子级 AoE，3 种类型——`1 点`(面向0-7+距离+伤害比例)、`2 面`(可加随机数量)、`3 角度`；命中范围成员多一个 `延迟时间`（例：对目标点每 500ms 判定一次、连续 8 次 = 多段技能），另有 `数量`(由内向外限数)、`起点`(命中点/施法人)、`角色模式`、`唯一模式`。
- **伤害公式**：字符串表达式（a 我方 b 敌方 c 技能对象，可用 math）或 Lua 函数；可返回数值或 `{掉血值,颜色,缩放,效果}` 控制飘血。
- **起手/命中效果**：table 数组按 `延迟` 触发音效/动画/**子弹**（形态、速度、射程、数量、角度、动效 0 直线/1 抛物线、穿透、自带伤害范围与公式）。
- **受伤效果**：命中后目标表现 {几率,动作,音效,闪烁色}；`命中提示` 释放前预警范围。
- **格子效果**：技能占据格子时的显示（资源、拿起显示、偏移）。
- **事件（4 个）**：`创建`(学会技能)、`启动`、`准备`、`结束`、`技能格子`。

## 4. 状态组件（buff.md / api_buff.md）

`类型="状态"`。周期性或常驻属性增减益：

- `持续时间`(-1 永久)、`触发间隔`(0 只触发一次)
- **消失条件**：死亡消失(默认 true)/移动消失/攻击消失/受伤消失
- 属性全部支持 `属性名` 与 `属性名_百分比` 双模式（含扩展属性）；攻速/移速/命中/躲避/暴击默认即百分比
- `图标/标题` 显示到屏幕状态图标区（App.lua 排布）
- **事件（4 个）**：`创建/触发/结束/受伤`

## 5. 道具组件（item.md / api_item.md）

`类型="道具"`。

- **分类体系**：`分类`(道具/装备/特殊)、`子类`(衣服/武器/项链/手镯/戒指/消耗/其他，可自定义)、`细类`；`最大叠加`、`禁止丢弃`、`等级` 使用限制、`冷却={标识,间隔}` 共享冷却组
- **属性**：hp/mp/maxhp/maxmp 及全部扩展属性，均支持 `_百分比` 模式；`攻击速度/移动速度` 百分比
- **外观**：`内观`(角色框)、`外观`(武器外观等分层动画)、`图标`+`颜色`(品级色)、`气泡提示`(丰富文本)
- **表现**：`音效`(发现/使用/攻击)、`格子效果`、`地面效果`、`自动拾取`、`消失间隔`(默认 40s)
- **事件（5 个）**：`创建/使用/拾取/掉落/丢弃`
- **道具对象 API**：运行时改 `数量`、`冷却进度`(0-100)、气泡等；`引擎.鼠标道具` 直接操作拿起的道具

## 6. 地图组件（map.md / api_map.md）

`类型="地图"`。**斜 45° 矩形网格**（`格子宽度=64,格子高度=32` 典型传奇视角）：

- 基础：格子宽高/列数/行数、`默认地图`、`初始位置`、`小地图`(自动进地图框控件)、`边距`(扩黑边使角色居中)、`地图模板`(在线模板标识)
- **表现**：`环境色`、网格显示/颜色、`排序显示`(高物件排序线框)
- **内容四表**：`地图物件`(静态图/动画+锚点)、`地图格子`(障碍状态)、`地图角色`({名称,阵营,格子x,格子y,范围,数量} 批量刷怪)、`地图门点`(传送门：坐标→目标地图/坐标/方向)、`地图光源`(光斑/氛围)
- **地图对象方法（19 个）**：`创建角色/取出角色/查找角色`、`地图格子`(读写障碍)、`添加物件/地图物件/地图光源`、`掉落物品`、`设置主角`、`显示气泡`、`重置`、`抖动`、`坐标转换`、`取出空位`、节点三件套、`加入事件/删除事件`
- **地图对象属性（13 个）**：`主角`、`镜头对象/镜头平滑移动`、`视距`、`加速`、`黑白画面`、`暂停`、`鼠标事件`、`环境色`、`地图信息`、`初始位置` 等
- **事件（4 个）**：`创建/门点/鼠标事件/自定义事件`

## 7. 成长组件（levelattr.md）

`类型="成长"`：按等级数组给角色自动配基础属性。可用 Lua 循环生成 99 级数据（例：`maxhp = 60+(n-1)*5`，`升级经验 = floor((50*(n^1.8+0.4n))/10+0.5)*10`），角色配置 `成长="主角成长"` 即挂接。

## 8. 自定义组件 / Prefab（prefab.md / api_prefab.md）

- 用 `文本/精灵/矩形/动画/模型` 等节点拼装出新"类型"（例：文本按钮），可在窗口 `组件` 内联定义或独立文件入 `扩展组件`。
- `属性 = { 标题=function(组件对象,value) ... end }` 拦截属性赋值实现数据绑定；`方法` 表暴露自定义方法；`系统事件` 含 `创建/更新/鼠标按下弹起移动滚轮/焦点变化/拖拽开始中结束`。
- 运行时 `取出节点("名字")` 访问内部节点。

## 9. 丰富文本（richText.md）

`#W #R #Y #B...` 快速颜色、`#f(字体)`、`#c(颜色)`、`#p(图片,x,y)` 图文混排、`#z(x,y)` 定位、`#L` 换行、`#rt(100)` 右对齐、超链接与气泡提示，用于道具气泡/聊天/公告等所有文本场景。
