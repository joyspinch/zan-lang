# 04 节点绘制与缓动动画

> 对应原文：`api_node_text/api_node_bmptext/api_node_sprite/api_node_rectangle/api_node_circleShape/api_node_animation/api_node_model`、`api_sprite`、`api_tween`(712 行)

## 1. 节点（Node）体系

节点是最小绘制单元，可挂载于：窗口、自定义组件（`节点 = {...}` 数组）、地图、角色（`添加节点/取出节点/清除节点`）。共同模式：

```
{
  名称 = "节点名",        -- 局部唯一，用 取出节点("名") 获取
  类型 = "文本|艺术字|精灵|矩形|圆形|动画|模型",
  默认可视 = true,
  鼠标事件 = false,       -- 是否拦截鼠标
  资源表 = {...},         -- 节点级资源表
}
```

| 节点类型 | 文件 | 用途与要点 |
| --- | --- | --- |
| 文本 text | api_node_text | 普通文本，字体/描边/对齐（15 项） |
| 艺术字 bmptext | api_node_bmptext | 像素字/图集字（`-f` 命令生成的字体），数字滚动等（11 项） |
| 精灵 sprite | api_node_sprite | 图集帧精灵（15 项） |
| 矩形 rectangle | api_node_rectangle | 矢量矩形：填充/边框/圆角/渐变，可做血条底、遮罩（17 项） |
| 圆形 circleShape | api_circleShape | 矢量圆/环/扇形，技能指示器（19 项） |
| 动画 animation | api_node_animation | 图集动画：动作名/播放次数/模式/定格帧（18 项） |
| 模型 model | api_node_model | 3D 模型渲染节点（27 项：光影角度/仰角/镜头角度距离/缩放/动画速度/阴影），配合角色 `外观` 的 glTF |

动画动作字符串约定贯穿全引擎：`"动作名,播放次数,播放模式,定格帧"`（次数 0=循环；模式 0 正序 1 倒序）。

## 2. 缓动（api_tween）

`引擎.创建缓动()` 创建补间对象，9 个方法：

| 方法 | 说明 |
| --- | --- |
| `to` | 补间到目标值（时间+easing） |
| `by` | 相对增量补间 |
| `wait` | 等待 |
| `call` | 完成回调 |
| `jump` | 跳跃轨迹（抛物线位移） |
| `stop` | 停止 |
| `over` | 查询是否结束 |
| `all` | 全部停止 |
| `progress` | 进度查询 |

典型链式用法：移动 UI 弹出动画、NPC 巡逻位移、伤害数字飘动。技能"子弹"（速度/射程/抛物线/穿透）在效果系统内独立实现，不走 tween。

## 3. 与渲染相关的全局机制

- **排序**：地图分低物件 `tile`（不参与排序）与高物件 `object`（按 y 参与排序），地图模板 json 中即区分（asset.md）。
- **光影**：角色 `光影效果/影子效果`、模型节点 `阴影效果/光照角度/光照仰角/影子透明`、地图 `地图光源` 光斑、`环境色` 全局染色。
- **转场**：`引擎.转场动画`；镜头：地图对象 `镜头对象/镜头平滑移动/抖动/视距`。
