# 01 引擎核心与运行时 API

> 对应原文：`api_engine.md`（2038 行）、`api_global.md`（1407 行）、`api_tween.md`、`varTable.md`

## 1. 全局单例 `引擎`（api_engine）

脚本中通过 `引擎.xxx` 访问的全局接口，分属性与方法两部分。

### 属性（9 个）

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `系统信息` | table 只读 | 窗口标题、桌面/屏幕宽高与鼠标坐标、帧率、垂直同步、运行模式（0 调试/1 打包/2 盒子）、运行时间 |
| `平台信息` | table 只读 | 游戏盒子账号：玩家账号/昵称/头像、签到、投币、发电、剩余金币；`附加[1..5]` 五个整数可自动同步平台并做排行榜 |
| `地图` | 地图对象 只读 | 当前地图对象，最常用入口 |
| `道具` | 道具对象 读写 | `引擎.道具["短剑"]` 取项目默认道具配置并可改 `气泡提示` 等 |
| `菜单` | 菜单对象 读写 | 读写 App.lua 声明的菜单项（标题/可视/选中/禁用），支持 `重置()` 动态重建 |
| `鼠标道具` | 道具对象 只读 | 鼠标上拿起的道具，无则 nil |
| `鼠标技能` | 文本 只读 | 鼠标上拿起的技能名 |
| `鼠标角色` | 角色对象 只读 | 鼠标焦点处的角色对象 |
| `鼠标指针` | 整数/文本 读写 | 0-20 系统指针样式，或填自定义指针组件名；-1 隐藏 |

### 方法（14 个）

| 方法 | 用途要点 |
| --- | --- |
| `系统设置` | 全局系统项（如 Alt 显示掉落名持续可见等） |
| `屏幕提示` | 屏幕飘字/气泡，支持锚点偏移、弹簧效果、跟随角色对象 |
| `弹出文字` | 场景内文字弹出 |
| `转场动画` | 场景切换过渡 |
| `播放特效` | 播放全局特效 |
| `信息框` / `对话` | 内置信息框/对话 UI（皮肤由 App.lua 配置） |
| `引导` | 新手引导 |
| `增加物品(名称,数量)` / `减少物品` / `取物品数量` / `取包裹空位` | 背包裹物操作 |
| `创建音乐` | 返回音乐对象（见 api_music） |
| `创建缓动` | 返回缓动对象（见 api_tween） |
| `添加指针` | 注册自定义鼠标指针组件 |
| `弹出菜单` | 弹出 App.lua `菜单` 中声明的菜单，点击事件回流到 App `菜单` 事件 |
| `存档` / `读档` / `结束` / `执行` / `资源解析` / `加入事件` / `删除事件` | 存档、程序结束、执行脚本、资源路径解析、自定义事件总线 |

## 2. 全局函数（api_global，22 个）

- **调试**：`调试输出`、`Log`
- **颜色**：`RGBA(r,g,b,a)`
- **哈希/编码**：`MD5`、`BASE64`
- **HTTP**：`POST`（客户端直接发 http 请求，可对接外部服务）
- **字符串扩展**：`string.split`、`string.fileinfo`、`string.addspace`
- **数学扩展**：`math.round`、`math.format`、`math.取两点间距离`、`math.取两点间格子`、`math.取两点间角度`、`math.取两点间方向`、`math.按角度距离取坐标` —— 这组是格子地图战斗的基础几何函数
- **工具**：`os.uuid`、`table.copy`、`table.tojson`、`table.loadjson`、`table.tofile`、`table.loadfile`

## 3. 模板变量（varTable）

- 语法：文本中写 `&属性名&`，绑定**当前主角属性表**；组件/接口支持时文档会标注"支持模板变量"。
- 数据变化后视图自动刷新，典型用法：`标题 = "生命: &hp&/&maxhp&  法力: &mp&/&maxmp&"`。
- 自定义数据源：把任意 table 填到控件的 `数据源` 属性，模板变量改为绑定该 table（如调试标签绑定 `引擎.系统信息`，用 `&桌面宽度&` 等取值）。

## 4. 缓动系统（api_tween）

`引擎.创建缓动()` 生成缓动对象，链式 API 共 9 个：
`to`（补间到目标值）、`by`（相对增量）、`wait`、`call`（回调）、`jump`（跳跃路径）、`stop`、`over`（是否结束）、`all`、`progress`。用于 UI/节点/NPC 的程序化动画。

## 5. 事件总线

所有对象（引擎、地图、角色、窗口、dmclient…）均有 `加入事件/删除事件` 与 `自定义事件` 派发，构成跨组件解耦通信（见 07 速查表）。
