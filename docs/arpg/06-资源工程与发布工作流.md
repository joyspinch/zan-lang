# 06 资源工程与发布工作流

> 对应原文：`get-started.md`、`asset.md`、`dmres.md`、`gameBox.md`、仓库目录（项目模板/组件模板/资源库/游戏盒子）

## 1. 工程目录形态

引擎发行包（免安装）：

```
App.exe            # 引擎宿主 + 编译器 + 工具集
Dat/Game.lib       # 引擎字节码库
DmMcp.exe          # MCP AI 服务（供 Trae 等 AI IDE 调用）
Dat/mcp_config.json
Res/               # 本地资源（与引擎同级，不是工程目录内）
MapRes/ Res/ 资源库/ 组件模板/ 项目模板/ 游戏盒子/
```

一个游戏工程（如 `项目模板/RPG模板/`）：

```
App.lua                 # 入口：窗口/资源表/皮肤/扩展组件/系统事件
地图/矿洞13.lua          # 地图组件
角色/主角.lua  角色/半魔人.lua
技能/普通攻击.lua
道具/木剑.lua
窗口/包裹窗口.lua  窗口/角色窗口.lua  窗口/底部UI.lua
```

## 2. 资源体系

- **资源表**：全局 `{标识,文件}`；引擎自动补 `Res/` 前缀；`dmstore_XXXX` 表示在线 DM 资源库素材（dm3.2ddm.com/store），启动时自动下载缓存到 `Res/dmstore`。配置处一律填标识。
- **直接路径**：不经资源表、直接写控件/节点 `图片=` 属性时**不补前缀**，须写全 `Res/地图/1.png`；适合工具类项目动态加载。
- **常用素材**（dmres.md）：宋体12/黑体12/宋体14粗/黑体14/默认皮肤 等固定 dmstore 标识可直接引用。
- **地图模板**（asset.md）：GBK 编码 .json，字段 `dmtools="map", ver=10, width/height/col/row, obs[](0 通行/1 障碍/2 透明/3 障碍+透明), tile[]低物件, object[]高物件, res{标识→{type 1图/2动画, file, action, ox, oy 中心点}}`。

## 3. 命令行工具集（App.exe）

| 命令 | 功能 |
| --- | --- |
| `-n 模板标识 项目名` | 从在线资源库或本地 .pro 模板创建工程 |
| `-g 项目名 [参数]` | 调试运行，参数进"启动"事件 |
| `-s 项目名` | 启动服务端 |
| `-b 项目名 [nopak/appkey]` | 打包：单机合并资源 / nopak 不合并 / appkey 微端上传 |
| `-p 项目名` | 导出 .pro 工程模板 |
| `-c xxx.dat` | 运行打包后的游戏（如内置地图编辑器 `Dat/MapEditer.dat`） |
| `-f 字体 宽 高 行距 粗细 平滑` | 生成像素字体（等宽字体） |
| `-u 文件 gbk/utf8` | 编码转换 |
| `-y 目录 [保存目录]` | 图片裁剪到最小有效区，生成偏移文件 |
| `-z 目录 [1]` | 压缩 jpg/png/json 资源 |

## 4. 模板生态（仓库实测）

**项目模板**（完整可运行工程）：`RPG模板`（矿洞探险：主角+半魔人+木剑+包裹/角色窗口/底部UI）、`传世RPG`、`俄罗斯方块模板`、`消消乐模板`、`地图编辑器`、`图集编辑器`、`模型读取`、`自定义控件`。

**组件模板**：`传奇风格`（主角男+怪物+技能+道具）、`欧美风格`（弓箭手/野蛮人/魔法师+技能+装备）、`魔兽三风格`（大法师/灰狼/雄鹿，**glb 3D 模型**）、`地图`（传世风格/风格1_地牢/风格2_出生地/密道/山洞）。

→ AI 建项目的本质：`-n 模板` 拷模板工程 + MCP 让 AI 改写各组件 .lua。

## 5. 发布三通道

1. **单机**：`-b game` → `Build/game.dat + 游戏名.exe`（`nopak` 资源不合并，便于打补丁）。
2. **微端/盒子**：`-b game appkey` 上传到游戏盒子平台；玩家侧由 `游戏盒子.exe`（`Dat/config.json`：title/icon/text/gid 首页工程/uid 只显示某作者）聚合展示；游戏内 `引擎.平台信息` 读写账号/签到/投币/金币，`附加[1..5]` 同步排行榜。
3. **联机**：服务端工程 `-s` 部署（见 05 篇），客户端可微端分发。

## 6. 调试

- 游戏内 `F12`：内置系统信息窗（地图状态/鼠标格子/坐标）。
- `调试输出`/`Log` 打印到控制台；绑定 `引擎.系统信息` 到调试标签实时显示。

## 7. 附:RPG 模板实战解剖(源码实录)

### 主角.lua 的分层着装与数值
`默认主角=true` + `阵营="友方"`、技能表 `{名称="普通攻击",自动释放=true}`、
`包围盒={52,104,0,10}`(宽,高,x偏移,y偏移,F12 可视化)、
`血条效果={{皮肤="通用血条",显示偏移=-110,血条颜色=RGBA(0,220,0)}}`、
`掉血效果={艺术字="艺术字",缩放={0.8,1.5},动画效果=3}`、
`外观={{位置="衣服",动画="角色动画_棉布衣"}}`、
`装备={武器={名称="",显示外观=true,格子="角色窗口/主角武器"}}` ← 装备位绑定到角色窗口的道具格子控件,穿武器即换外观。

### 半魔人.lua 的怪物 AI 数值
`经验值=50`(被杀奖励)、`尸体保留时间=5000`、`重生间隔=10000`、`掉落={"木剑 1/1"}`(掉落表字符串语法:道具 几率/权重)、
AI 组:`巡逻范围=8`、`追击距离=10`、`视野范围=4`、`主动攻击=true`、`自动战斗=true`、`攻击间隔=3000`、`移动间隔=1500`。

### 普通攻击.lua 的完整技能
`攻击距离=1`、`间隔=2000`(CD)、`目标位置=0`(锁定角色)、`伤害延迟=500`(起手到判定)、
`伤害范围={类型=1,范围={{0,0,100}}}`(自身面向0距离0=对目标)、
`受伤效果={几率=100,动作=true,音效=true,闪烁=RGBA(255,255,255)}`、
`伤害公式="a.攻击 ^ 2 / ( a.攻击 + b.防御 ) * (0.8 + math.random() * 0.2)"`。

### 木剑.lua —— 组件配置+逻辑混合(随机属性装备)
道具组件的 `系统事件.创建` 里写随机属性逻辑:基础攻击 5~15,从 暴击/命中/攻速/maxhp/maxmp/防御 池随机抽 1~2 条。
说明组件文件既可以是纯配置,也可以内嵌 Lua 逻辑(创建时机:道具实例化)。

### 底部UI.lua —— 血球进度条+遮罩波浪
进度条控件 `最大值="&maxhp&" 位置="&hp&"` 用模板变量直连主角属性;
`遮罩=1` 图片框定义镂空形状,`遮罩=2` 动画框只在镂空内显示(血球波浪动画),纯配置实现暗黑式血球。

### 矿洞13.lua —— 在线地图模板+批量刷怪
`地图模板`/`小地图` 均为 dmstore 在线素材;
`地图角色` 一条配置 `{名称="半魔人",格子x=50,格子y=50,范围=5,数量=3,等级=5,...}` 即在范围内刷 3 只并覆盖部分 AI 数值(等级/主动攻击/间隔)。
