## 5. 伤害范围三种类型（技能/命中范围通用）

```lua
-- 类型=1 点模式：{面向0-7, 距离, 伤害比例}
伤害范围 = {类型=1, 范围={{0,1,100},{1,1,70},{2,1,70},{6,1,70},{7,1,70}}}  -- 半月
-- 类型=2 面模式：第4参 可选"随机数量"（命中范围中）
-- 类型=3 角度模式
-- 命中范围成员多一维 {面向,距离,比例,延迟时间} → 多段判定
命中范围 = {类型=1, 范围={{0,0,100,0},{0,0,100,500},{0,0,100,1000},...}}  -- 每500ms一次×N
-- 附加：数量(由内向外限制)、起点(0命中点/1施法人)、角色模式、唯一模式
```

## 6. 效果数组通用格式（技能起手/命中、子弹）

```lua
起手效果 = {
  {延迟=0, 音效={"xx起手"}},
  {延迟=0, 动画="血影刀法,攻击"},
  {延迟=400, 子弹={形态="动画,火球术,飞行", 速度=800, 射程=1200, 数量=1, 角度=0,
                   动效=0,   -- 0直线 1抛物线
                   穿透=0, 伤害延迟=0,
                   伤害范围={类型=1,范围={{0,0,100}}},
                   伤害公式="...", 受伤效果={...}, 命中效果={{延迟=0,音效={...}},{延迟=0,动画="火球术,命中"}}}},
},
```

## 7. 属性双模式与公式

- 任何属性 X 均可写 `X`（绝对值）或 `X_百分比`（百分比），道具/状态/角色通用。
- 命中率 = `攻方命中/(攻方命中+守方躲避)*100`；暴击 = `随机(1,100)<=暴击`；暴伤默认 150。
- 伤害公式：`"a.攻击^2/(a.攻击+b.防御)*(0.8+math.random()*0.2)*c.伤害系数"`（a 我方 b 敌方 c 技能对象）或函数 `function(技能对象,来源角色,目标角色,伤害比例,名称) return 数值 or {掉血值,颜色,缩放,效果} end`。
