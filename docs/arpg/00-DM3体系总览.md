## 1. DM3 是什么

**DreamMod3（Dream Mod Game Engine 3.0）** 是一个 Windows 64 位、免安装、解压即用的**2D 即时战斗（ARPG/传奇类）游戏模组引擎**：

- **脚本语言：Lua 5.4**，全部配置与逻辑以 Lua table 表达，"不写一行脚本，全 AI 自动化实现一个游戏" 是其官方卖点。
- **声明式配置驱动**：游戏 = 一组"组件配置文件"（`.lua`，返回一个 table），引擎负责解释执行。
- **中文编程界面**：所有 API、配置项、事件均为中文命名（`引擎.屏幕提示`、`角色.血条效果`、`:small_blue_diamond: 死亡` 事件等）。
- **AI 协作内置**：发行包自带 `DmMcp.exe` + `Dat/mcp_config.json`，即引擎通过 MCP（Model Context Protocol）对接 AI IDE（Trae / VSCode+Trae 插件），实现对话式建项目、改游戏。
- **面向对象形态**：单机（App.exe `-b` 打包 exe+dat）、微端（游戏盒子线上发布）、C/S 联机（`-s` 启动 Server.lua）。

## 2. 极简使用流程

```
./App.exe -n app1 game      # 从在线资源库模板创建工程（生成 game/App.lua）
./App.exe -g game           # 调试运行（可传参给"启动"事件）
./App.exe -b game           # 编译打包 → Build/game.dat + 我的活动.exe
./App.exe -s game           # 启动服务端模式
```

其他命令行：`-p` 导出工程模板(.pro)、`-c` 运行打包后的 dat、`-f` 生成像素字体、`-u` 编码转换(GBK/UTF8)、`-y` 图片裁剪最小有效区、`-z` 资源压缩。

## 4. 核心机制速览（详见各分篇）

- **组件化**：App.lua 的 `扩展组件` 数组声明游戏由哪些组件文件组成（地图/角色/技能/道具/窗口…），`扩展脚本` 载入纯逻辑库；两者先于 `游戏开始` 事件初始化。
- **资源表**：全局 `{标识,文件}` 映射，`dmstore_` 前缀 = 在线 DM 资源库素材自动下载缓存到 `Res/dmstore`；配置处填标识不填路径。
- **模板变量**：`&hp&/&maxhp&` 语法把主角属性表绑定进任意文本，数据变化视图自动更新（MVVM 雏形）。
- **属性系统**：10 个内置基础属性（hp/mp/maxhp/maxmp/命中/躲避/暴击/暴伤/移动速度/攻击速度）+ 任意数值型 `扩展属性` 一处声明全组件生效；道具/状态/技能均有 `属性名` 与 `属性名_百分比` 双模式。
- **战斗内核**：命中公式 `攻击者命中/(攻击者命中+被攻击者躲避)*100`；暴击 = `随机(1,100) <= 暴击`；伤害公式支持字符串表达式（a 我方/b 敌方/c 技能对象）与 Lua 函数两种。
- **事件驱动**：所有组件统一 `系统事件` table 声明回调（创建/移动/受伤/死亡/点击…），App 级还有键盘鼠标/菜单/气泡提示等 16 个全局事件；自定义事件用 `加入事件/删除事件` 分发。

## 5. 与 Zan 项目的关联点（个人笔记视角）

- DM3 的"配置驱动 CRUD + 权限/属性声明在配置旁 + 组件即插即用"与本项目 L2 元数据驱动思路同源，可对照其 `扩展属性 → 全组件自动获得` 的做法。
- 其 MCP 接入方式（引擎内置 mcp server 供 AI IDE 调用）是"AI 原生引擎"的现成范式。
- ARPG 战斗数值模板（命中/暴击/仇恨/威望/掉落/套装）可作为 zan 游戏模板的业务参考。
