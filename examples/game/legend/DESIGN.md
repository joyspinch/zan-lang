## 1. 单机化方案总览

PRD 描述的是带服务器端演算的"传奇放置挂机"网页/微端网游。本工程是 **Zan + SDL3
的单机演示**，因此所有需要服务器/在线的功能都做了"单机降级"：

| PRD 系统 | 单机版方案 |
|---|---|
| 离线挂机（服务器演算） | 本地按真实墙钟 dt 累积；启动时按 `last_ts` 计算离线秒数批量结算 |
| 在线挂机（5 秒/怪） | 主循环按 `IdleStep(dt)` 在前台 tick |
| 排行榜 / 幻境层数榜 | **影子天梯**：以玩家自己的历史 best 为种子生成伪对手分布（10 人榜） |
| 世界 BOSS（全服共斗） | **影子共斗**：固定 HP，玩家 30 秒内打出多少伤害即得多少贡献，影子榜排序 |
| 沙巴克（行会攻城） | 标"开发中"——纯社交 PvP，单机版不可复现 |
| 城池争夺 / 钱庄 | **单机影子**：每日 1 次结算随机事件决定护租/被抢 |
| 押镖 / 劫镖 | **单机影子**：每日 5 次自动生成可劫镖的影子镖车 |
| PK 竞技场 | **单机影子**：从玩家历史 best 生成对手 3 人，胜+100 / 负+20 战功 |
| 传说塔 | **单机影子**：5 层，每层守关=玩家历史镜像 |
| 师徒 | **单机**：1 名 NPC 徒弟 + 1 名 NPC 师父，纯数值驱动 |
| 行会 | **单机**：玩家"创建/加入"一个影子行会，资产按离线时间累积 |
| 交易市场（C2C） | **影子挂牌**：每日刷新一批 NPC 挂牌，玩家可买/挂单（离线不交易） |
| 寻宝 | 完全本地：每日 0 点刷奖池（本地时间） |
| 祭坛 | 完全本地：单进度条，全服档改为"全服影子共建" |
| 红包 | 完全本地：发给自己/影子好友 |
| 邮箱 | 完全本地：附件 8 格、一键领取、清空已领 |
| 聊天 | **影子广播**：每 N 秒自动播放一条"玩家 X 获得 Y"的全服掉落广播 |
| 会员（终身 / 超级终身） | 三档由玩家自己勾选，演示付费层特权 |

**单机版的红线**：
1. 所有 PvP / 排行榜的"对手"必须有可重现的种子（Rng 派生），断网/重启后镜像关系不漂移；
2. 所有"离线"事件必须**幂等地**可在登录时结算；
3. 不引入任何联网请求。

## 2. 本期实现的系统清单（广度优先策略）

### 2.1 端到端可玩（核心循环）

- **角色 3 职业 + 等级 + 9 转**：战士 / 法师 / 道士，生命 / 法力 / 攻击区间 / 防御 / 魔防 / 经验
- **幻境推层**：自动战斗、推层 BOSS、离线 24h 满结算、掉落墙、扫荡特权（终身会员）
- **秘境推层**：转生后解锁，材料/经验产出更高
- **装备 12 槽 + 系数 + 品阶**：武器 / 头盔 / 衣服 / 项链 / 手镯×2 / 戒指×2 / 腰带 / 鞋子 / 宝石 / 天书 / 印记 / 护身符
- **铁匠铺**：金币洗炼（有概率降低）/ 元宝洗炼（保底）/ 升级锻造 / 幸运传承 / 符文锻造
- **回收 7 货币**：金币 / 经验 / 战功 / 声望 / 红包 / 元宝 / 积分，"一物七吃"
- **BOSS 之家（个人 BOSS）**：沃玛/祖玛/赤月/魔龙/牛魔/七转守卫 共 8 只，每日次数
- **世界 BOSS（影子共斗）**：固定 HP 巨型 BOSS，30 秒打伤害计贡献
- **称谓天梯**：21 页 105 级，纯声望+金币，免费线
- **爵位**：6 档（男爵→亲王），元宝累计捐献
- **五行修炼**：金木水火土 5 槽 + 离线时间制
- **将星图谱**：8 卡池，激活费翻倍递增
- **神兵图鉴**：9 组，每组 10 槽（沉没成本，向上替换）
- **至尊极品殿堂**：5 页（武器之攻/武器之法/武器之道/铠甲之首/头盔之首），登记 +5% 经验
- **寻宝**：每日奖池，连抽，自动寻宝
- **祭坛**：单进度 + 全服影子进度
- **成就**：等级 / 充值 / 推图 / 属性 / BOSS / 推广 6 类
- **排行榜（总榜 + 幻境 + PK + 世界 BOSS + 钱庄 + 师徒 + 祭坛）**：影子榜 10 人
- **PK 竞技场（影子）**：3 个影子对手，胜 +100 / 负 +20 战功，小时薪排名
- **押镖 / 劫镖（影子）**：每日 5 次 + 5 劫镖
- **城池争夺 / 钱庄（影子）**：8 城，每日收租/被抢
- **传说塔（影子）**：5 层镜像挑战
- **师徒（影子）**：1 NPC 师父 + 1 NPC 徒弟
- **行会（影子）**：单人行会
- **交易市场（影子）**：NPC 挂牌 + 玩家寄售
- **商店**：元宝 / 金币 / 灵符 / 激活码 四页
- **邮箱**：附件 8 格
- **聊天 + 广播**：本地世界/行会频道，影子玩家自动广播
- **帮助（公式算法公开）**：符文之语公式 / 洗炼概率公示 / 经验公式
- **设置**：老板键 F10 / 界面缩放 80-300% / 静默模式 / 装备过滤 / 转永久区

## 3. 三文件拆分

```
examples/game/legend/
├── DESIGN.md     # 本文件
├── Data.zan      # 静态数据表（地图/怪物/BOSS/装备模板/符文/称谓/爵位/图谱/图鉴）
├── Game.zan      # 游戏状态 + 离线结算 + 推层战斗 + 洗炼 + 回收 + 寻宝 + 影子榜种子
└── main.zan      # SDL3 主机 + 30+10 导航栏 + 左角色面板 + 右聊天 + 中央幻境 + 全部面板
```

合计约 4500 行，编译命令：

```
build/zanc.exe examples/game/legend/main.zan \
              examples/game/legend/Game.zan \
              examples/game/legend/Data.zan \
              examples/game/common/GameKit.zan \
              --auto-stdlib -o build/legend.exe
```

## 5. 节奏红线（参考 PRD §15.5 的每日行为锚点）

每日登录 5 分钟内的"分配决策"清单：

1. 领离线结算（弹窗，2 秒）
2. 处理世界 BOSS（30 秒倒计时，1 次/天）
3. 处理个人 BOSS（每只 1 击，10 秒）
4. 处理 PK 竞技场（每日 5 次，30 秒）
5. 处理押镖 + 劫镖（每日 5+5 次，1 分钟）
6. 处理钱庄收租（每日 1 次，10 秒）
7. 处理寻宝（按寻宝图数量，30 秒）
8. 处理祭坛捐献 + 补领昨日（30 秒）
9. 处理铁匠铺洗炼 + 装备分配（1 分钟）
10. 看称谓 / 成就 / 图鉴 进度条（30 秒）

总耗时 ≈ 5 分钟，符合 PRD "上班族碎片时间"设定。

## 6. 数值节奏（基线锚点）

无头仿真：`LEGEND_SIM=1 build/legend.exe`，输出 `build/legend_sim.log`。
仿真分四段：**A** 在线 60s → **B** 离线 8h → **C** 长跑 7 天（每天一键换装 +
一键回收 + 24h 挂机）→ **D** 强推转生，最后跑一遍健全性检查。

### 6.1 实测基线（2026-09-02，战士，自动换装开）

| 阶段 | 幻境层 | 等级 | 累计击杀 | BOSS 击破 | 金币 | 攻 | HP |
|---|---|---|---|---|---|---|---|
| T0 建档 | 1 | 1 | 0 | 0 | 1,000 | 13~15 | 80 |
| A 在线 60s | 3 | 2 | 22 | 0 | 1,398 | 25~27 | 98 |
| B 离线 8h | 73 | 25 | 1,350 | 7 | 14.3 万 | 290~299 | 636 |
| C day1 | 160 | 80（封顶）| — | 15 | 452 万 | 1581~1605 | 2307 |
| C day7 | 251 | 80 | 10,250 | 25 | 1.03 亿 | 4580~4606 | 4502 |
| D 转生 | — | 1（转生 1）| — | — | — | 4442~4445 | — |

**结论**：首日可推到 160 层并封顶 80 级；7 天推到 ~250 层并攒够 25 次 BOSS 击破，
刚好够第一次转生（`TURN_REQ_BOSS[1] = 20`）。转生是真正的节奏闸门，等级不是。

### 6.2 关键曲线常量（`Data.zan`）

| 常量 | 值 | 说明 |
|---|---|---|
| `HJ_HP_BASE` / `HJ_HP_GROWTH` | 30 / **1.028** | 怪 HP 每层 ×1.028（原 1.18 会把玩家 3 天锁死在 20 层） |
| `HJ_ATK_GROWTH` | 1.022 | 怪攻击成长 |
| `ATK_INTERVAL` | 1.2 s | 一次出手；配合 ~4 刀击杀 ≈ 5 s 节拍 |
| `OFFLINE_BEAT` | 5.0 s | 离线每 5 秒结算一只怪（PRD §幻境） |
| `HJ_DROP_RATE` | 0.18 | 普通怪掉装备率，BOSS 必掉（原 0.6 会 60 秒塞满背包） |
| `EQUIP_COEF_PER_FLOOR` | 10 | 掉落系数每 10 层 +1，保证高层掉落跟得上 HP 曲线 |
| `REWARD_GOLD/XP/SW_GROWTH` | 1.030 / 1.035 / 1.025 | 每层收益成长（原 1.05~1.06 会让金币 7 天冲到 67 亿） |
| `EXP_BASE` / `EXP_POW` | 80 / 1.45 | 升级经验 = 80 × LV^1.45 |

### 6.3 已修的三处数值/逻辑缺陷

1. **`StepIdle` 每帧一刀**：`dt` 被忽略，怪在几帧内被秒。改为 `atkAcc` 累加器 +
   `AtkInterval()`（受速度属性压缩，下限 0.35 s），一次结算最多补 4 刀防追帧爆炸。
2. **离线虚报击杀**：按总时长算 `kills`，但"卡层守卫"提前 break 后仍全额记账，
   导致 `totalKills` 虚高 10 倍而等级不动。改为统计 `actualKills`。
3. **洗炼上限削装备**：`TIER_COEF_CAP[tier]` 是绝对上限（最高 12），而楼层掉落系数
   在 250 层已到 ~26，一洗炼就被削回 12。改为"当前系数 + 品阶头room"。

### 6.4 健全性检查（`SimCheck`）

每轮仿真末尾校验：7 种货币非负、层号 ≥ 1、总 HP > 0、攻击上下限不反、背包 0..60、
装备品阶 0..4 / 系数 ≥ 1 / 槽位 0..11、金币非 NaN。当前 **PASS**。

### 6.5 已知未做深度平衡

PRD 的"幻境 6043 层"是全网历史最高记录，**不是**可达目标。以 HP ×1.028 的指数曲线
配合 `long` 上限（9.2e18），理论天花板约 1100 层；实际 7 天 ~250 层，需要靠 9 次转生
的乘区继续推进。要把曲线拉到千层以上，需要把伤害/HP 都换成科学计数（double + 尾数/
指数拆分显示），这是独立的工作量，本期不做。

## 7. 已知工程折中

- **Zan IDE 禁自绘规则**（AGENTS.md "ZanIDE禁止任何自绘必须全部用标准库组件来完成"）：
  所有 UI 控件（按钮/进度条/面板/标签）通过 GameKit 的 `Draw.RoundRectFill` /
  `Text.Draw*` / `Ui.Button` / `Ui.Panel` 程序化绘制，或贴 9-slice 资产；不调任何
  原始像素 set 操作。
- **音效**：直接走 SDL3 wav 短音（盒/锻造/提示/交易/升级）。
- **存档**：单文件 key=value 文本（`legend_save.txt`，与旧 `miner_save.txt` 同源设计）。
- **确定性**：所有 Rng 派生走 `GameKit.Rng.Seed(playerBest ^ tick)`；不引入系统时间
  作为随机源（系统时间只用于日刷新 / 离线时长结算）。
