# examples/game/ra2 — 红色警戒 2 演示

用 Zan 重写的《红色警戒 2》等轴测 RTS 演示：直接读取玩家自己的原版
MIX 资源包，用 SDL3 渲染。

> 当前进度：主菜单（原版 TITLE.PCX 背景）→ 遭遇战设置（地图列表 +
> 地图预览 + 阵营选择 + 阵营配色）→ 完整遭遇战。数值层 `game/Rules.zan`
> 按原版 RULES.INI 转写：武器/弹头/护甲克制/造价/血量/射程/装填/科技树
> 全部数据驱动，`data/` 里装有原版 RULES.INI 时会直接读它。盟军/苏军
> 两套建筑与兵种（大兵/动员兵、警犬、工程师、狙击手、间谍、超时空军团兵、
> 谭雅、磁暴步兵、防空步兵、疯狂伊文、辐射工兵、尤里、恐怖机器人，以及
> 灰熊/犀牛坦克、棱镜坦克、天启、V3 等原版 VXL 体素车辆），特殊机制
> 齐备：伊文定时炸弹、工程师占领、间谍停电、尤里心灵控制、超时空冻结、
> 辐射工兵部署、遇袭反击、驻守警戒。经济只有矿场出钱，没有被动收入；
> AI 按 [AI] 建造序列扩张、补防御、练兵进攻，**和玩家遵守同一套规则**。
> 遭遇战支持**最多 7 个敌人槽位**，每个 AI 独立难度（可全冷酷）、独立经济，
> 全员混战；打光所有 AI 的建筑（快速游戏）或建筑+部队（长局）才分胜负。
> 摧毁对方全部建筑分胜负（遭遇战设置可开**快速游戏**）——无平局补丁：
> 长局模拟验证弱方必败（t≈5250）、强方决定性获胜（t≈21496）。

## 准备资源（必需）

本仓库**不附带任何原版素材**。你需要自备一份合法的《红色警戒 2》安装目录，
整个拷到：

```text
examples/game/ra2/data/
```

程序启动时会先检查以下资源包是否就位，缺任何一个都会打印提示并退出：

- `ra2.mix`
- `language.mix`
- `multi.mix`

`data/` 已在 `.gitignore` 中，永不入库。

## 编译运行

在仓库根目录执行：

```bash
bash examples/game/ra2/build.sh
./build/ra2.exe
```

操作：

| 界面 | 按键 |
| --- | --- |
| 主菜单 | 鼠标点击；`Esc` 退出 |
| 遭遇战设置 | `↑`/`↓` 选地图，`Enter` 开始，`Esc` 返回；敌人槽位点**关闭(点击加入)**加入该 AI，点难度牌循环其难度（简单/普通/冷酷） |
| 游戏内 | 左键选中对象（拖框多选，Shift+点击追加）/ 点击建造菜单武装建造 / 地图上点击放置；`A` 武装移动攻击后点击目标；`Ctrl`+数字存编队、数字召回；选中兵营或战争工厂后点击训练面板训练单位；右键移动、攻击或取消建造；方向键或贴屏边缘平移，滚轮或 `+`/`-` 缩放，点击小地图跳转镜头，空格步进一帧，`P` 暂停/继续，`Esc` 返回 |
| 任何时候 | `F11` 全屏 |

不想手动点，可以让它自己走一遍完整流程再退出：

```bash
RA2_SELFTEST=1 ./build/ra2.exe
```

## 已实现

- **归档**：MIX 读取（含 Blowfish 加密头、TS/RA2 名字哈希）、分层 VFS
- **格式**：INI、CSF、PAL、SHP、TMP、PCX、Format80/LCW、LZO1X、IsoMapPack5
- **地形**：主题贴图集、等轴测投影、按 `x+y` 的画家序合成、视区裁剪、
  水面拦路、桥可通行
- **界面**：原版 PCX 背景（TITLE.PCX，过暗时自动提亮）、红警风主菜单
  （居中红色大标题 + 红条纹金属按钮 + 侧边警示带）、地图预览缩略图、
  场景状态机
- **数值层**：`game/Rules.zan` 按原版 RULES.INI 转写——武器（伤害/装填/
  射程）、弹头对 11 类护甲的克制表、单位/建筑造价血量、科技树前置、
  建造时间、电力收支全部数据驱动；`data/` 里有原版 RULES.INI 时
  `Rules.Load` 直接覆盖默认值
- **游戏**：建筑占地放置、单元生成与寻路（BFS，目标被建筑封死时自动
  改打够得着的最近敌人）、左键选中、右键移动，按阵营的建造菜单（按钮
  显示原版建筑贴图、锁定的前置变暗）、资金扣除、原版 SHP 建筑贴图 +
  建造动画 + 选中框、建造幽灵预览（绿=可放/红=受阻）
- **战斗**：射程内开火、伤害按弹头×护甲结算、血量条（绿→黄→红）、
  目标死亡自动重获、尸体清理、枪口闪光 + 死亡爆炸特效；遇袭反击（无目标
  的单位回头打攻击者）、空闲单位驻守警戒自动迎敌
- **特殊机制**：疯狂伊文定时炸弹（400 伤害开罐碉堡）、工程师进建筑
  占领、间谍进电厂全区停电、尤里心灵控制（ MindControl 免疫单位除外）、
  超时空军团兵冻结、辐射工兵部署辐射区、恐怖机器人寄生跳脸
- **碾压**：履带/悬浮类的 `Crusher=yes` 载具（灰熊/犀牛/天启/采矿车等
  13 种）开进敌兵所在的格子会直接把人轧死——不留尸体（DeathType.Crush
  跳过死亡动画、InfDeath 归零）、按自己的 `CrushSound=` 出声（步兵
  InfantrySquish）、轧杀照常给经验；可碾的墙（沙袋 GASAND、三种栅栏墙
  CAFNCB/CAFNCW/CAFNCP）被压塌且**不**向邻格连锁半伤（半伤只走弹伤
  路径），混凝土墙 GAWALL/NAWALL 缺 `Crushable=` 所以挡得住；碾墙的
  载具拿到 rocking 请求（34 刻衰减）。老兵能力 `CRUSHER` 在晋级时把
  标志翻起（`VeteranTrait.handlePromotion`），但轮式车拿到标志仍被
  SpeedType 门挡住
- **防御建筑**：机枪碉堡/哨戒炮/磁暴线圈/高射炮自动迎敌，耗电的防御
  在低电压或停电时离线；围墙阻挡地面单位
- **生产**：兵营/战争工厂排队训练（进度条、从建筑旁空地走出），缺电
  减半速；**没有建造厂就不能建造**——打掉基地车，敌方基地从此无法重建，
  这是终结一场战争的关键
- **经济**：只有建成的矿石精炼厂按 Rules 每刻滴钱（油井被工程师占领后
  也出钱），没有被动收入；矿场被拆就会断粮
- **电力**：电厂供电、建筑耗电，低电压生产减半、耗电防御离线，侧边栏
  实时显示电力平衡
- **小地图**：地形缩略图 + 敌我对象点 + 当前视野框，点击跳转镜头
- **选择信息**：选中单位/建筑后，顶部信息条显示名称、血量、攻击/射程或
  电力贡献，选建筑时还会显示训练能力
- **阵营控制**：只能指挥自己阵营的单位——点敌方单位只显示信息，右键
  空地不会操控它，也不能用敌方建筑训练（修复了之前可操控敌方单位的
  作弊漏洞）
- **暂停**：`P` 键暂停/继续游戏，暂停时 AI、生产、战斗全部停止，镜头
  仍可滚动
- **多选**：左键拖框选择多个己方单位（绿色选择框，敌方排除），Shift+
  点击追加选择，右键批量移动/攻击（队伍自动散开站位），全部单位显示
  选择框
- **移动攻击**：`A` 键武装后点击目标点，所有选中单位前往该处并沿途自动
  攻击遇到的敌人（经典 A-move），光标旁有红底"移动攻击"提示
- **编队**：`Ctrl`+`1`..`0` 把当前选择存为编队，按 `1`..`0` 一键召回（死亡
  成员自动跳过）；多选时信息条显示"已选 N 个单位"
- **单位贴图**：所有单位都用原版 SHP 精灵——警犬 DOG、间谍 SPY、狙击手
  SNIPE、工程师 ENGINEER 是本人；因精简安装缺少 E1/动员兵贴图，普通步兵
  复用平民 CIV1 的精灵，全部带走路动画和 8 朝向，不再是占位菱形
- **车辆**：坦克是原版 VXL 体素模型（含独立炮塔 VXL）——灰熊/犀牛坦克、
  甲弹斗车、坦克杀手、棱镜坦克、V3 发射车、磁暴坦克、盖特坦克、天启、
  恐怖机器人、采矿车，渲染带 8 朝向与炮塔转向
- **单位动画**：有原版贴图的单位带走路动画（8 朝向 × 6 帧循环）+ 原地
  呼吸动画，移动时会根据行进方向切换朝向块
- **敌方 AI**：遭遇战可开最多 7 个 AI（受地图出生点数限制），每房独立
  钱包、难度与建造游标，阵营轮转、全员混战；小地图与侧栏资金按房着色、
  显示敌方合计。AI 走 Rules 的 [AI] 建造序列
  （电厂→矿场→兵营→电厂→战争工厂→雷达→科技→防御），按同样的前置和
  造价检查补矿场、补电、重建被毁的生产建筑、维持部队并主动进攻；AI 与
  玩家完全同规：基地车被毁后它同样不能再建造
- **终局**：摧毁对方全部建筑即胜利/失败，结束画面后按 `Esc` 返回；遭遇战
  设置里的**快速游戏**开着时打光对方建筑就算赢（不用再清散兵）——长短
  两种规则的胜负链路由 `winchain.zan` 回归程序验证（含多 AI 房
  的逐个清场场景）；没有
  平局兜底——headless 长局模拟（24000 刻）验证过弱势方必败、强势方
  决定性获胜，双端都不会卡死
- **溅射**：带 CellSpread 的弹头（磁暴波、辐射爆发等）向落点周围摊伤害，
  随距离线性衰减、按受击方护甲克制结算、不伤友军与中立单位

## 已知缺口

- **抬升地形下方有菱形空洞**。悬崖/高地的 TMP `extra` 数据块已能解析
  （`flags` 位 0 标志其存在），但绘制位置仍不对：实测四张地图开启后空洞
  总数只从 61673 降到 60406，且其中两张反而变差，所以默认关闭。用
  `RA2_EXTRA=1` 可以打开继续调试。
- **侧边栏按钮仍是自绘的圆角矩形**。原版按钮/侧边栏是 SHP，但 MIX 用
  哈希存名字，这些资源名还没找到。按钮里现在放的是对应建筑的原版贴图
  缩略图，但按钮边框和排版是自己画的。
- **没有启动动画**。原版是 VQA 视频，解码器未实现。
- **碾压的几处边角还没接上**：① `CrushSound=` 参考项目只解析、从不播放
  （全树 grep 只有 `ObjectRules.ts` 的读取点），但零售版会响，所以本移植
  照零售版接线（走 `SndEngine.CrushSoundFeedback`）——这是一处**故意的
  参考偏离**；② 参考里履带车驶向可碾目标时会触发 `SCATTER` 老兵能力的
  逃散（`MoveTask.ts:854-864`），本移植的老兵能力表还没有 SCATTER，逃散
  路径未接；③ 参考的 `MoveTrait` 会豁免 `StanceType.Paradrop`（伞兵未落地
  不挨碾），本移植还没有空降姿态；④ rocking 只移植了请求/衰减/状态，渲染
  层还没画出车身倾斜；⑤ 参考的 rocking 幅度按 `weight` 衰减
  （`Vehicle.updateRocking`），本移植未接体重。
- **内置 `[OverlayTypes]` 表是按零售版转写的**（246 项，含 40/41/183 三处
  DUMMY 填充），这样不装 `data/` 时沙袋/围墙也能被地图 OverlayPack 字节
  索引到；有安装时 `ApplyIni` 会用安装自己的表整体替换并清掉按索引缓存
  的墙/可碾事实。
- **没有空军与超级武器**。基洛夫、火箭飞行兵、核弹、闪电风暴不在单位与
  科技清单里；鲍里斯的空袭呼叫也因此暂用步枪本体作战。
- **盖特兰升温未实现**。盖特系列的多管升温（越打射速越快）只保留了
  固定射速。
- **单位贴图是"替代品"而非本人**。这个精简安装没有美国大兵/动员兵的
  SHP（美术被裁掉了），所以这些单位借用了类别相近的原版精灵（步兵用
  平民 CIV1），外形与原版对应单位不同但都是原版素材。若把完整版
  E1/E2.SHP 放进 data/，改一行 `shpName` 即可换成真身。

## 测试

胜负规则的回归程序独立编译，不读 `data/`（地形是程序化铺出的平地，
规则用 `Rules.Default()`），237 项断言覆盖胜负链路（长局/短局/判负/多
AI 房）以及各子系统：皮肤/战区、粒子、损伤火焰、步兵姿态与死亡序列、
墙的连接与连锁半伤、矿石生长、可破坏桥梁、焦痕、战争迷雾、箱子、
声音引擎的键名分流与事件位、老兵经验等级、碾压（规则键解析、Track/
Hover 门控、友军豁免、进格轧杀与尸体豁免、墙的碾压与邻格不连锁、
rocking 请求与衰减、老兵 CRUSHER 授予）：

```bash
cd 仓库根目录
./build/zanc.exe templates/game/ra2/winchain.zan \
  templates/game/ra2/src/game/*.zan \
  templates/game/ra2/src/formats/*.zan \
  templates/game/ra2/src/Assets/*.zan \
  templates/game/ra2/src/render/RenderShim.zan \
  --auto-stdlib -o build/winchain.exe
./build/winchain.exe   # 输出 winchain ok,否则逐项列 FAIL 并返回非零
```

跑完整流程的自测（读 `data/`，走到遭遇战并截图退出）：

```bash
RA2_SELFTEST=1 ./build/ra2.exe             # 盟军+苏军各跑一遍,双阵营截图
RA2_HEADLESS=1 加在上面即可无窗口运行
```
