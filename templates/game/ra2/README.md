# examples/game/ra2 — 红色警戒 2 演示

用 Zan 重写的《红色警戒 2》等轴测 RTS 演示：直接读取玩家自己的原版
MIX 资源包，用 SDL3 渲染。

> 当前进度：主菜单（原版 TITLE.PCX 背景）→ 遭遇战设置（地图列表 +
> 地图预览 + 阵营选择）→ 完整遭遇战。数值层 `game/Rules.zan` 按原版
> RULES.INI 转写：武器/弹头/护甲克制/造价/血量/射程/装填/科技树全部
> 数据驱动，`data/` 里装有原版 RULES.INI 时会直接读它。盟军/苏军两套
> 建筑与兵种（大兵/动员兵、警犬、工程师、狙击手、间谍、超时空军团兵、
> 谭雅、磁暴步兵、防空步兵、疯狂伊文、辐射工兵、尤里、恐怖机器人），
> 特殊机制齐备：伊文定时炸弹、工程师占领、间谍停电、尤里心灵控制、
> 超时空冻结、辐射工兵部署、遇袭反击、驻守警戒。经济只有矿场出钱，
> 没有被动收入；AI 按 [AI] 建造序列扩张、补防御、练兵进攻，**和玩家
> 遵守同一套规则**。摧毁对方全部建筑分胜负——无平局补丁：长局模拟验证
> 弱方必败（t≈5250）、强方决定性获胜（t≈21496）。

## 准备资源（必需）

本仓库**不附带任何原版素材**。你需要自备一份合法的《红色警戒 2》安装目录，
整个拷到：

```text
examples/game/ra2/data/
```

程序启动时会先检查以下资源包是否就位，缺任何一个都会打印提示并退出：

- `ra2.mix`
- `language.mix`
- `multi.mix`

`data/` 已在 `.gitignore` 中，永不入库。

## 编译运行

在仓库根目录执行：

```bash
bash examples/game/ra2/build.sh
./build/ra2.exe
```

操作：

| 界面 | 按键 |
| --- | --- |
| 主菜单 | 鼠标点击；`Esc` 退出 |
| 遭遇战设置 | `↑`/`↓` 选地图，`Enter` 开始，`Esc` 返回 |
| 游戏内 | 左键选中对象（拖框多选，Shift+点击追加）/ 点击建造菜单武装建造 / 地图上点击放置；`A` 武装移动攻击后点击目标；`Ctrl`+数字存编队、数字召回；选中兵营或战争工厂后点击训练面板训练单位；右键移动、攻击或取消建造；方向键或贴屏边缘平移，滚轮或 `+`/`-` 缩放，点击小地图跳转镜头，空格步进一帧，`P` 暂停/继续，`Esc` 返回 |
| 任何时候 | `F11` 全屏 |

不想手动点，可以让它自己走一遍完整流程再退出：

```bash
RA2_SELFTEST=1 ./build/ra2.exe
```

## 已实现

- **归档**：MIX 读取（含 Blowfish 加密头、TS/RA2 名字哈希）、分层 VFS
- **格式**：INI、CSF、PAL、SHP、TMP、PCX、Format80/LCW、LZO1X、IsoMapPack5
- **地形**：主题贴图集、等轴测投影、按 `x+y` 的画家序合成、视区裁剪、
  水面拦路、桥可通行
- **界面**：原版 PCX 背景（TITLE.PCX，过暗时自动提亮）、红警风主菜单
  （居中红色大标题 + 红条纹金属按钮 + 侧边警示带）、地图预览缩略图、
  场景状态机
- **数值层**：`game/Rules.zan` 按原版 RULES.INI 转写——武器（伤害/装填/
  射程）、弹头对 11 类护甲的克制表、单位/建筑造价血量、科技树前置、
  建造时间、电力收支全部数据驱动；`data/` 里有原版 RULES.INI 时
  `Rules.Load` 直接覆盖默认值
- **游戏**：建筑占地放置、单元生成与寻路（BFS，目标被建筑封死时自动
  改打够得着的最近敌人）、左键选中、右键移动，按阵营的建造菜单（按钮
  显示原版建筑贴图、锁定的前置变暗）、资金扣除、原版 SHP 建筑贴图 +
  建造动画 + 选中框、建造幽灵预览（绿=可放/红=受阻）
- **战斗**：射程内开火、伤害按弹头×护甲结算、血量条（绿→黄→红）、
  目标死亡自动重获、尸体清理、枪口闪光 + 死亡爆炸特效；遇袭反击（无目标
  的单位回头打攻击者）、空闲单位驻守警戒自动迎敌
- **特殊机制**：疯狂伊文定时炸弹（400 伤害开罐碉堡）、工程师进建筑
  占领、间谍进电厂全区停电、尤里心灵控制（ MindControl 免疫单位除外）、
  超时空军团兵冻结、辐射工兵部署辐射区、恐怖机器人寄生跳脸
- **防御建筑**：机枪碉堡/哨戒炮/磁暴线圈/高射炮自动迎敌，耗电的防御
  在低电压或停电时离线；围墙阻挡地面单位
- **生产**：兵营/战争工厂排队训练（进度条、从建筑旁空地走出），缺电
  减半速；**没有建造厂就不能建造**——打掉基地车，敌方基地从此无法重建，
  这是终结一场战争的关键
- **经济**：只有建成的矿石精炼厂按 Rules 每刻滴钱（油井被工程师占领后
  也出钱），没有被动收入；矿场被拆就会断粮
- **电力**：电厂供电、建筑耗电，低电压生产减半、耗电防御离线，侧边栏
  实时显示电力平衡
- **小地图**：地形缩略图 + 敌我对象点 + 当前视野框，点击跳转镜头
- **选择信息**：选中单位/建筑后，顶部信息条显示名称、血量、攻击/射程或
  电力贡献，选建筑时还会显示训练能力
- **阵营控制**：只能指挥自己阵营的单位——点敌方单位只显示信息，右键
  空地不会操控它，也不能用敌方建筑训练（修复了之前可操控敌方单位的
  作弊漏洞）
- **暂停**：`P` 键暂停/继续游戏，暂停时 AI、生产、战斗全部停止，镜头
  仍可滚动
- **多选**：左键拖框选择多个己方单位（绿色选择框，敌方排除），Shift+
  点击追加选择，右键批量移动/攻击（队伍自动散开站位），全部单位显示
  选择框
- **移动攻击**：`A` 键武装后点击目标点，所有选中单位前往该处并沿途自动
  攻击遇到的敌人（经典 A-move），光标旁有红底"移动攻击"提示
- **编队**：`Ctrl`+`1`..`0` 把当前选择存为编队，按 `1`..`0` 一键召回（死亡
  成员自动跳过）；多选时信息条显示"已选 N 个单位"
- **单位贴图**：所有单位都用原版 SHP 精灵——警犬 DOG、间谍 SPY、狙击手
  SNIPE、工程师 ENGINEER 是本人；因精简安装缺少 E1/坦克贴图，普通步兵
  复用平民 CIV1 的精灵、坦克/气垫船复用防空车 FLAKT 的精灵，全部带走路
  动画和 8 朝向，不再是占位菱形
- **单位动画**：有原版贴图的单位带走路动画（8 朝向 × 6 帧循环）+ 原地
  呼吸动画，移动时会根据行进方向切换朝向块
- **敌方 AI**：地图远端生成敌方基地，AI 走 Rules 的 [AI] 建造序列
  （电厂→矿场→兵营→电厂→战争工厂→雷达→科技→防御），按同样的前置和
  造价检查补矿场、补电、重建被毁的生产建筑、维持部队并主动进攻；AI 与
  玩家完全同规：基地车被毁后它同样不能再建造
- **终局**：摧毁对方全部建筑即胜利/失败，结束画面后按 `Esc` 返回；
  没有平局兜底——headless 长局模拟（24000 刻）验证过弱势方必败、
  强势方决定性获胜，双端都不会卡死

## 已知缺口

- **抬升地形下方有菱形空洞**。悬崖/高地的 TMP `extra` 数据块已能解析
  （`flags` 位 0 标志其存在），但绘制位置仍不对：实测四张地图开启后空洞
  总数只从 61673 降到 60406，且其中两张反而变差，所以默认关闭。用
  `RA2_EXTRA=1` 可以打开继续调试。
- **侧边栏按钮仍是自绘的圆角矩形**。原版按钮/侧边栏是 SHP，但 MIX 用
  哈希存名字，这些资源名还没找到。按钮里现在放的是对应建筑的原版贴图
  缩略图，但按钮边框和排版是自己画的。
- **没有启动动画**。原版是 VQA 视频，解码器未实现。
- **单位贴图是"替代品"而非本人**。这个精简安装没有美国大兵/动员兵的
  SHP（美术被裁掉了），所以这些单位借用了类别相近的原版精灵（步兵用
  平民 CIV1），外形与原版对应单位不同但都是原版素材。若把完整版
  E1/E2.SHP 放进 data/，改一行 `shpName` 即可换成真身。
- **没有车辆**。精简安装没有坦克/车辆的 SHP，所以遭遇战是纯步兵战争：
  战争工厂只出恐怖机器人。Rules 层已按原版写好车辆字段，补齐车辆贴图
  并在 `Rules.zan` 里登记即可恢复装甲洪流。

## 测试

`formats/`、`assets/`、`render/`、`game/` 下的代码有一套回归测试，
同样只用 zanc 编译，不经过 CMake：

```bash
bash examples/game/ra2/tests/run.sh
```

每个 `tests/<名字>.zan` 是独立程序，它的标准输出必须逐字匹配
`tests/expected_<名字>.out`。测试只用公开测试向量和构造出来的缓冲区，
**不读 `data/`**——那是你自己的游戏安装目录。
