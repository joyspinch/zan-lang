# RA2 迁移排障规程(每片验证的血泪沉淀)

来源:战争迷雾片(2026-09-12)。移植本身半天完成;排障烧掉的时间数倍于移植,
以下每条都是当日实际踩过坑的直接反面。

## 1. 逻辑探针先进 winchain,自检只管画面与集成

winchain(RenderShim、无 GUI、平地构造图)是确定性秒级回归;双线自检有菜单
过场前端(~2 分钟)且地图轮换。迷雾段错误在自检里烧了 13+ 轮"改-编译-跑",
同样的二分搬进 winchain 后 4 轮搞定。**每片的探针先写成 winchain 场景,跑绿了
再进自检看截图。**

## 2. 原生崩溃第一步:读 build/zan_crash.log

寄存器转储直接给答案:`rcx=0xfeeefeeefeeefeee`(Windows 堆释放填充)即
use-after-free;`rcx` 就是被毒指针。今日排障数小时后才打开它,而它第一眼就
写着"已释放对象"。zanc 无 addr2line,用 gdb(`info symbol`/`disassemble`)
把偏移翻译回函数,一步到位。

## 3. 崩溃插桩写文件,别写 stdout

stdout 有缓冲,崩溃丢尾——死点"漂移",制造出根本不存在的"非确定性",
把排查引向无辜代码(今天冤枉过 double 转型与容器类型)。用
`File.AppendAllText` 标记文件,拿到真实的最后一条语句。退出码速查:
bash 下段错误 139,zanc ARC/护栏失败 70。

## 4. 一次实验验一个假设,先写判别式,别先写"修复"

把"疑似代码"改掉重跑是修复尝试;它通过了也不知道是不是它的问题是它。
先构造最小判别:同一二进制里并排放"孤立探针"与"出问题的路径"(今日
`probeA` 孤立 shroud 全绿 + `InitShrouds` 崩,一步锁死差异在取用路径)。

## 5. 环境是变量:跨时间对比必须建基线

并行会话会在中途重建 zanc/stdlib/zan_gui.dll。性能与崩溃的先后对比,隔了
一次 DLL/编译器重建就全部失效。对照法:
`git worktree add _scratch/wt-base <已验证提交>`,同一编译器同一 DLL 重编
基线版,A/B 同机顺序跑。**绝不 git stash。**

## 6. 编译器/运行时 bug:绕过 + 留精确定位,不修编译器

今日定位到 zanc ARC 误编译:三元表达式 `cond ? null : list[i]` 返回引用时
元素引用计数被错放,活对象被提前释放(段错误,确定性复现)。处理:
语义等价绕过(显式 if + 局部变量),winchain 场景即复现用例,报给编译器侧;
模板侧不恋战。

## 7. 探针一切从玩家房推导,不许写死房号/兵种

迷雾探针把征召兵生成在 0 号房,苏军腿(玩家房非 0)揭示落错 shroud、
OrderMove 因"不指挥非指挥官部队"被拒——探针红了半天其实是断言错。规则:
房号一律 `game.Side()`;兵种查本房花名册(盟军 E1,苏军 E2);选择按对象
(`AddSelectionByObject`)不按格子。

## 8. 已知环境噪声(报并行会话)

- zanc 三元 ARC 误编译(见第 6 条),复现:winchain 迷雾场景绕过前版本。
- 04:29 的 zan_gui.dll/stdlib 重建后,draw/terr 全阶段 +4~5ms
  (基线 130cf7ad 在新环境 drawAvg 16-17ms,焦痕时代同代码 11-13ms),
  16ms 预算在新环境下基线自身已贴线。

- 06:27:49 并行会话对工作树做了 `reset --hard a57b9a9a`(reflog 铁证),
  六文件未提交的箱子切片整片被洗;stash 全部早于事故、悬空对象里也

## 10. 声音切片:IMA 块头样本与 GBK 日志的 grep

- AUD IMA(压缩 99)每块输出含块头预测器本体:outSize = 2 + 2*半字节数,
  即"1 个头预测器样本 + 每半字节 1 个"。解码器必须先把头预测器写进输出
  再走半字节链——只算半字节会少 1 样本/块且块头错位(Vladan Bato 文档
  与 FFmpeg westwood_aud 的 outSize 记账都指向这一语义)。合成样件用
  "每块 5 样本 = 4 增量 = 整 2 字节",奇数增量会让解码器多吃一个幽灵
  半字节,样件设计必须保持偶数增量。
- 自测日志是 GBK+CRLF 混合编码,Git Bash 的 grep 会按二进制吞掉匹配;
  一律 `grep -a`。日志行数对不上时先怀疑这个,再怀疑回归。
