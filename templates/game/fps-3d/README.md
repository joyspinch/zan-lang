# 3D Target Tag — Neon Time Trial (第一人称 3D 霓虹计时赛模板)

基于 Zan.Game.Render3D 的第一人称计时赛：在一座霓虹黄昏竞技场里跑、跳、冲刺，
**用准星标记全部发光目标，越快越好**。6 个关卡组成一条短战役，每关有金/银/铜奖牌、
一枚隐藏碎片，成绩与奖牌持久保存。

## 玩法

- **核心循环**：倒计时 3-2-1-GO → 计时开始 → 标记本关全部目标 → 结算（净用时、奖牌、最佳）。
- **净用时 = 计时 − 奖励**：
  - **连击**：上一次标记后 2 秒内再标记，连击 +1（最多 x4），每次奖励 (连击−1) × 0.2 秒；
    右上角洋红条显示连击窗口剩余。
  - **隐藏碎片**：每关藏着一枚金色晶体（墙后、柱顶、角落），碰到即 −2 秒，并永久记录"已找到"。
- **目标种类**：静止、沿导轨往返（余弦缓动）、绕塔环绕；**踏台目标**（带旋转光环）
  只有站在同色发光踏台上标记才算数。标记射程 16 m，建筑会挡住准星。
- **关卡**（难度递增，机器人实测见下）：
  1. WARM-UP — 6 个静止目标，熟悉移动与标记；
  2. ELEVATION — 中央高台、坡道与胸墙，部分目标要绕后或登高；
  3. DRIFT — 8 个导轨移动目标，练习预判与连击；
  4. VANTAGE — 4 个踏台目标；
  5. ORBIT — 三只目标绕 9 m 高塔转圈，外加移动与踏台目标；
  6. GAUNTLET — 12 个目标、全部机制混合。
- **进度**：通关（任意用时）解锁下一关；选关页显示每关奖牌、最佳、三档奖牌门槛与碎片。

## 画面

- 程序化黄昏天空盒 + 同色距离雾 + 半球环境光 + 斜射日光 2048 阴影贴图 + ACES 色调映射、暗角与泛光。
- 地面是双色方砖（顶点色网格）+ 青色发光网格线；建筑按用途配色（墙 紫/洋红灯条、柱 青、
  平台 琥珀、坡道 楔形网格 + 侧灯条、掩体 冰蓝、踏台 同目标色），顶边嵌发光灯条。
- 目标：自转发光核心 + 半透明脉动光壳 + 直冲天空的信标光柱；最近 4 个目标各挂一盏同色脉动点光；
  移动目标有导轨/环绕光点轨迹。标记时迸出碎片、冲击光环、屏幕色闪与轻微镜头震动；
  已标记目标缩成灰色残骸（不再挡准星）。
- HUD（全部标准 Gui 控件 + 本游戏"霓虹黄昏"皮肤 `src/FpsSkin.zan`）：关卡牌与奖牌配速、
  大计时与奖励飘字、进度环（`Progress.Ring`）、连击条、碎片状态、四态准星（空闲/锁定/太远/需踏台）
  + 命中 X、屏幕内目标菱形与距离、屏幕外贴边箭头、3-2-1-GO 倒计时。
- 开始页与选关时镜头绕竞技场环飞，背景随选中的关卡切换。
- GPU 不可用时 CPU 透视线框兜底（天空渐变 + 网格 + 建筑 + 目标）。

## 操作

| 按键 | 作用 |
|---|---|
| W A S D / 方向键 | 移动 |
| Space | 跳跃（按住落地即连跳；有起跳缓冲与土狼时间） |
| Shift | 冲刺 |
| 按住鼠标左键或右键拖动 | 转动视角 |
| F 或右键单击 | 切换自由视角（无需按住，选择会被记住） |
| 鼠标左键 | 标记准星对准的目标 |
| R | 对局中快速重开本关；结算页重试 |
| P / Esc | 暂停 / 继续 |
| Enter | 开始页开始、结算页下一关 |
| S / ←→ | 开始页打开选关 / 切换关卡；选关页方向键选择、Enter 开始、Esc 返回 |
| M | 静音 / 取消静音（会被记住） |

## 存档

`GameProfile.Open("fps-3d")`：每关最佳净用时 `SubmitLowest("best_s<i>")`（奖牌由最佳用时对照门槛得出）、
碎片 `Flag("shard_s<i>")`、局数 `plays`、通关数 `clears`、`muted`、`freelook`。写在用户数据目录：

- macOS：`~/Library/Application Support/ZanGames/fps-3d/`
- Windows：`%LOCALAPPDATA%\ZanGames\fps-3d\`
- Linux：`~/.local/share/ZanGames/fps-3d/`

设置环境变量 `ZAN_GAME_DATA_DIR=<目录>` 可改根目录（测试 / 便携版）。
调试：`FPS3D_DEBUG=1` 解锁全部关卡并启用 T 键（瞬移到最近目标并标记），`FPS3D_STAGE=<n>` 选默认关卡；默认关闭。

## 平衡

奖牌门槛用无头机器人定出：BFS 寻路 + 自动瞄准的机器人分三档（熟练 60 px/帧甩枪、
普通 25 px/帧 + 0.2 s 反应、新手 12 px/帧 + 0.5 s 反应且不冲刺）各跑一遍全部关卡。
净用时（秒）：

| 关卡 | 熟练 | 普通 | 新手 | 金 / 银 / 铜 |
|---|---|---|---|---|
| WARM-UP | 2.6 | 3.6 | 9.7 | 6.0 / 12.5 / 22.5 |
| ELEVATION | 5.9 | 6.5 | 12.7 | 10.5 / 16.5 / 30.0 |
| DRIFT | 11.8 | 7.0 | 20.8 | 19.0 / 27.0 / 48.5 |
| VANTAGE | 15.0 | 17.7 | 24.0 | 28.0 / 36.5 / 65.5 |
| ORBIT | 9.4 | 13.6 | 17.2 | 22.0 / 28.5 / 51.5 |
| GAUNTLET | 12.0 | 16.5 | 27.2 | 26.5 / 35.5 / 64.0 |

金牌 ≈ 熟练/普通机器人 × 1.6，银牌 ≈ 新手 × 1.3，铜牌 ≈ 银牌 × 1.8（真人拖拽转视角比机器人慢得多）。

## 回放与回归

`src/FpsSim.zan` 以固定 1/60 秒一帧无头推进 `FpsGame`（不上传网格、不画、不碰音频与档案），
种子决定关卡（`seed % 6`）。输入编码见文件头注释：`1..64` 按键位（前/后/左/右/跳/冲刺）、
`100..107` 拖鼠标、`200` 左键标记、`300` 朝最近目标甩一次鼠标（换算成真实鼠标位移）。
校验和覆盖关卡、位置、视角、着地、准星状态、标记位图、完成、计时、奖励、连击与碎片；
不变量检查俯仰钳制、命中距离、标记计数、计时/倒计时、连击与奖励上限、玩家在场内且不嵌进建筑、
准星"可标记"状态与踏台规则一致。
`replays/bot.replay` 由 `Replay.Fuzz(new FpsSim(), "FpsSim", 20261125, 1200, FpsSim.Bot, 0)` 录制；
改了关卡布局、移动、跳跃或视角参数导致回放分叉时，按 `packages/Zan.Game/src/Game/Foundation/README.md`
重新录制。

## 已知缺口（模板内绕行，待包/驱动修复）

- **macOS GL 后端 3D 上下颠倒**：Render3D 的输出在 macOS 上整帧上下翻转（HUD 正常；改造前的截图里同样如此）。
  `FpsScene.FlipWorkaround()` 在 macOS 上把世界、相机、光源沿 X 镜像并把相机倒挂来抵消；驱动修好后删掉即可，
  `FPS3D_FLIP=0/1` 可强制关/开对照。GPU 后处理 Pass（曝光/ACES/暗角/泛光）默认关闭，`FPS3D_POST=1` 打开。

## 运行与编译

在当前主仓根目录运行，直接编译模板原始源码，不复制模板树：

```powershell
Set-Location D:/project/zan-lang
& ./scripts/build_gate.ps1 -Name build -Script {
    build/zanc.exe templates/game/fps-3d/src/main.zan templates/game/fps-3d/src --auto-stdlib --package-project . --publish --subsystem windows -o build/fps3d.exe
}
build/fps3d.exe
```

`main.zan` 必须排在首位，随后 `src` 目录递归纳入其余源码（`FpsGame` 规则与物理、`FpsStages` 关卡数据、
`FpsScene` 世界渲染、`FpsHud` / `FpsMenu` 界面、`FpsSkin` 皮肤、`FpsWidgets` 准星与目标指示、`FpsSim` 回放）。
`--package-project .` 使用当前主仓的 `packages/`；本模板没有素材目录（全部程序化）。生成的原生驱动文件应与程序保持在同一目录。
