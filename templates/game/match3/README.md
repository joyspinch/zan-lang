# Gem Cascade — Match-3 模板

基于 Zan.Game 三消底座 `Match3Board`（`packages/Zan.Game` 的 `Game.Match3`）做的完整三消游戏：
24 关关卡地图、四类目标、特殊宝石与组合技、提示与自动洗牌、1-3 星评价与存档。

## 玩法

- **交换**：点一颗宝石再点相邻宝石，或按住宝石往邻格拖。换完必须连成 3 个以上，否则宝石弹回、不扣步数。
- **特殊宝石**
  | 怎么做 | 得到 | 效果 |
  |---|---|---|
  | 横 / 竖 4 连 | 条纹宝石 | 引爆时清整列 / 整行（白色条纹 = 清除方向） |
  | L / T / 十字形 | 区域炸弹 | 炸掉 3x3 |
  | 5 连 | 彩色炸弹 | 和任一宝石交换：清掉该颜色全部宝石 |
- **组合技**（两颗特殊宝石互换）：条纹+条纹 = 十字；条纹+区域 = 三行三列；区域+区域 = 5x5；
  彩色炸弹+条纹/区域 = 该颜色全部变成条纹/区域炸弹再一起引爆；彩色炸弹+彩色炸弹 = 清空全盘。
- **连锁**：掉落产生的新消除逐级加倍计分，第 2 级起中央弹出 SWEET / GREAT / AMAZING / INCREDIBLE / DIVINE。
- **提示与洗牌**：5 秒不操作，评估最好的一步并让两颗宝石发光；盘面无棋可走时自动洗牌（SHUFFLE!）。
- **过关奖励**：目标达成后剩余步数逐步兑换成分数（GEM RUSH，每步 +150）。

## 关卡与进度

24 关（`src/Match3Levels.zan`），每关有步数上限与一个目标：

| 目标 | 说明 | 关卡 |
|---|---|---|
| 计分 | 在步数内达到目标分 | 1 3 7 12 16 22 |
| 收集 | 收集 N 个指定颜色（最多 3 色） | 2 5 9 13 17 20 |
| 果冻 | 消除压在果冻格上的宝石；粉色厚果冻要两次 | 4 8 11 15 18 21 24 |
| 木箱 | 木箱会随重力下落，旁边消除或被特效击中才会碎；铁箍箱要两下 | 6 10 14 19 23 |

难度曲线：1-6 关 5 色盘面、每关只教一件事（关卡提示条写在棋盘下方）；7 关起 6 色，步数收紧、障碍叠加。
星级：达成目标 = 1 星，分数到 2 星 / 3 星线再加星（线由平衡机器人调出，见下）。
第 N 关拿到至少 1 星解锁第 N+1 关。

存档 `GameProfile.Open("match3")`：每关最高星 `stars_<n>` 与最高分 `score_<n>`（`SubmitBest`），
总局数 `plays`、过关数 `clears`（`Counter`），静音 `muted`（`Flag`）。位置：

- macOS：`~/Library/Application Support/ZanGames/match3/`
- Windows：`%LOCALAPPDATA%\ZanGames\match3\`
- Linux：`~/.local/share/ZanGames/match3/`

设置环境变量 `ZAN_GAME_DATA_DIR` 可改根目录（测试/便携版）。

## 界面流程

标题（特殊宝石说明、总星数）→ 关卡地图（蜿蜒路径上的 24 个关卡按钮，已得星数、目标图标、
下一关高亮）→ 开局横幅（关卡号 + 目标 + 步数）→ 对局（左 MOVES、中 GOAL 图标与剩余数、
右 SCORE 与 2/3 星刻度进度条）→ 暂停（继续 / 重开本关 / 回地图）→ 结算（星星逐颗弹出、
光芒与彩带、本关最高分、最长连锁与特殊宝石数；下一关 / 重玩 / 地图）。

所有面板、按钮、标签、进度条都是标准 Gui 控件（Panel / Label / Button / Progress），
皮肤在 `src/Match3Skin.zan`（夜紫玻璃面板 + 金边 + 金色主按钮，悬停 / 按下 / 焦点 / 禁用全有样式）。
画布只画场景美术：星空背景、金边棋盘、果冻、木箱、宝石、特效、地图路径与星星图标。

## 操作

| 按键 / 操作 | 作用 |
|---|---|
| 点宝石再点邻格 / 按住拖向邻格 | 交换 |
| 标题点任意处 / `Enter` | 进入关卡地图 |
| 地图点关卡 / `Enter` | 开始该关 / 开始下一关 |
| `P` / `Esc` | 对局中暂停 / 继续 |
| 结算 `Enter` | 下一关（失败时重试） |
| 结算 / 地图 `Esc` | 回地图 / 回标题 |
| 标题 `Esc` | 退出 |
| `M` 或右上 SOUND 按钮 | 音效开关（持久保存） |

调试（默认关闭）：`MATCH3_DEBUG=1` 解锁全部关卡并启用 `D`（在盘面放几颗特殊宝石）与
`W`（立即达成目标，看结算）、`L`（步数归零，看失败结算）；`MATCH3_SEED=<n>` 固定盘面随机种子（截图 / 复现）。

## 源码分工

| 文件 | 职责 |
|---|---|
| `Match3Game.zan` | 规则 + 相位机（交换 → 弹出 → 下落 → 连锁 → 收尾）、特殊宝石、木箱 / 果冻、目标与星级、提示、洗牌 |
| `Match3Levels.zan` | 24 关数据与目标文案 |
| `Match3Fx.zan` | 粒子、光束、冲击环、闪电、飘字、连锁大字、震屏（纯表现，独立随机源） |
| `Match3Painter.zan` | 棋盘场景美术与特效绘制 |
| `Match3Scenes.zan` | 标题 / 地图 / 结算星星的场景美术，HUD 里的目标图标 |
| `Match3Hud.zan` / `Match3Skin.zan` | 标准控件外壳、流程、音效、存档 / 皮肤 CSS |
| `Match3Sim.zan` | 无头仿真、`[Invariant]` 规则、模糊测试机器人 |

格子编码：`颜色 | 特殊 << 4 | 木箱血量 << 8`（颜色 1-6 宝石、7 木箱、8 彩色炸弹；特殊 1 横条纹、2 竖条纹、3 区域炸弹）。
`Match3Board` 负责存盘、交换、相邻判断与重力压缩，模板在其上加特殊宝石与障碍规则。

## 回放与确定性

`src/Match3Sim.zan` + `replays/bot.replay` 是无头回归：仿真驱动同一个 `Match3Game`（含动画相位，
按固定步长推进），不碰音频、存档、时钟与窗口。音效由规则层抛出 `sfxMask`，界面层（`Match3Hud`）
每帧取走播放。不变量：步数范围、分数非负且只增、果冻 / 木箱只减、静止盘面必有合法步且无现成三连、
计数与盘面一致、格子编码合法。机器人既乱换（测无效交换）也照提示走（攒特殊宝石、触发连锁），偶尔换关。
改了规则就按 `Game.Foundation` README 重录 `replays/bot.replay`。

## 平衡

关卡曲线用无头机器人在每关 40 个种子上调：随机合法步（新手）、一半随机一半最佳（普通）、
总走提示最佳步（熟手）。熟手胜率 1-6 关 100%，中段 77-100%，后段 60-95%；普通玩家后段 35-87%。
2 星线 ≈ 熟手中位分，3 星线 ≈ 熟手 75 分位 x1.12。
