# 围住神经猫

回合制解谜：点击圆点种一丛灌木（或一段篱笆）封路，每封一个点，猫沿逃生路线走一步。猫到达棋盘边缘就逃脱；切断所有通向边缘的路线即可获胜，即使猫身边仍有空点。

## 两种玩法

- **闯关（30 关）**：三章——后院、花园、屋顶，每章换一块场景底图和一套开局障碍（石头 / 花盆 / 烟囱）。每关是固定开局（第 1、2、3、10、20、30 关是手绘的环形图案，其余是挑过的种子），有**篱笆预算**（用完还没围住，猫就大摇大摆走掉）和**三星步数线**（HUD 上的 `★★★ ≤N · ★★ ≤M`）。通关解锁下一关；每关最佳星数与解锁进度存档。
- **无尽**：轻松 / 经典 / 挑战三档随机开局（18 / 12 / 6 个障碍），不限篱笆，按难度记胜场、连胜和最少步数。

## 猫越来越聪明

| 关卡 | 猫 | 规则 |
|---|---|---|
| 1–5 | 直奔出口 | 沿最短路走，等长路线随机挑 |
| 6–14（及无尽·挑战） | 会挑岔路 | 仍走最短路，但在等长路线里挑“下坡岔路”最多的一格，一刀切不断 |
| 15–20 | 会算两步 | 两步前瞻：对每个可去的格子，假设你接着封住最要命的一格，挑最坏情况最好的那条路（可能绕远） |
| 21–30 | 会蹦两格 | 在“会算两步”之上，每 5（后期 4）回合一口气蹦两格；蹦之前头顶冒橙色“!”，状态栏也会提醒 |

## 提示

每局 2 次提示（`H` 或“提示”按钮）：逐格试封、用真实规则让猫回应、按局面评分，把最好的一格用闪光圈和小箭头标出来。闯关中用过提示，本关最多两星。

## 画面与手感

- 木框里铺一块草坪（花园章节更多小花，屋顶章节是一排排屋瓦），带修剪条纹、草丛和暗角；木框用 `assets/cell.png`，标题图标与结算卡头像用 `assets/icon.png`。
- 玩家种下的灌木/篱笆带回弹缩放弹出并飞出几片叶子；开局障碍按章节画成石头、花盆或烟囱。道具与小猫同一套描边和配色，SVG 按尺寸缓存成位图。
- 小猫由 SVG 绘制：待机摇身、举爪、甩尾、眨眼；走格小跳 240 毫秒，猛扑两格时跳得更高。**逃脱**时冲出棋盘扬起尘土；**被围住**时闭眼坐下——紧贴一圈全封就落下一只笼子（弹跳落地），被圈在一片区域里则冒出爱心。
- 胜负后约 0.9 秒弹出结算卡：闯关胜利显示三颗星（逐颗弹出）和满屏彩纸，按钮是“重玩 / 选关 / 下一关”；失败给“选关 / 重玩 / 悔一步”。
- 点到已封点或猫会红圈抖动 + 提示音；篱笆剩 ≤2 道时 HUD 篱笆数变红，状态栏变成提醒色。
- 圆点、芯片、按钮、选关格都是标准 GUI 控件，常态 / 悬停 / 按下 / 焦点 / 禁用都在 `TrapCat.html` 的 CSS 里配成同一套奶油、木色、叶绿的风格。

## 纪录与存档

- 闯关：每关最佳星数（`camp.stars.<关>`）、已解锁到第几关（`camp.unlocked`）、上次停在哪一关（下次启动直接回到那一关）。
- 无尽：每个难度分别记胜场、当前连胜/最佳连胜、最少几步围住猫；刷新最少步数（或最佳连胜 ≥2）时出现 NEW BEST。
- 每局只结算一次——胜负后悔棋可以复盘，但不会重复计分；无尽模式中途换局算放弃，连胜清零。
- **音效**（程序化合成，无音频文件）：种灌木、无效点击、猫跳一格、猛扑、提示、结算星星、围住、逃脱、篱笆用完、悔棋、开新局各有一声。没有音频设备时静默。

## 操作

| 操作 | 按键/点击 |
|---|---|
| 种灌木封路 | 点击空圆点 |
| 提示 | `H` 或“提示”按钮 |
| 悔一步 | `U` / Backspace 或“悔一步” |
| 重新开始 | `N` 或“再来一局 / 重玩本关” |
| 选关 / 返回 | “闯关 ★”芯片；`Esc` 返回 |
| 结算卡主按钮 | `Enter` |
| 静音开关 | `M` 或右上角“音效”按钮 |

回合制，没有暂停（不需要：猫只在你落子后才动）。小跳期间仍接受下一次封路，精灵从当前视觉位置继续移动，快速点击不会被动画吞掉。

## 平衡

关卡表 `src/TrapCatLevels.zan` 由无头机器人生成：求解机器人每步采纳 `TrapCatBoard.Hint()`，它围住猫用的步数就是三星线，预算在此基础上留 3–4 道余量；再用一个“七成照提示、三成随手封猫附近”的普通玩家机器人多次试玩，挑出胜率随关卡从约九成逐步降到三成左右的开局。改了猫的规则或提示评估，要重跑平衡再改这张表。

调试：`ZAN_TRAP_CAT_UNLOCK=1` 解锁全部关卡，`ZAN_TRAP_CAT_LEVEL=<1..30>` 直接开某一关（都默认关闭，便于截图与验收后期关卡）。

**存档位置**：`Game.Foundation.GameProfile.Open("trap-cat")`，即用户应用数据目录下的
`ZanGames/trap-cat/`（macOS `~/Library/Application Support`、Windows `%LOCALAPPDATA%`、Linux
`~/.local/share`）；设 `ZAN_GAME_DATA_DIR` 可改根目录。不写工作目录。UI 自动化脚本
（`ZAN_UI_SCRIPT`）在未指定 `ZAN_GAME_DATA_DIR` 时使用内存档案，回归不会改写玩家纪录。

在 ZanIDE 的“新建项目 → 游戏 → 围住神经猫”中创建项目后运行。项目配置不固定操作系统目标。

生成项目中的命令行构建：

```powershell
New-Item -ItemType Directory -Force build | Out-Null
zanc src/{{NAME}}.zan src --auto-stdlib -o build/{{NAME}}.exe
.\build\{{NAME}}.exe
```

Android ARM64 APK 构建（需要 Android SDK、NDK 和 JDK）：

```powershell
zanc src/{{NAME}}.zan src --auto-stdlib --publish --embed src/TrapCat.html=src/TrapCat.html --target android-arm64 --emit-apk build/{{NAME}}.apk --apk-package com.zan.trapcat --apk-label "围住神经猫" -o build/{{NAME}}.so
```

Android 使用竖屏实际客户区，隐藏桌面标题栏；字体跟随设备 DPI，棋盘按屏幕逻辑宽高切换尺寸。`Form.Create` 的 600×760 用于桌面初始尺寸和 Android 竖屏方向，不会把手机表面限制为 600×760。APK 使用工具链自动生成的调试签名。

入口 `.zan` 排在首位，`src` 递归纳入其余 Zan 源码。`TrapCat.html` 在开发时从项目目录读取，发布时以程序读取的逻辑名 `src/TrapCat.html` 内嵌。

**底图怎么接的**（`src/App.zan` 的 `SetupArt`）：`assets/cell.png`（木框）与 `assets/icon.png`（图标/头像）用
`Game.Kit.Assets.Find` 定位（以 exe 目录为锚向上找 4 级），找到就写进
对应 `<img>` 的 `Src`，找不到就把这个 `img` 藏掉。草坪由 `TrapCatGarden` 插在木框与圆点之间绘制。**引擎的 CSS 背景
不支持 `url()`**（只有颜色与线性渐变），所以底图只能用 `<img>` 元素叠在
棋盘底下，不能写 `background-image`。

`src/TrapCatBoard.zan` 负责规则、BFS 寻路、猫的四档 AI、提示与撤销记录；`src/TrapCatLevels.zan` 是 30 关关卡表；`src/TrapCatSim.zan` 是回放仿真；`src/App.zan` 在生成时改名为项目名，负责事件、界面状态、档案与音效；`src/TrapCat.html` 负责布局和样式；`src/TrapCatSprite.zan` 负责小猫的矢量造型和动画；`src/TrapCatFx.zan` 是场景美术层（草坪、灌木、笼子、粒子、彩纸）。猫的随机选择以回合数派生种子，悔棋后重复同一步会保持猫的走法。

可通过环境变量 `ZAN_TRAP_CAT_SEED` 指定整数种子，复现随机开局。仓库内规则测试在 `tests/templates/trap-cat/board_test.zan`，GUI 点击回归在同目录的 `gameplay.ui`；模板创建、编译与发布验收使用：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/e2e_pipeline.ps1 -Only trap-cat
```
