# Survivor Roguelite 割草模板

吸血鬼幸存者式的割草肉鸽：在一张 3600×3600 的墓野里走位求生，武器全自动开火，
捡经验宝石升级，每级三选一强化构筑；怪潮组成随时间变化，3:00 与 6:00 各有一只首领。
世界全部是 Canvas 程序化绘制，界面全部是标准 Gui 控件换上本作皮肤。

## 玩法

- **五把武器（各 4-5 级）**：电弧弹（自动瞄准，第二发起优先打精英/首领，3 级起穿透）、
  回旋刃（绕身旋转的刀片）、圣域光环（灼烧并减速范围内的怪）、风暴链（落雷并在敌人间跳跃）、
  飞轮（掷出后折返、全程穿透）。
- **四种被动（各 5 级）**：疾行靴（移速 +10%）、磁石（拾取范围 +40%）、生命之心（最大生命 +20 并回血）、
  沙漏（武器冷却 -8%）。武器与被动各 4 格；全部满级后卡池给回血药。
- **升级三选一**：升级时世界冻结，弹出三张卡（标准 Button/Label/Image 拼成，依次弹入）。
  `1/2/3` 直接选，`←/→` 或 `A/D` 移动高亮、`Enter/Space` 确认，也可以鼠标点；
  弹入的 0.3 秒内不接受选择，防止走位时连按误选。卡面写明 NEW / 下一级、效果与等级刻度。
- **怪物**：食尸鬼（基础）、蝙蝠（快、蛇形绕飞）、蛮兵（血厚、抗击退）、吐酸怪（保持距离，蓄力后吐酸弹）、
  自爆怪（贴身后点燃引信，地面橙圈预警；被你打死会殉爆伤到周围的怪）、
  恐惧骑士（精英：蓄力时地上画出红色冲锋道，随后高速冲锋；掉回血心）、
  首领骸骨巨像（3:00）/ 深渊守望（6:00）：红圈预警的跃击砸地、环形弹幕，守望还会召唤蝙蝠；击杀掉宝箱（额外升级 + 回满血）。
- **波次**：0:40 前只有食尸鬼，之后依次加入蝙蝠、吐酸怪与蛮兵、自爆怪；0:55 蝙蝠群、2:30 亡者合围、
  4:30 大蝙蝠群、5:30 自爆潮等固定事件，6 分钟后精英/蝙蝠群/蛮兵合围轮流出现；
  怪物血量随时间增长，7 分钟后怪潮越来越快。
- **掉落**：经验宝石按价值分蓝/绿/红，进入拾取圈后先轻弹开再加速吸入（带拖尾）；稀有掉落回血心与磁石（吸全图经验）。

## 进度与解锁（GameProfile）

`GameProfile.Open("survivor")`：最好存活秒数 `time`、最多击杀 `kills`、最高等级 `level`，
计数 `plays`、`kills_total`、`bosses_total`、上次选的角色 `hero`，开关 `muted`。

| 角色 | 解锁 | 特点 |
|---|---|---|
| RANGER | 默认 | 100 HP，开局电弧弹 |
| WARDEN | 单局存活 3:00 | 130 HP、较慢，开局回旋刃 |
| MYSTIC | 单局存活 6:00 | 85 HP、较快、拾取范围更大，开局风暴链 |

结算页显示存活时间、击杀、等级、首领击杀、用过的每把武器的等级与总伤害，以及新纪录 / 新角色解锁。

## 操作

| 按键 | 作用 |
|---|---|
| `W A S D` / 方向键 | 移动 |
| `1` `2` `3` / `←` `→` + `Enter` | 升级选卡（也可鼠标点卡） |
| `Enter` / `Space` | 标题页开始；结算页再来一局 |
| `←` `→` / `1` `2` `3` | 标题页选角色（锁定的不可选） |
| `P` / `Esc` | 对局中暂停 / 继续（失焦自动暂停） |
| `R` / `Q` | 暂停时重开 / 回到标题 |
| `Esc` | 结算页回到标题；标题页退出 |
| `M` | 音效开关（记住设置） |

## 表现

- 世界：苔石地面（大块明暗斑 + 草丛、碎石、裂缝、符文圈、骸骨，按世界格子哈希摆放）、石墙立柱的世界边界、
  上下暗角与低血量红色脉动；相机平滑跟随并钳在世界内。
- 角色与怪物：描边剪影、落影、走路摆动、受击闪白；首领跃击有腾空弧线与落点红圈，精英有冲锋道预警。
- 特效：电弧弹拖尾、回旋刃轨迹残影、光环符点、链状闪电、飞轮旋转、爆炸冲击环、死亡碎片、升级光环爆发、
  伤害跳字（暴击金色、受伤红色、回血绿色）、震屏与顿帧。
- 界面（`SurvivorHud` / `SurvivorCards` / `SurvivorMenu`，图标是 `SurvivorIcons` 里的 SVG，交给标准 `Image`）：
  顶部经验条、计时、等级、击杀；左上武器 4 格 + 被动 4 格图标行（等级角标，满级 MAX）；首领血条；公告横幅；
  角色脚下血条；蛮兵/精英头顶血条。
- 音效（`SfxBank` 程序化合成）：射击、命中、击杀、宝石、电弧、爆炸、拾取、升级、首领登场、受伤、阵亡、界面。

## 源码分工

| 文件 | 内容 |
|---|---|
| `SurvivorData.zan` | 武器/被动/角色/怪物数值表与实体类、配色工具 |
| `SurvivorGame.zan` | 玩家、经验与三选一、波次与事件、相机、调试快进 |
| `SurvivorCombat.zan` | 武器、怪物 AI、伤害/死亡/掉落、粒子推进 |
| `SurvivorRender.zan` | 世界绘制（只读逻辑状态） |
| `SurvivorHud.zan` `SurvivorCards.zan` `SurvivorMenu.zan` `SurvivorIcons.zan` | HUD、升级卡、标题/暂停/结算、矢量图标 |
| `SurvivorSim.zan` | 无头回放仿真、`[Invariant]`、Bot |
| `main.zan` | 外壳：状态机、存档、音效 |

调试捷径（默认关闭）：`SURVIVOR_DEBUG_WARP=秒,等级` 让新开的一局直接快进（用于截取后期/首领画面），
`SURVIVOR_DEBUG_LEVELUP=1` 开局即弹出升级卡。

## 回放与确定性

`src/SurvivorSim.zan` 以固定 1/60 秒一帧无头推进 `SurvivorGame`（宿主同样用 16ms 固定步长），所有随机来自种子
（玩法随机与纯表现粒子随机分两条流）。种子 `% 4 == 2/3` 的场景会快进到 2:50 / 5:50，
让 2000 帧的模糊测试也能碰到首领、跃击与后期怪潮；输入 `17/18/19` 表示选第 1/2/3 张升级卡，Bot 会随机选卡。
不变量覆盖：玩家在世界内、血量范围、阵亡当且仅当血量归零、经验余数、选卡状态自洽、构筑合法（等级与槽位）、
卡面不出现满级/重复项、对象池有上界、首领槽位有效。
`replays/bot.replay` 由 `zan-check` 重放比对；改了数值或刷怪后按 `Game.Foundation` README「Replays are regression tests」重录。

## 运行与编译

在主仓根目录：

```powershell
Set-Location D:/project/zan-lang
& ./scripts/build_gate.ps1 -Name build -Script {
    build/zanc.exe templates/game/survivor/src/main.zan templates/game/survivor/src --auto-stdlib --package-project . --publish --subsystem windows -o build/survivor.exe
}
build/survivor.exe
```

`main.zan` 必须排在首位，随后 `src` 目录递归纳入其余源码。本模板没有素材目录（全部程序化绘制 + 内联 SVG 图标）。
生成的原生驱动文件应与程序保持在同一目录。
