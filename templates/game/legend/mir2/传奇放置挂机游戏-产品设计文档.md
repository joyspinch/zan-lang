# 《传奇放置挂机》产品设计文档（PRD）

> 本文档基于竞品（某传奇类放置挂机页游/端游）31 张实际运行截图逆向拆解而成，目标是完整复刻其系统框架与玩法矩阵，并可直接作为自研项目的立项与开发依据。
> 文档中带【竞品实测】标记的数值为截图中观察到的真实数值，可作为数值设计的锚点参考；带【设计建议】标记的内容为补齐性设计。

---

## 1. 产品概述

### 1.1 产品定位

- **品类**：传奇 IP 风格 · 数值放置类 · 多人同服网页/微端游戏。
- **核心卖点**：离线挂机自动成长 + 传奇经典情怀（沙巴克、屠龙、祖玛、赤月）+ 重度数值养成 + 强社交强 PK。
- **形态特征**（竞品实测）：
  - 面板式 UI（非大地图漫游），所有玩法以功能面板承载，开发成本低、信息密度高；
  - 支持"开始挂机后关闭客户端离线挂机"，本质是**服务器端演算的放置游戏**；
  - 提供"老板键 F10"一键隐藏、界面缩放 80%~300%、静默战斗模式——明确服务于**上班族桌面挂机**场景。

### 1.2 目标用户

| 用户层 | 画像 | 核心诉求 | 对应系统 |
|---|---|---|---|
| 情怀玩家 | 30~45 岁男性，玩过端游传奇 | 沙巴克、屠龙、祖玛地图情怀 | 地图、沙巴克、装备命名 |
| 放置用户 | 时间碎片化的上班族 | 不肝、离线也变强 | 离线挂机、老板键、自动战斗 |
| 数值玩家 | 喜欢研究公式与最优解 | build 深度、优化快感 | 符文之语、系数洗炼、帮助-公式算法 |
| 攀比/大 R | 追求服务器地位 | 排行榜、称号、全服广播 | 排行榜、爵位、至尊极品殿堂、红包 |

### 1.3 核心体验三支柱

1. **躺着也变强**：离线挂机结算、自动挑战 BOSS、自动重置幻境层数。
2. **上线有决策**：上线后做"分配型决策"——洗炼、镶嵌、捐献、挑战、掠夺，而非操作型劳动。
3. **变强被看见**：全服广播掉落、排行榜实时看装备、称谓/爵位/殿堂展示。

### 1.4 核心循环

```
        ┌──────────────────────────────────────────────┐
        │            离线/在线挂机（幻境·秘境）            │
        │   自动打怪 → 金币/经验/装备/材料/符文掉落          │
        └──────────────────┬───────────────────────────┘
                           ▼
        ┌──────────────────────────────────────────────┐
        │              上线收菜 + 分配决策                 │
        │  回收/洗炼/镶嵌/图鉴/五行/称谓/捐献/合成符文之语    │
        └──────────────────┬───────────────────────────┘
                           ▼
        ┌──────────────────────────────────────────────┐
        │            数值验证（PVE + PVP）                 │
        │  推层(幻境6000+层)/世界BOSS/PK场/传说塔/沙巴克/押镖 │
        └──────────────────┬───────────────────────────┘
                           ▼
        ┌──────────────────────────────────────────────┐
        │        社交反馈（广播/排行/称号/掠夺恩怨）         │
        └──────────────────┬───────────────────────────┘
                           └──→ 回到挂机（更强 → 更快）
```

## 2. 功能总览（主界面功能矩阵）

竞品主界面为"上下两排功能入口 + 左侧角色面板 + 右侧聊天栏 + 左下信息流"结构，共 **30 个一级功能入口**：

**顶排（战斗/玩法类）**：地图传送、PK 竞技场、幻境、BOSS 之家、押镖、行会、沙巴克、城池争夺、传说塔、排行榜
**二排（养成/活动类）**：五行修炼、师徒、秘境、世界 BOSS、祭坛、寻宝、将星图谱、回收系统、发红包、至尊极品殿堂
**底排（基础系统类）**：背包、铁匠铺、交易市场、图鉴、爵位、称谓、成就、商店、帮助、邮箱
**其他**：设置（偏好/挂机过滤/改名/界面风格/仓库命名/转永久区）、角色面板（升级/每日福利/充值/刷新）、战斗统计、聊天（世界/行会频道）。

> 【设计建议】该矩阵即本项目的**一级功能清单**，可按本文第 16 节的优先级分期实现。

## 3. 角色基础系统

### 3.1 职业与属性

- **三职业**：战士 / 法师 / 道士（对应攻击 / 魔法 / 道术三系）。
- **属性面板**（竞品实测）：生命、法力、攻击（区间值 937-25822）、魔法、道术、防御、魔防、幸运（+9 为满）、速度、经验加成。
- 属性为**区间值**（最小-最大），保留传奇原汁原味的伤害浮动体验。

### 3.2 等级与转生

- 等级上限以"巅峰 N 级"表示，竞品实测顶级玩家为 **巅峰 1500 级**；
- **转生**共 9 转（图鉴卡牌以 0 级~9 转分档；个人 BOSS 出现"七转守卫 180 级"）；
- 转生是核心里程碑：解锁秘境（"巅峰人物才能挑战秘境"）、收徒（师父条件 2 转）、传说装备等。

### 3.3 角色面板要素

头像、称谓、行会、会员标识（黄金 VIP 徽记）、经验条、生命/法力/声望/战功/等级/灵符/金币/元宝，按钮：升级、每日福利、充值、刷新。

## 4. 核心挂机系统（产品基石）

### 4.1 幻境（主挂机推层图）

- **层数制推图**：幻境第 N 层，竞品实测榜首 **6043 层**；每层清怪后出现"本关 BOSS"，首次击杀过关进下一层。
- **自动战斗**：自动寻怪、自动拾取、自动重置（勾选后死亡/卡层自动处理）。
- **挑战幻境 / 扫荡幻境**：扫荡为**终身会员特权**（重要付费点）。
- **掉落展示墙**：界面下方实时展示本层掉落的装备/符文/号角等，形成持续视觉奖励流。
- **幻境排行榜**：按层数排名，全服公示。
- 离线日志示例（竞品实测）："你在【银杏小村】战斗了 24 时 00 分 00 秒，消灭了 17280 个怪物"——即 **5 秒/怪** 的离线战斗节拍，24 小时满结算。

### 4.2 秘境（高阶挂机推层图）

- 解锁条件：巅峰等级（"巅峰人物才能挑战秘境"），竞品实测榜首 1650 层。
- 掉落品质显著高于幻境（掉落墙出现 +1~+6 系数彩色装备）。
- 同样支持自动/挑战/扫荡/自动重置。
- 【设计建议】幻境=全生命周期主图，秘境=转生后第二成长曲线，两图错位投放不同材料，避免单图疲劳。

### 4.3 离线挂机与结算

- "开始挂机后，可以关闭客户端，离线挂机"——服务器端计时演算。
- 结算产出：经验、金币、装备、强化材料（强化攻击/魔法/道术/生命/防御 ×N）、木剑×326、声望、经验等批量入账，并提示"背包已满，部分道具没有获得"（**背包容量=付费扩容点**）。
- 挂机设置：装备过滤（只保留总系数≥N）、保留天数/保留等级过滤、静默模式、空闲警告。

### 4.4 地图传送（情怀地图池）

20 张经典传奇地图分两页：银杏小村、比奇省、沃玛森林、半兽人古墓、废弃矿洞、未知暗殿、沃玛寺庙、死亡棺材、祖玛寺庙、霸者大厅、赤月峡谷、重装之家、魔龙岭、牛魔寺庙、骨魔洞窟、圣域回廊、镇魔神殿、盘古之地、上古战场、诛仙伏魔殿。
【设计建议】地图作为**挂机场景皮肤 + 怪物/掉落主题包**使用，不承担导航功能，低成本复用情怀资产。

## 5. BOSS 体系（三层结构）

### 5.1 BOSS 之家（个人 BOSS）

- BOSS 序列（竞品实测）：沃玛教主 25 级 → 祖玛教主 35 → 赤月恶魔 45 → 魔龙教主 70 → 牛魔王 80 → 一转守卫 80 … 七转守卫 180 级，共 3 页。
- **挑战次数限制**（"剩余 BOSS 挑战次数：0"），次数为稀缺资源，可通过充值/礼包补充。
- 支持自动挑战、结束后自动挑战下一 BOSS。
- 奖励预览前置展示（符文、元宝等），先看见奖励再付费买次数。

### 5.2 世界 BOSS（全服共斗 + 伤害竞赛）

- 全服共享血量池，竞品实测 **100 亿 HP**（2554900892/10000000000）。
- 右侧实时**伤害排行榜**（次数 + 伤害额），按贡献结算奖励。
- 挑战次数限制（实测剩余 6 次）。
- 【成瘾点】合作外壳下的竞争内核：打得多=拿得多=榜上有名。

### 5.3 层 BOSS（幻境/秘境守关）

- 每层首杀过图，天然形成"再打一层就睡"的睡前钩子。

## 6. PVP 系统

### 6.1 PK 竞技场（异步天梯）

- 挑战排行榜玩家；胜 +100 战功，负 +20 战功（**败者安慰奖**降低挫败）。
- 排名小时薪：第 1 名 1000 战功/小时，第 2 名 800，第 3 名 600，第 4 名 500，5-8 名 400，9-50 名 300，51-100 名 200；**精确到分钟结算，低于一分钟无法领取**（竞品实测规则）。
- 挑战次数限制（实测 0 次）→ 次数即付费点。

### 6.2 传说塔（爬塔抢位 PVP）

- 塔分多层（一层~五层+塔顶），每层守关者为**真实玩家镜像**。
- 挑战次数 0/10 每日限制；逐层挑战上位，形成"塔位"争夺。
- 【设计建议】塔位=荣誉位+少量属性，被挑战者有"被攻擂"推送，制造回访触发。

### 6.3 沙巴克（行会攻城战）

- 固定开战时间（竞品实测 08-09 18:00），行会申请攻沙排队列表。
- 占领奖励：宝石、技能书、金币、黑铁、金砖、魂灵等；战役中随机掉落：祝福油、金砖、100 元宝等。
- 占领公会与占领时间公示；全服可"膜拜沙巴克城主"（城主荣誉感设计）。
- 战役日志留档。

### 6.4 城池争夺 / 钱庄（领土产出）

- 8 座钱庄（钱庄 1~8），占领后 **每小时产出金币**（实测：攻击条件金币×50 万，产出 50 万/小时递增高阶池）。
- 申请攻打需缴纳费用，费用部分注入钱庄池；城主更替时池内资源结算给前任城主（邮件发放）。
- **每人最多占领一个城池**（稀缺性保障更多人有机会）。
- 【成瘾点】"收租"机制=每天必须上线护租/抢租的强回访钩子。

### 6.5 押镖 / 劫镖（日常 PVP 经济玩法）

- 每日押镖次数、劫镖次数双限制（实测均 0 次）。
- 镖车分品质（普通镖车…），右侧实时刷新其他玩家镖车列表，可"劫镖"。
- 【成瘾点】押镖=保底收益，劫镖=掠夺快感+恩怨社交，二者互锁。

## 7. 装备与锻造系统（数值核心）

### 7.1 装备槽与部位

12 槽位：武器、头盔、衣服、项链、手镯×2、戒指×2、腰带、鞋子、宝石/勋章类、天书等。装备对比显示、一键锻造、卖出。

### 7.2 系数与品阶（本游戏特色数值机制）

- 每件装备带**系数**（实测武器 +1~+10，天书系数 143/284），系数直接放大装备基础属性；
- 装备分**品阶/转生阶**（无阶不可入图鉴；巅峰之后装备用"符文之语洗阶"）；
- 回收/交易/图鉴/洗炼全部围绕"系数×品阶"二维品质体系运转——这是贯穿全游戏的装备语言，**必须一期实现**。

### 7.3 铁匠铺（锻造矩阵）

模式按钮（竞品实测 11 种）：
| 模式 | 功能 | 消耗 |
|---|---|---|
| 金币洗炼 | 重组系数，**有概率降低**（风险洗炼） | 金币（系数越高越贵） |
| 元宝洗炼 | 特殊洗炼（无风险/保底） | 元宝 |
| 幸运传承 | 幸运值转移 | 材料 |
| 升级锻造 | 装备升级 | 黑铁等 |
| 淬炼锻造 | 淬炼属性 | 材料 |
| 符文锻造 | 符文镶嵌/强化 | 符文 |
| 灵符锻造 | 灵符系强化（巅峰后洗阶入口） | 灵符 |
| 符文之语 | 传奇装备合成 | 符文#+矿石 |
| 龙珠锻造 | 形态成长 | 龙珠 |
| 天书传承 | 天书系数转移 | 天书 |
| 传说锻造 | 传说装备终极锻造 | 传说矿石等 |

- 材料仓格独立展示（黑铁、武器 fodder、天书），支持入库/加载/放入/整理/清空。
- 【成瘾点】金币洗炼的"有概率降低"=经典**可变比率强化**（赌博心理），元宝洗炼=付费保底，二者构成风险/付费双通道。

### 7.4 符文与符文之语（类暗黑 Rune Words）

- 符文 1#~14#（商店售 1#=100 元宝、10#=2000 元宝；交易市场玩家挂牌 1#=1 万金币）。
- 升级：3 个同符文合成高 1 级（1#+1#+1#=2#）；降级：2# 以上 = 黑铁矿石×10 换低 1 号。
- **符文之语公式**（竞品实测，帮助页公开）：
  - 传说武器 = 赤血魔剑 + 传说矿石×2000 + 13#
  - 传说男/女衣 = 城主战袍(男/女) + 传说矿石×2000 + 13#
  - 形态增长 = 传说装备[第一形态] + 龙珠 1★×100 + 13#（每形态需同等级龙珠×100 + 新 13#）
  - 最终传说 = 传奇黄[第九形态] + 龙珠 9★×100 + 13#
  - 传说洗炼 = 传奇黄[第九形态] + 传说矿石×2000 + 14#
  - 洗炼天赋区间：武器攻击天赋 50%-80%，男衣防御 30%-80%，女衣魔防 30%-80%
- 【设计要点】公式公开透明（帮助页可查）→ 数值玩家自发计算与传播，形成社区攻略生态。

### 7.5 神兵图鉴（装备收藏槽）

- 分组：祈祷、天玛、符玛、圣战、法神、天尊等（共 9 页分组），每组 10 槽。
- 规则（竞品实测）：
  1. 集齐组内要求装备激活对应属性；
  2. 放入后**无法取出**，只能以更高系装备替换（沉没成本+向上替换驱动）；
  3. 组品质取决于**最低品质**装备（木桶原理，逼玩家补齐短板）；
  4. 属性以被动加成计入人物；
  5. 无阶装备不可放入；
  6. 加成 = 系数×基数/10，各组基数不同；
  7. 巅峰后装备先洗阶再入图鉴（推荐洗到低于满系数 10 以内）。

### 7.6 至尊极品殿堂（全服装备标杆 + 复制经济）

- 仅收录全服**最好**的装备与天书（武器之攻/武器之法/武器之道/铠甲之首/头盔之首/项链之首/手镯之首/戒指之首…共 5 页）。
- 其他玩家可付**复制费**（10~100 灵符）复制该装备；武器与铠甲不可复制（保稀缺）。
- 登记一件装备 = **+5% 经验加成**（最高 50%）——把"晒装备"变成可量化的成长收益。
- 【成瘾点】顶级玩家=全服"装备偶像"，登记=名+利双收；普通玩家=付费抄作业，双向收费。

### 7.7 宝石 / 天书 / 内功 / 技能（背包四子页）

- 宝石：等级 N + 系数二维（二级宝石系数 4/6/7，交易价 5000 万~7000 万金币）。
- 天书：系数型道具（魔法天书系数 143、魔防天书系数 284），可传承。
- 内功：8 槽，0/100 级，TP 点升级。
- 技能：8 槽技能，升级消耗 TP/材料。

## 8. 角色成长线（八线并行）

> 设计原则：**任意时刻玩家至少有一条成长线"差一点就够"**，其余线"攒着攒着就成了"，制造永远有事可做的体感。

| # | 成长线 | 消耗 | 产出 | 节奏 |
|---|---|---|---|---|
| 1 | 等级/转生 | 经验 | 全属性、解锁系统 | 主线 |
| 2 | 技能/内功 | TP、材料 | 技能倍率 | 中频 |
| 3 | 五行修炼 | 五行材料注入 | 五维属性 | 离线时间制 |
| 4 | 称谓 | 声望+金币 | 固定四维 | 21 页超长线 |
| 5 | 爵位 | 元宝捐献 | 百分比全属性+速度+经验 | 付费线 |
| 6 | 将星图谱 | 图谱积分 | 气血天赋 %+ | 翻倍递增 |
| 7 | 神兵图鉴 | 装备填充 | 被动属性 | 收藏线 |
| 8 | 成就 | 行为达成 | 一次性奖励 | 引导线 |

### 8.1 五行修炼

- 金/木/水/火/土五槽，各挂一件五行装备，"升级/注入"材料；
- **修炼经验 + 修炼时间**：开始修炼后按时间累积（离线有效），典型的"时间池"放置子系统。

### 8.2 称谓（21 页称号天梯）

- 序列示例（竞品实测）：筑基一阶（声望 100/金币 10 万/1 级，攻 0-1）→ 筑基五阶 → 开光一阶~五阶 → 融合一阶（声望 1.4 万/金币 2050 万/1 转 40 级）→ 融合二阶（1.7 万/2400 万/1 转 50 级）…共 **21 页**。
- 每个称谓=永久四维加成；当前称谓外显。
- 【成瘾点】声望来自挂机与师徒，金币来自挂机，**纯挂机即可推进的超长免费天梯**=零付费玩家的生命线。

### 8.3 爵位（捐献百分比线）

- 男爵→子爵→伯爵→侯爵→公爵→亲王（竞品实测顶档：全属性各 +20%、速度 +10%、经验 +50%）。
- 消耗：元宝累计捐献（沉没型，不返还）。
- 【商业化要点】百分比属性在后期数值爆炸时价值同步爆炸，是**大 R 的必买线**。

### 8.4 将星图谱（收集激活卡）

- 主题卡池：古代美女、上古神剑、十大神器、三国演义、水浒传、英雄联盟、王者荣耀、待开放（竞品实测，多 IP 混搭，自研时需换用自有/无 IP 素材）。
- 每张卡按转生阶分档（0 级~9 转），激活费**翻倍递增**：1 万→2 万→4 万→8 万→16 万→32 万→64 万→128 万→256 万→512 万。
- 产出：气血天赋 +1%~+10%。
- 图谱积分作为统一消耗货币。

### 8.5 成就

- 分类：等级奖励、累计充值、幻境奖励、推图、属性-攻/魔/道/防/魔防、推广、挑战 BOSS。
- 每条成就=条件+多格奖励（金币/经验/材料/元宝），手动领取（保留"点击领奖"的仪式感）。

## 9. 社交系统

### 9.1 行会

- 创建条件：沃玛号角 + 500 万金币（竞品实测）。
- 规模 48 人起，行会等级提升上限与"等级上限"特权（实测高级行会成员等级上限 500/600 级）。
- 行会资产公示；行会排名 13 页。
- 行会承载：沙巴克、城池争夺、行会聊天。

### 9.2 师徒

- 条件：拜师等级 ≤60；收徒需 80 级；师父资格 2 转（竞品实测）。
- 师父活跃度 0/100：师父每次挑战幻境/世界 BOSS 增加活跃度；满 100 徒弟可领取**储备经验翻倍**（最高 400 万升级经验）。
- 徒弟每升 1 级师父得声望；终身会员（小龙女）2 倍、超级终身会员（大龙女）3 倍。
- 徒弟出师送大量**寻宝图**（超级终身会员徒弟更多）——把师徒关系直接接入寻宝经济。
- 单方面解除关系 24 小时冷却。
- 师父排行榜公示徒弟数（实测榜首 53 徒弟）。

### 9.3 聊天 / 广播 / 红包

- 频道：世界、行会；右侧常驻聊天栏。
- 系统广播：全服掉落广播（"玩家[万万]在幻境第 2001 层击杀 BOSS 获得 100 元宝×1"）——**高频刺激付费欲望的橱窗**。
- 发红包：玩家间元宝红包，可设置"不允许自动弹出红包"。

### 9.4 邮箱

- 附件 8 格、一键领取、清空已领、领取前背包空间校验提示。承担：城主结算、活动补偿、成就溢出等所有异步发放。

## 10. 经济系统

### 10.1 货币矩阵

| 货币 | 主要来源 | 主要消耗 |
|---|---|---|
| 金币 | 挂机、回收、钱庄产出 | 洗炼、称谓、创建行会、攻城费 |
| 元宝 | 充值、BOSS、回收 | 爵位捐献、特殊洗炼、商店、红包 |
| 声望 | 挂机、师徒、回收 | 称谓 |
| 战功 | PK 竞技场 | 【建议】战功商店 |
| 灵符 | 充值/活动/回收 | 灵符锻造、殿堂复制 |
| 红包 | 回收/玩家红包 | 商店兑换 |
| 积分 | 回收 | 积分商店 |
| 推广币 | 推广拉新 | 商店 |
| 寻宝图 | 签到/出师/活动 | 寻宝 |
| 图谱积分 | 图鉴行为 | 将星图谱激活 |
| 黑铁/传说矿石/龙珠 | 掉落/商店/礼包 | 锻造、符文之语 |

### 10.2 交易市场（玩家 C2C）

- 分类：全部/武器/防具/首饰/消耗类/杂物类/材料类/符文；过滤：寄售人/名称/加密。
- 金币计价自由挂牌；支持加密挂单；时长 499 天长期有效。
- 我的寄售 / 一键领取 / 重新上架；实测 **649 页**挂单——经济活跃度极高，说明**回收+交易**构成了健康的装备流转闭环。
- 【设计要点】C2C 让非 R 玩家"打金卖钱"，是传奇用户的核心留存动机之一。

### 10.3 回收系统（装备出口）

- 一件装备可选择回收为 7 种货币之一：金币 / 经验 / 战功 / 声望 / 红包 / 元宝 / 积分（竞品实测分类页）。
- 单价示例：屠龙=100 万金币，幸运雪莲=5000 万金币。
- 【设计要点】"一物七吃"让任何掉落都有价值感，**彻底消灭"垃圾掉落"的负反馈**。

### 10.4 商店

- 四货币页签：元宝 / 金币 / 推广币 / 灵符 + 激活码兑换。
- 商品示例（竞品实测）：改名卡 12800 元宝、大鹅峰矿礼包 30000、黄金钥匙 1000、秘境礼包 9888、幻境礼包 9888、黑铁矿石 1、符文 10# 2000、符文 1# 100、1000 元宝 1000、祝福油礼包 38000、仓库扩充卷 5000、新区礼包 1998、定风珠 1000、魂灵 12800、技能突破内丹 1000、金砖礼包 10800、灵石礼包 25800、超级祝福油 1998。

## 11. 商业化设计

### 11.1 会员体系（三档）

| 档位 | 特权（竞品实测散落各处） |
|---|---|
| 会员 | 基础标识 |
| 终身会员 | 幻境/秘境**扫荡**、每日签到 2 张寻宝图、师徒声望 2 倍 |
| 超级终身会员 | 每日 5 张寻宝图、师徒声望 3 倍、出师寻宝图加成 |

### 11.2 付费点全景

1. **效率类**：扫荡、离线结算上限、背包/仓库扩容（仓库 1~5 + 扩充卷）、挑战次数（BOSS/PK/爬塔/劫镖）。
2. **数值类**：爵位捐献、元宝洗炼（保底）、灵符锻造、殿堂复制、礼包（秘境/幻境/矿/灵石/金砖）。
3. **炫耀类**：改名卡、红包、称谓/爵位外显、会员徽记。
4. **博弈类**：寻宝图、黄金钥匙。
5. **激活码**：渠道/活动拉新兑换入口。

### 11.3 付费心理设计要点

- **先体验后付费**：个人 BOSS 奖励预览、殿堂复制"看得到买得到"。
- **小额高频**：黑铁矿石 1 元宝起售，1 元也能变强。
- **沉没成本**：爵位累计捐献、图鉴放入不可取、符文之语九形态链。
- **损失厌恶**：离线挂机"背包已满部分道具未获得"→ 扩容付费；钱庄被抢→ 上线护租。

## 12. 运气与全服活动系统

### 12.1 寻宝（每日刷新奖池抽奖）

- 消耗寻宝图抽环形奖池；**每天 0:00 更新奖池**（不满需等明天=次日回访钩子）。
- 文案直接写明"寻宝等同于拼人品…适可而止"——用自嘲式坦诚降低赌博负反馈。
- 自动寻宝（关闭音效）支持连抽。
- 来源：终身会员签到 2 张/超会 5 张、徒弟出师大量。

### 12.2 祭坛（个人进度 + 全服共建）

- 捐献换进度：金币×1=+1、金砖×1=+2、天书×1=+1、一级宝石=+1、黑铁×500=+4、100 元宝=+5、1000 元宝=+50（竞品实测）。
- 双进度条：我的进度 0/1000（个人档奖励）+ 祭坛进度 14230/8000（**全服共建档，溢出即爆奖**）。
- 全服进度排行公示；"补领昨日祭坛奖励"=漏领召回钩子。
- 【成瘾点】个人小额捐献同时推进全服目标，制造"我在为全服做贡献"的参与感与从众压力。

## 13. 排行榜与展示系统

- 总榜：等级 / 攻击 / 魔法 / 道术 / 称号 / 金币（10 页，每小时刷新）。
- **实时查看他人装备**（"装备查看为实时信息"）——满足窥探与战术研究，是 PK 生态的催化剂。
- 子榜遍布各系统：幻境层数、秘境层数、PK 战功、世界 BOSS 伤害、传说塔、行会、师徒、祭坛、钱庄城主。
- 【设计要点】"有榜即竞争"：每个子系统都配一个榜，把单机式挂机改造成全服可见的竞赛。

## 15. 成瘾性设计专章（核心方法论）

以 Hook 模型（触发→行动→多变的酬赏→投入）逐条映射：

### 15.1 触发（Trigger）

| 类型 | 实现 |
|---|---|
| 外部-推送型 | 全服掉落广播、沙巴克开服时间、祭坛"补领昨日"、钱庄被攻提示 |
| 外部-时间型 | 每日 0 点寻宝池刷新、每日福利、签到、押镖/劫镖次数重置 |
| 内部-情绪型 | "再打一层就睡"（层 BOSS）、差一点够到的称谓/图鉴 |
| 内部-身份型 | 城主/榜首/师父身份带来的"必须上线维护"责任感 |

### 15.2 行动（Action）——极低操作成本

- 一键：一键领取、一键锻造、自动战斗、自动重置、自动寻宝、扫荡。
- 离线即行动：关闭客户端仍在打怪（5 秒/怪节拍）。
- 上线只做"分配决策"，单次会话可短至 5 分钟，契合上班族碎片时间。

### 15.3 多变的酬赏（Variable Reward）

1. **猎物酬赏**：掉落墙实时滚动、系数洗炼浮动、世界 BOSS 伤害排名。
2. **社交酬赏**：排行榜、膜拜城主、红包、师徒、劫镖恩怨。
3. **自我酬赏**：21 页称谓天梯、9 转里程碑、图鉴集齐、公式最优解。
4. **可变比率**：金币洗炼可能降系数、寻宝拼人品、BOSS 掉落随机——老虎机式强化，最抗消退。

### 15.4 投入（Investment）——越玩越难走

- 沉没：爵位捐献、图鉴不可取、符文之语九形态、称谓 21 页。
- 资产：交易市场挂单、钱庄租约、行会职位、徒弟网络。
- 数据：巅峰 1500 级、6000 层幻境——**数字本身就是护城河**。

### 15.5 每日行为清单（DAU 锚点设计）

| 行为 | 限制 | 回访动机 |
|---|---|---|
| 领离线结算 | 每日 | 损失厌恶 |
| 每日福利/签到 | 每日 | 连续签到沉没 |
| 押镖×N / 劫镖×N | 次数 | 经济保底+掠夺 |
| 个人 BOSS×N | 次数 | 核心掉落 |
| 世界 BOSS×N | 次数 | 伤害榜 |
| 传说塔 10 次 | 次数 | 塔位荣誉 |
| PK 竞技场 | 次数 | 战功小时薪 |
| 寻宝 | 寻宝图 | 奖池日刷新 |
| 祭坛捐献/补领 | 每日 | 全服进度 |
| 钱庄收租/护租 | 持续 | 被抢损失 |

### 15.6 反沉迷与合规提示（自研必做）

- 竞品为成人向数值付费产品；自研需按目标市场法规加入实名、防沉迷、付费上限、概率公示（寻宝/洗炼概率必须公示）。
