# 放置矿工 (Idle Miner) 游戏模板

点地心矿晶开采金币 → 买矿机自动挖 → 冲里程碑翻倍 → 抓金矿石、点燃熔炉超载 →
矿脉够深就**地心转生**，把这一轮压成永久加成的地心晶，再来一轮更快的。

界面全是标准 `Gui` 控件（`Form` / `Panel` / `Label` / `Button` / `Progress` / `Modal`），
外观走游戏自己的皮肤 `src/MineSkin.zan`（`app.UseCss` 内嵌进 exe，"熔岩矿洞"：焦黑岩板 +
熔金 + 余烬橙，转生层用冷色的地心晶青）。只有矿洞场景是自绘的世界画面。

## 玩法

| 系统 | 规则 |
|---|---|
| 手动开采 | 点矿晶（或"开采"按钮）：每下 = (1 + 矿机总等级 + 5% 基础秒产) × 永久倍率 × 增益 |
| 矿机 | 八座，价格每级 ×1.15；前一座买过才"勘探"到下一座（问号卡） |
| 里程碑 | 每座矿机到 **Lv25 / 50 / 100**、之后每 100 级，该矿机产出 **×2**；卡片底部进度条显示离下一个还差多少 |
| 批量购买 | 右上角 **×1 / ×10 / 最大** 开关（快捷键 1/2/3）；卡片价格随模式变；买不起整批就一级也不买 |
| 金矿石 | 第一次开采后每 45~90 秒在矿洞里冒出一块，**13 秒**内点它（或按 G）：65% **金矿脉**（60 秒产出的横财），35% **淘金狂潮**（12 秒手动开采 ×7） |
| 熔炉超载 | 按钮或 B 键：**30 秒全部产出 ×2**，之后冷却 4 分钟 |
| 成就 | 16 个（开采次数、总等级、秒产、累计、里程碑、金矿石、超载、转生、地心晶），每个**全产出永久 +2%** |
| 地心转生 | 本轮累计满 **2B** 解锁；得 ⌊√(本轮累计 / 10M)⌋ 枚地心晶（门槛处 14 枚），每枚**全产出永久 +10%**。确认弹窗显示本次所得与加成变化；清空金币/矿机/增益，保留地心晶、成就、统计 |
| 离线收益 | 关掉也在挖：按稳态秒产（不含超载）结算，上限 8 小时，回来弹"欢迎回来" |

### 节奏（无头平衡探针，见下）

| 玩家 | 首次可转生 |
|---|---|
| 主动（每秒点 5 下、见金矿石就敲、超载就绪就开、按回本时间买） | 24.7~29.5 分钟（8 个种子，平均 27.7） |
| 偶尔点（每秒 2 下） | 29~33 分钟 |
| 纯挂机（只点 15 下起步） | 约 92 分钟 |
| 第二轮（带着 10 枚地心晶） | 约 14 分钟 |

第一分钟只有鹤嘴锄和蒸汽矿井，点几下就买得起；Lv25 里程碑在头两分钟内到，之后每座新矿机
回本时间逐级拉长，后两座（地幔虹吸塔、星核熔炉）是转生前的冲刺目标。

## 操作

| 操作 | 作用 |
|---|---|
| 点矿晶 / "开采" | 手动开采一次 |
| 点金矿石 / `G` | 敲开金矿石 |
| 点矿机卡 | 按当前模式购买（买不起会报还差多少） |
| `1` `2` `3` / 右上开关 | 购买数量 ×1 / ×10 / 最大 |
| "超载" / `B` | 熔炉超载 |
| "转生" | 打开地心转生确认（不够深会报还差多少） |
| 🏆 / 📊 | 成就墙 / 采矿统计 |
| `M` / 🔊 | 开关音效（记住偏好） |
| `Esc` | 关闭当前弹窗 |

放置游戏没有暂停与"结束"：关掉窗口即存档，下次打开接着挖。

## 画面与反馈

- **矿洞场景**（`src/Views/MineCoreView.zan`）：起伏岩层、闪烁矿点、冒余烬的熔岩池；地心矿晶是
  16 个顶点的宝石，切面按"朝向 vs 左上光源"取明暗，一转起来亮面就流动；外面两层呼吸辉光 +
  慢转光束。点击 = 弹性放大 + 挤压 + 脉冲环 + 加速旋转；超载时整块烧红、转速翻倍；淘金狂潮时转金色。
- **金币喷发**（`src/ParticleSystem.zan`）：离屏透明画布烘焙金币/光点精灵，`SpriteBatch` 每类一次
  提交；金币按翻转相位压扁宽度、落到熔岩池边会弹一下。金矿石/超载/转生还有一圈环形火星与闪光。
- **矿机卡**（`src/Views/BuildingCard.zan`）：整卡是一个 `Button`；图标 + 名字 + 等级徽章（过了
  里程碑转亮）+ 当前秒产 + 价格（批量时带 ×N）+ 里程碑进度条；买得起时描金发光。
- 音效（`SfxBank` + `SfxPresets`，`.WithSweep` 调过音高）：敲矿、买到、钱不够、里程碑、成就、
  金矿石（高亮叮）、超载点火（锯齿上扫）、转生（长上扬）。

动画只在矿洞场景里跑（约 30fps 的 `form.Every`），其余控件按需重绘。

## 存档位置

根目录为 `GameProfile.DataRoot()`：macOS `~/Library/Application Support/ZanGames`、
Windows `%LOCALAPPDATA%\ZanGames`、Linux `~/.local/share/ZanGames`；设置环境变量
`ZAN_GAME_DATA_DIR` 可改到任意目录（测试/便携版）。其下 `idle/` 里：

| 文件 | 内容 |
|---|---|
| `economy_slot0.json`（+ `.bak`） | 经济存档（格式 2）：金币、本轮/终身累计、点击、矿机等级、地心晶、转生次数、成就位图、金矿石/超载计时与随机数状态、购买模式、`savedAtSec` |
| `idle_slot0.json`（+ `.bak`） | 玩家档案：最高秒产、最多地心晶、累计开采/点击/上线次数、成就旗标、静音 |

存档带格式号：第一版（没有 `format` 字段）读进来时自动迁移——累计收益同时记作本轮与终身，
新增的两座矿机为 0 级，已经够格的成就补判解锁；下次存档写成格式 2。想从头开始，删掉 `idle/` 目录。

调试捷径（默认关）：环境变量 `IDLE_DEBUG=rich` 直接给到可转生的进度，`golden` 让金矿石 2 秒后
出现，`boost` 立即超载（可组合，如 `rich,golden`）。只供截图/验收走到后期状态。

## 代码分工

机制与内容分开：**换个挂机游戏还成立**的部分归包，模板只留"这个矿场"。

| 位置 | 内容 |
|---|---|
| `packages/Zan.Game.Idle`（`namespace Game.Idle`） | `IdleState` / `IdleBuilding`（金币、点击、等级、1.15 成本倍率）、离线收益、大数、飘字、挤压回弹 |
| `src/Model/MineEconomy.zan` | 本游戏规则：里程碑、批量购买、金矿石、超载、成就判定、地心转生、事件队列 |
| `src/Model/MineCatalog.zan` / `MineAchievements.zan` | 内容表：八座矿机、十六个成就 |
| `src/main.zan` | 界面搭建、点击反馈、音效/静音、自动存档与离线结算、调试捷径 |
| `src/MineSkin.zan` | 游戏皮肤（全部语义类 `mn-*` 与五态） |
| `src/Views/` | 矿洞场景、矿机卡、四个弹窗（欢迎回来 / 统计 / 成就 / 转生确认）、数字格式 |
| `src/IdleSaveGame.zan` | 经济存档（`GameSaveStore`：原子写 + `.bak` 回退 + 格式迁移） |
| `src/ParticleSystem.zan` / `src/Model/Particle.zan` | 金币/火花/余烬粒子 |

## 回放与平衡

`src/IdleSim.zan` 把 `MineEconomy` 包成无头回放（输入：开采 / 敲金矿石 / 超载 / 转生 / 切购买模式 /
买第 i 座），`[Invariant]` 锁住：金币非负且不超本轮累计、终身 ≥ 本轮、增益计时在合法区间、成就与
地心晶只增不减、永久倍率 = 地心晶 × 成就、里程碑产出 = 基础 × 等级 × 2^里程碑数。`Bot` 会狂点、
敲金矿石、开超载、换购买模式、随机买矿机。`replays/bot.replay` 是它按种子 20261125 录的 1200 帧。

改了数值，回放就会分叉——用 `Replay.Fuzz(new IdleSim(), "IdleSim", 20261125, 1200, IdleSim.Bot, 0)`
重录（见 `Game.Foundation` README「Replays are regression tests」）。上表的节奏数字来自同一份
`MineEconomy` 上跑的"主动玩家"机器人（逐帧 100ms，按回本时间买最划算的一级）。

契约测试：`tests/conformance/idle_state.zan`（包里 `IdleState` 的点击产出、成本曲线、每秒产出、
定步结算全锁死；本模板的规则在 `MineEconomy` 里叠加，不改包）。
