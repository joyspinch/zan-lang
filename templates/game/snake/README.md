zan Snake Party — 蛇蛇乐（模板版）
====================================

玩法
----
- 鼠标控制方向，吞豆成长；**撞上大蛇身体或竞技场围墙即出局**（6400×3600 有边界竞技场，
  贴墙时围墙泛红预警，屏幕外是警戒斜纹区）
- 按住左键/空格冲刺（纯加速，尾部喷火花）；吃豆积攒狂热槽，狂热时刻双倍得分
- **三种性格的 AI 大蛇，颜色即性格**，头顶名牌同色：
  - 天蓝 · 谨慎者：比你小就躲开，只在比你大一半时才出手，专心吃豆
  - 猩红 · 猎杀者（红瞳怒眉）：敢以小搏大，预判你的走位冲刺截击，威胁越高横切越勤
  - 紫罗兰 · 缠绕者（竖瞳）：绕着你转圈收口，想把你困死在身体里
  - 金色小蛇是猎物，撞上就吃掉；大蛇之间也会互撞、吞小蛇
- **蛇阵亡炸成能量豆**：从死亡点四散飞出、带死者颜色、比普通豆更值钱，伴随冲击波
- **限时道具球**（玩家专属，最多 3 个，刷在你附近 450–1000px，屏幕外有彩色指引点，22 秒后消散）：
  - 磁铁（红，9s）：吸豆半径 78 → 240px
  - 护盾（青，12s）：挡下一次致命碰撞（含撞墙），碎裂后 1.5s 无敌
  - 双倍（金，10s）：得分 ×2，与狂热叠加可达 ×4
- **威胁等级 0–6 随分数上升**（200 / 550 / 1100 / 1900 / 2900 / 4200）：猎手提速、拦截更远、
  横切更勤；2/4/6 级各增援一条猎杀者或缠绕者
- **实时排行榜**（右上前 5，含你和所有有名大蛇），第一名头顶戴王冠；**击杀播报**滚动显示
  谁截杀了谁、谁撞墙出局
- 开局 3 秒出生保护（半透明闪烁）；截杀时 70ms 顿帧 + 震屏
- 结算显示最终排名 / 本局最高排名、**凶手名字与性格**（附一句针对性提示）、道具数、
  新解锁的皮肤或离下一款还差多少
- 暂停面板（继续 / 重新开局 / 回到菜单）；窗口失焦或最小化时自动暂停
- 程序化音效（无音频素材）：吞豆、狂热、冲刺、截杀、阵亡、道具拾取、护盾碎裂、威胁升级、按钮、新纪录
- 首局自动显示完整操作说明，之后开局短暂提示暂停/静音键

进度与皮肤
----------
五款皮肤，在主菜单的皮肤卡里选（标准按钮：已解锁显示色板渐变，未解锁置灰并写明条件），
选择写入档案：

| 皮肤 | 解锁条件 |
|---|---|
| 薄荷 | 默认 |
| 落日 | 最高分 400 |
| 冰晶 | 累计击败 10 |
| 熔岩 | 最高分 1200 |
| 极光 | 累计击败 40 |

操作
----

| 按键 | 作用 |
|---|---|
| 鼠标 | 转向（蛇头追随光标方向） |
| 左键 / 空格（按住） | 冲刺 |
| P / Esc | 对局中暂停；暂停面板里继续 |
| R | 暂停面板里重新开局 |
| M | 音效开关（任意场景，记入档案） |
| ← / → | 主菜单里切换已解锁皮肤 |
| 回车 / 空格 | 菜单开始、结算再来一局 |
| Esc | 结算回菜单；主菜单里退出游戏 |
| F11 | 全屏 |

开发者开关：环境变量 `ZAN_SNAKE_DEV=1` 时对局里 J = +300 分（看威胁升级）、U = 三种道具全开、
K = 立即被榜首截杀（看结算）；再加 `ZAN_SNAKE_AUTO=1` 玩家蛇走自动驾驶（无人值守截图）。默认关闭。

平衡（无头仿真）
----------------
`SnakeSim` 的输入 33/34 是自动驾驶（避险 > 避墙 > 抢道具 > 吃豆），拿它当"普通玩家"量曲线
（12 个种子，单局上限 6 分钟）：

| 策略 | 平均存活 | 平均分 | 登顶率 | 平均威胁 |
|---|---|---|---|---|
| 不操作（直线） | 16s（撞墙） | 124 | 0/12 | 0.1 |
| 乱转 | 39s | 234 | 1/12 | 0.5 |
| 自动驾驶 | 85s | 2115 | 9/12 | 3.0 |

AI 之间每分钟约 5 次阵亡（播报不冷场）；高分局 2–3 分钟到威胁 6 级。

存档
----
档案由 `Game.Foundation.GameProfile.Open("snake")` 管理（`src/Entities/Profile.zan` 是薄适配层），
写在用户应用数据目录下的 `ZanGames/snake/`（macOS `~/Library/Application Support`、
Windows `%LOCALAPPDATA%`、Linux `~/.local/share`），原子写 + `.bak` 回退；设置环境变量
`ZAN_GAME_DATA_DIR` 可改根目录（测试/便携版）。记录：最高分 `score`、最长长度 `length`、
总局数 `games`、累计击败 `kills`、最佳排名 `rank`，以及静音偏好 `muted` 与所选皮肤 `skin`（皮肤解锁由最高分/累计击败推导）。不再写工作目录（旧版的
`snake_save.txt` 不会被读取）。无头回放（`SnakeSim`）用内存档案，不碰文件、音频与窗口。

编译
----
在当前主仓根目录运行以下 PowerShell 命令，直接编译模板原始源码，不复制模板树：

```powershell
Set-Location D:/project/zan-lang
& ./scripts/build_gate.ps1 -Name build -Script {
    build/zanc.exe templates/game/snake/src/main.zan templates/game/snake/src --auto-stdlib --package-project . --embed templates/game/snake/assets=assets --publish --subsystem windows -o build/snake.exe
}
build/snake.exe
```

首个参数指定 `Main` 所在文件，随后 `src` 目录递归纳入游戏、Entities、Scenes 和 HUD 的全部 `.zan`，已列入口不会重复纳入。`--package-project .` 使用当前主仓的 `packages/`。`--embed 磁盘路径=内嵌前缀` 将图片和 `assets/scenes/*.html` 一起内嵌到 `assets/`；HTML 是运行期资源，不作为编译输入。生成的原生驱动文件应与程序保持在同一目录。

源码分工
--------

| 文件 | 职责 |
|---|---|
| `src/SnGame.zan` | 对局状态与规则：出生、吞豆、道具、截杀/阵亡、护盾、威胁升级、排行榜（只读模拟时钟，无头可跑） |
| `src/SnAi.zan` | 三种性格的 AI 决策与步进、大蛇互撞、玩家自动驾驶（回放机器人 / 演示） |
| `src/SnArt.zan` | 世界绘制：视差星云、蜂巢地纹、围墙、豆子/能量豆/道具球、蛇（投影、皮肤、表情、王冠）、粒子与冲击波 |
| `src/SnHud.zan` | 对局 HUD（标准 Label/Panel/Progress + 霓虹玻璃 CSS）：排行榜、击杀播报、道具计时、名牌、狂热槽 |
| `src/SnSkins.zan` | 皮肤 / 性格 / 道具配色表与解锁规则 |
| `src/SnakeSim.zan` | 无头回放仿真、`[Invariant]` 规则、模糊机器人 |
| `src/Scenes/*` + `assets/scenes/*.html` | 菜单（皮肤卡）/ 对局 / 暂停 / 结算场景 |

改了规则（数值、AI、道具）回放会分叉，按 `Game.Foundation` README「Replays are regression tests」
用 `Replay.Fuzz(new SnakeSim(), "SnakeSim", 20261125, 1200, SnakeSim.Bot, 0)` 重录 `replays/bot.replay`。
