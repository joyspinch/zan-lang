{{NAME}} — 裂谷战役（即时战略模板）
====================================

三关短战役的即时战略：采矿、排产、兵种克制、抢占上行链路，顶住红军一波比一波大的攻势，
最后摧毁对岸的指挥中心。每关按用时与基地完好度评 1~3 星，存档记录每关每难度的最佳星数与最快胜利。

玩法
----
- **战场**：1600×960 的裂谷战场，中央一条南北向的悬崖裂谷，只有北、中、南三个峡口能过；
  中央峡口里是**上行链路**。蓝军（玩家）在西岸，红军在东岸，各有一座指挥中心与背后一片晶矿。
- **经济**：采矿车自动往返矿片与指挥中心，每趟运回 10 晶矿（交矿时飘 `+10`）；矿片会采空。
  占住上行链路每秒再 +4 晶矿。
- **生产**：指挥中心排产（队列最多 5 个，取消全额退款），单位按人口计（上限 60）：

  | 兵种 | 晶矿 | 人口 | 特点 |
  |---|---|---|---|
  | 步兵 | 50 | 1 | 快、便宜、近射程速射；**克制炮兵** |
  | 坦克 | 150 | 3 | 皮厚、中射程重炮；**克制步兵** |
  | 炮兵 | 125 | 2 | 超远射程溅射、贴脸打不到；**克制坦克**，拆建筑 ×1.6 |
  | 采矿车 | 60 | 1 | 不参战，自动采矿；右键可临时调度 |

  克制三角：步兵 ▶ 炮兵 ▶ 坦克 ▶ 步兵（克制方伤害约 ×2，被克制方约 ×0.5）。
  单位自动打射程内“最划算”的目标（距离按克制倍率折算，建筑最后打）。
- **上行链路**：只有一方作战单位在圈内时占领度朝那一方推进，满格易主、归零中立；双方都在则僵持。
- **红军 AI**（确定性，`src/RtsAi.zan`）：先补足采矿车，再按你的兵种组合加权生产克制兵种
  （难度越高越会克制）；开局守备队只守家；生产出来的部队到点就整队出发——目标在上行链路与你的
  指挥中心之间轮换，每一波最低规模递增；你摸到它基地附近，守家部队全体迎击；争夺型关卡还会
  派小队去抢链路。
- **三关战役**（通关解锁下一关）：

  | 关卡 | 目标 | 时限 | ★★ 用时 |
  |---|---|---|---|
  | 01 破晓突击 | 摧毁红军指挥中心（敌军薄弱，练生产与编队） | 4:00 | 2:30 |
  | 02 上行链路 | 累计控制上行链路 60 秒（红军开局驻守链路并反复争夺） | 4:00 | 2:30 |
  | 03 铁砧行动 | 摧毁红军指挥中心（红军按你的组合造克制兵种，攻势递增） | 5:00 | 3:10 |

  难度：新兵（红军经济 ×0.6、进攻间隔 ×1.25、你多 150 晶矿）/ 老兵 / 精英（红军经济 ×1.6+1、
  间隔 ×0.8、开局多 3 步兵 1 坦克、每波更大）。
- **星级**：★ 完成目标；★★ 在标准用时内完成；★★★ 同时指挥中心完好度 ≥ 70%。
- **失败**：我方指挥中心被摧毁，或时限到仍未完成目标。

操作
----

| 输入 | 作用 |
|---|---|
| 左键点击 / 拖拽 | 点选 / 框选（Shift 追加）；框里有作战单位时不选采矿车 |
| 右键地面 | 选中单位行军（流场绕开裂谷）；点到敌人 = 攻击移动 |
| Shift + 右键 | 攻击移动：途中遇敌先交战 |
| 只选中指挥中心时右键 | 设置集结点（新出厂的部队开过去） |
| A / S / H | 全选部队 / 全选采矿车 / 选中指挥中心并把镜头移回基地 |
| Q / W / E / R | 生产 步兵 / 坦克 / 炮兵 / 采矿车（底部生产线按钮同效） |
| X | 取消队尾 |
| 方向键 / 鼠标贴边 | 平移镜头；Space 镜头跟到选中单位 |
| 小地图 | 左键点击或拖动移动镜头，右键直接下行军令 |
| P / Esc | 暂停 / 继续（窗口失焦自动暂停）；战报里 Esc 回作战地图 |
| R | 暂停或战报中重新开始 |
| Enter / Space | 作战地图里出击、战报里下一关（失败则再战）、暂停中继续 |
| 1 / 2 / 3、← →、D | 作战地图里选关、切换难度 |
| M | 静音开关（顶栏也有按钮） |

界面与美术
----------
- 界面全部是标准 Gui 控件，外观是本作自己的**战术指挥台皮肤**（`src/Views/RtsSkin.zan`，
  `app.UseCss` 内嵌进 exe，不叠桌面皮肤）：深海军蓝玻璃面板、冷青描边与发光、琥珀警示、
  猩红敌情；按钮五态（常态 / 悬停 / 按下 / 焦点 / 禁用）齐全，弹层（标准 `Modal`）换成战术终端卡面。
- 顶栏：关卡与难度、目标进度条（敌基地血量或链路控制秒数）、警报条、倒计时、晶矿、人口、暂停、静音。
- 底部指挥台：**战术雷达**（缩略战场、裂谷、矿片、链路归属、基地、单位光点、我军遭袭红环、
  白色镜头框）、**选中面板**（头像 `Image`、编队构成、总血量条、攻击 / 射程 / 速度、克制提示）、
  **生产线**（四个生产按钮带价格与排队数、队列格、当前进度条、取消）。
- 战场画布只画世界：底图 + 阵营地面光 + 战术网格、发光崖边与警示灯的裂谷、程序化晶簇
  （枯竭变灰）、带旋转刻度与占领扇区的上行链路、带塔楼 / 雷达 / 出厂口进度的指挥中心。
- 单位：开局把 `assets/` 的俯视贴图烘焙成 16 朝向 × 2 阵营（红军换猩红涂装，`Views/SpriteBank.zan`），
  按移动 / 开火方向转身；炮兵用坦克车体去饱和加长炮管拼出；位置在仿真帧之间插值，运动连续。
  选中单位脚下是绿色选中圈，血条只在受伤或选中时出现，受击闪白，采矿车有采矿激光与载货光点。
- 特效（`Views/BattleFx.zan`）：炮口焰、曳光、炮弹抛物线与落点爆炸、命中火花、阵亡爆炸
  （闪光 + 冲击波 + 碎片 + 烟团 + 焦痕）、重型单位与基地被毁震屏、行军令落点脉冲（绿 = 行军、
  红 = 攻击、青 = 集结点）、出厂跃迁环、链路易主脉冲。

音效与存档
----------
- 音效由 `Game.Foundation.SfxBank` 程序化合成（不带音频文件）：点选、下令、枪声（限频）、
  炮声、爆炸、交矿、出厂、链路占领 / 失守、红军攻势与基地遇袭警报、胜利、失败、无效操作。
- 档案用 `GameProfile.Open("rts")`，存在用户应用数据目录下的 `ZanGames/rts/`
  （macOS `~/Library/Application Support`、Windows `%LOCALAPPDATA%`、Linux `~/.local/share`），
  **从不写工作目录**；设 `ZAN_GAME_DATA_DIR` 可改根目录。内容：每关每难度最佳星数
  `m<关>_d<难度>_stars`（`SubmitBest`）与最快胜利 `m<关>_d<难度>_fast`（`SubmitLowest`）、
  通关标记 `cleared_m<关>`（解锁下一关）、局数 `plays`、胜场 `wins`、上次难度 `difficulty`、静音 `muted`。
- 第一次玩（`plays == 0`）作战地图里多一行新兵提示。

技术要点
--------
- **流场寻路**（`Game.Tactics.FlowField`）：裂谷格代价 255，按目标格缓存流场；同侧直线走、
  隔着裂谷才按流场绕行。单位也不能踏进悬崖格（沿另一轴滑开）。
- **RVO 群体避障**（`Game.Tactics.RvoSimulator`）：每个机动单位一个槽位，编队推进互相让位；
  指挥中心是实心圆（不占槽位，挤进去的单位推回圆周）；阵亡单位退还槽位。
- **确定性步进**：仿真固定 50ms 一帧，界面按显示帧插值；暂停不走表，时限按仿真帧计。
- **逻辑与表现分离**：`RtsBattle` 只记录本帧射击 / 阵亡 / 交矿 / 出厂 / 链路易主 / 进攻波次事件，
  特效、警报与音效都在界面层。

平衡（无头仿真测算）
--------------------
`RtsSim.Coach` 是一个“中等玩家”机器人（维持 6 台采矿车、步坦炮混编、攒够兵力先攻击移动抢链路、
再推基地，不会回防也不会微操）。按关卡 × 难度各跑一局（20 帧/秒）：

| 关卡 | 不操作（新兵 / 老兵 / 精英） | 教练机器人（新兵 / 老兵 / 精英） |
|---|---|---|
| 01 破晓突击 | 超时败 4:00 / 超时败 4:00 / 超时败 4:00 | 胜 1:30 ★★★ / 胜 2:04 ★★★ / 败 3:28 |
| 02 上行链路 | 基地被毁 2:47 / 2:41 / 2:15 | 胜 1:29 / 胜 1:34 / 败 2:55 |
| 03 铁砧行动 | 基地被毁 3:28 / 2:24 / 2:18 | 胜 2:14 / 败 2:55 / 败 2:37 |

第一分钟红军只守家（首波进攻在 0:39~1:33 之间），之后攻势按关卡和难度递增；教练机器人能打穿
新兵三关与老兵前两关；老兵第三关与精英需要回防、克制与微操。

回放与回归
----------
`src/RtsSim.zan` 把 `RtsBattle` 包成无头仿真：种子决定关卡（`seed % 3`）、难度（`seed / 3 % 3`）
与红军 AI 的随机；输入编码见文件头（右键 / 攻击移动 / 全选 / 框选 / 点选 / 排产 / 取消）。
`[Invariant]` 钉住规则：两军人口不超上限且账平（在场 + 排队）、队列不超长、伤亡账平、阵亡当帧出场、
晶矿非负且守恒（矿区采走 = 交矿 + 车上 + 随车损失）、机动单位都有避障槽位、单位不出界不踏悬崖、
链路占领度合法、只能选中蓝军。`replays/bot.replay` 是机器人录下的一局。改了规则（数值、AI、寻路
参数）回放会分叉，按 `Game.Foundation` README「Replays are regression tests」重录：

    ReplayResult r = Replay.Fuzz(new RtsSim(), "RtsSim", 20261125, 1200, RtsSim.Bot, 0);
    if (r.ok) { r.log.Save("replays/bot.replay"); }

编译
----
根目录下（公共包在 zan-lang 仓库的 packages/ 下，编译要带 --package-project）。
传 `src` 目录即可带上其下全部 .zan：

    build/zanc templates/game/rts/src/main.zan templates/game/rts/src ^
               --auto-stdlib --package-project . ^
               --embed templates/game/rts/assets=assets -o build/rts/Rts.exe

自动化：模板调用了 `UiDriver.Enable`，`ZAN_UI_SCRIPT` 会话里可读探针 `rts.state`（0 作战地图 /
1 交战 / 2 暂停 / 3 战报）、`rts.ticks`、`rts.selected`、`rts.blue`、`rts.red`、`rts.muted`、
`rts.focused`、`rts.mission`、`rts.difficulty`、`rts.minerals`、`rts.queue`、`rts.uplink`；
脚本会话不跟随桌面焦点自动暂停。调试开关（默认关闭）：`RTS_DEBUG_AUTOPLAY=1` 由教练机器人代打、
`RTS_DEBUG_SKIP=<秒>` 开局快进、`RTS_DEBUG_UNLOCK=1` 解锁全部关卡、`RTS_DEBUG_MISSION=1..3` /
`RTS_DEBUG_DIFF=0..2` 预选关卡与难度。
