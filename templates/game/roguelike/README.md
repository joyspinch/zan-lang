zan Roguelike Deckbuilder — 肉鸽爬塔（模板版）
==============================================

玩法
----
- **三幕分岔地图**：每幕 7 行节点自下而上，连线决定能去哪；第 0 行全是普通战斗，
  第 3 行是宝箱，Boss 前一行是篝火。节点种类：
  **战斗**（换牌与金币）· **精英**（更强，掉遗物）· **商店**（买牌、买遗物、删牌）·
  **奇遇**（8 段有得有失的小故事）· **篝火**（休息回 30% 生命，或锻造升级一张牌）·
  **宝箱**（遗物 + 金币）· **Boss**（骸骨君王 / 腐化女巫 / 深渊守卫）
- **31 张牌**（攻击 / 技能 / 能力），每张都有升级版（"+"，数值更高或费用更低）。
  关键词：**中毒**（回合开始掉血、层数 -1）· **虚弱**（攻击 -25%）· **易伤**（受击 +50%）·
  **力量**（每段攻击 +N）· **抽牌** · **能量** · **消耗**（打出后移出本场）·
  **保留**（回合结束不弃）· **能力**（整场持续：恶魔形态、金属化、剧毒、灵感、荆棘）
- **17 件遗物**：起手「余烬之血」；精英与宝箱掉普通遗物，商店可买；第 1、2 幕 Boss 之后
  三选一一件 Boss 遗物。顶栏遗物栏悬停看效果。
- **17 种敌人**：每幕 3–4 种普通敌人 + 1 精英 + 1 Boss。敌人**提前亮出意图**
  （攻击 / 连击 / 防御 / 强化 / 削弱，数值已算上双方状态），出招方式有循环、
  随机不连出、开场招 + 循环三种。
- 每回合 3 能量、抽 5 张；战后三选一加牌（可跳过，保持牌组精简）。
- **难度曲线**：第 1 幕前两场只遇到最弱的两种敌人；之后招式组合、多段攻击、吸血、
  中毒逐幕加入；Boss 有四拍循环。

操作
----
| 操作 | 说明 |
|------|------|
| 点地图上亮着的节点 | 前进（悬停看节点说明） |
| 点手牌 / `1`–`9` | 出牌；变暗、费用宝石转灰的牌能量不足。悬停看关键词释义 |
| 「结束回合」/ `E` | 弃牌、敌人按意图行动、抽新牌 |
| `Esc` | 局中弹出"放弃本局？"确认条（再按收起）；结算页回主菜单 |
| `M` | 音效静音开关（偏好会记住） |

手感与演出
----------
- 出牌时卡牌沿弧线**飞向目标**并拖出火星；命中时目标**抖动、闪白**，斩痕划过，
  **伤害数字**弹出上飘（重击更大）；获得格挡时**护盾弹出**，有格挡时角色周身一圈护盾泡；
  中毒冒绿泡，增益/削弱有光尘；敌人攻击时会**前冲扑击**。
- 牌面伤害按当前状态实时预览（被力量/易伤抬高变绿，被虚弱压低变红）。
- 胜负分出后在战斗页停 1.3 秒播完击杀，再切到战利品/结算。
- 音效全部程序化合成：出牌、命中、重击、格挡、能力、削弱、回血、金币、购买、升级等。

进度与战绩（`GameProfile.Open("roguelike")`）
--------------------------------------------
- 开局次数、登顶次数、最高层、最快登顶（累计回合数）；结算页刷新纪录出现 **NEW BEST**。
- **进阶 1–5**：登顶一次解锁下一级（敌人生命 +6%/级，起始生命 -3/级），菜单里选。
- **图鉴**：记下遇到过的敌人种类（菜单显示 n/17）。
- 存在用户应用数据目录 `ZanGames/roguelike/`；`ZAN_GAME_DATA_DIR` 可改根目录。单局不存档。

种子与确定性
------------
- 同一颗种子（+ 同一进阶）必然给出：同一张地图、同一批敌人、同一组奖励、同一个商店货架、
  同一段奇遇。地图/奖励/商店/奇遇全走 `RunState` 的一个随机源，每场战斗的洗牌与敌人意图
  随机源也由种子派生。
- `RunFlow` / `RoguelikeSim` 不碰声音、档案、时钟和窗口；演出时间线（`BattleFx`）只在界面层。

平衡（无头仿真）
----------------
`RogueBot`（看意图叠甲、能斩杀就斩杀、先打能力、按血量选路、商店先买遗物再删打击）
跑 300–500 个种子：标准难度登顶率约 **36%**；只会"打第一张能打的牌"的弱玩家约 **6%**；
进阶 1 / 3 / 5 约 19% / 6% / 1%。死因集中在三个 Boss，第 1 幕普通战几乎不死。
调数值看 `Bestiary`（敌人）、`CardLibrary`（牌）、`RunState`（起始生命/进阶）。

回放
----
`src/RoguelikeSim.zan` 把 `RunFlow` 包成只认种子与逐帧输入的仿真（输入编码见文件头），
`[Invariant]` 校验：生命/幕数/金币范围、牌组完整、战斗中四区牌数守恒、地图路径一致、
阶段与数据一致。`Bot` 85% 照 `RogueBot` 出手、15% 乱按测边界。改规则后按
`Game.Foundation` README「Replays are regression tests」重录 `replays/bot.replay`：

    Replay.Fuzz(new RoguelikeSim(), "RoguelikeSim", 20260101, 1500, RoguelikeSim.Bot, 0)

调试：环境变量 `ROGUE_DEBUG=<幕>:<节点种类>` 开局直接跳过去（种类 0 战斗 1 精英 2 宝箱
3 Boss 4 奇遇 5 商店 6 篝火；9 战利品 10 Boss 战利品 11 结算），默认关闭，只给截图与试玩后期用。

编译
----

    zanc src/main.zan src --auto-stdlib --embed assets=assets -o roguelike.exe

在仓库里：

    zanc templates/game/roguelike/src/main.zan templates/game/roguelike/src --auto-stdlib \
        --package-project . --embed templates/game/roguelike/assets=assets -o roguelike.exe

美术
----
- `assets/cards/{attack,skill,power}.png` 卡面（按分类共享）、`assets/title.png` 标题图。
- 角色、敌人、篝火、宝箱、商人、祭坛是程序化 SVG（`RogueArt`，nanosvg 光栅化一次后按尺寸缓存）；
  战斗场景（拱廊、火把、余烬、光池）与地图连线在画布上画。**控件一律是标准 Gui 控件**，
  外观全在 `RogueSkin`（`rg-*` 语义类，含悬停/按下/焦点/禁用与提示气泡）。

源码分工
--------
| 文件 | 职责 |
|------|------|
| `main.zan` | 入口 |
| `Program*.zan` | 界面（分部类）：壳与顶栏 / 菜单与结算 / 地图 / 战斗 / 房间（战利品、篝火、商店、奇遇、选牌） |
| `RunFlow.zan` | 一局的流程状态机（无界面，回放与界面共用） |
| `RunState.zan` · `ActMap.zan` · `MapNode.zan` | 一局的状态、分岔地图生成、节点 |
| `Battle.zan` · `Fighter.zan` · `BattleEvent.zan` | 战斗规则（牌堆用引擎 `CardDeck`）、战斗单位、给演出用的事件 |
| `CardLibrary.zan` · `CardFx.zan` | 牌面定义（含升级版）与效果种类 |
| `Bestiary.zan` · `EnemyDef.zan` · `EnemyMove.zan` | 敌人图鉴、敌人、招式（意图） |
| `RelicBook.zan` · `RunEvents.zan` | 遗物、奇遇 |
| `RogueBot.zan` · `RoguelikeSim.zan` | 会玩的机器人、回放仿真 |
| `BattleFx.zan` · `FxItem.zan` · `BattleStage.zan` · `FxLayer.zan` · `MapBoard.zan` · `SceneArt.zan` · `RogueArt.zan` | 演出时间线与世界层绘制 |
| `RogueShell.zan` · `RogueSkin.zan` | 档案与音效、皮肤 |

扩展点
------
- **加一张牌**：`CardLibrary.Build()` 里加一行 `Add(...)`（效果记号见文件头），升级版同一行给出。
- **加敌人**：`Bestiary.Build()` 加一条 `EnemyDef` + 招式；外形在 `RogueArt` 选一种剪影配色。
- **加遗物**：`RelicBook` 登记，再在 `Battle`（战斗时机）或 `RunFlow.GrantRelic`（拾取时）认它的 id。
- **加奇遇**：`RunEvents` 的文案与 `Enabled/Apply` 各加一段。
