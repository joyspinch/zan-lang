手工恢复步骤
1. 停止应用服务（确保恢复期间无写入）。
2. 下载备份包（backup-{目录名}.zip，内含 app.db、uploads.zip、manifest.txt），或直接取服务器 data/backups/{目录名}/ 下的文件。
3. 用备份的 app.db 覆盖应用目录下的主库文件，并将 uploads.zip 解包覆盖 data/uploads/（注意保留目录结构 data/uploads/{年月}/{文件}）。
4. 重启应用服务，登录核对数据与附件完整性。
