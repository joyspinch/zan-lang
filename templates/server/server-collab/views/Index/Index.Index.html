语言

你已经会写了。

类、接口、泛型、属性、async/await——熟悉的 C# 形状，没有生命周期标注，也没有垃圾回收停顿。

// 结构体在栈上，集合写时复制，引用计数自动插入。
using System;

struct Point {
    float X;
    float Y;
    float Length() => Math.Sqrt(X * X + Y * Y);
}

class Program {
    static void Main() {
        var p = Point { X = 3.0, Y = 4.0 };
        Console.WriteLine($"({p.X}, {p.Y}) -> {p.Length()}");
    }
}
