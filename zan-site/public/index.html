Includes an .html visual drag-and-drop designer. Button, DataTable, Chart, CodeEditor, WebView and 60+ more controls ship out of the box. Runtime memory is typically under 80 MB.

AOT 编译 · ARC 内存AOT Compilation · ARC Memory
基于 LLVM 后端直接生成目标架构机器码，无 JIT、无字节码解释器。ARC 自动引用计数提供确定性析构，彻底消除 GC 停顿，资源释放时机可预期。 LLVM backend generates native machine code directly — no JIT, no bytecode interpreter. ARC provides deterministic destruction with zero GC pauses; resource lifetimes are predictable by construction.

快速开始Quickstart

解压即用，三步跑起第一个应用 Unzip, write, run — three steps to your first app

1

下载 Zan IDEDownload Zan IDE

官方网盘提供 Windows / Linux / macOS 三平台免安装包，提取码 zanlang，解压后直接运行 ZanIDE.exe。Grab the portable archive for Windows, Linux or macOS. Extract and launch ZanIDE.exe — no installer needed.

2

新建项目Create a project

在 IDE 里选「新建项目」，从 Console、GUI 桌面应用、server-mvc Web、2D 游戏等模板中选一个，IDE 自动生成骨架代码。Click "New Project" and pick a template: Console, GUI desktop app, server-mvc web, or 2D game. The IDE scaffolds the boilerplate for you.

3

编译运行Build and run

按 F5 或在命令行执行 zanc src/App.zan --auto-stdlib -o app.exe，AOT 编译完成后直接运行原生二进制。Press F5 or run zanc src/App.zan --auto-stdlib -o app.exe in the terminal. AOT compilation produces a native binary ready to run.

Terminal
$ zanc src/App.zan --auto-stdlib -o app.exe
  Parsing App.zan
  Checking types...
  IR gen → LLVM
  Link...
  ✓ app.exe (18.4 MB, 0.91 s)
$ ./app.exe
  Hello Zan!
