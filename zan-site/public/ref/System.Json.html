JsonValueclass
解析后的 JSON 值树（object / array / string / number / bool / null）。 与 JsonParser 的扁平 key 扫描器不同，这是真正的递归模型， 可以遍历嵌套文档（UI 布局树、状态实体）。用 Parse 构建；用 As*/类型化字段助手读取标量； 用 Get/Has 遍历对象、At/Count 遍历数组。 kind：0 null，1 bool，2 number，3 string，4 array，5 object。

  • static JsonValue Parse(string src)
    将 JSON 文档解析为值树。格式错误时抛出 JsonException（与 C# 一致）。校验与建树在同一遍扫描里 完成：出错只记录位置并停止，抛异常前先丢掉部分树， 所以错误路径依然不持有存活分配。
