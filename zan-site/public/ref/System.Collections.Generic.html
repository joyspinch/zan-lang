HashSetclass
唯一项的集合：成员判定走 <c>Dict<T, int></c> 的开地址哈希表 （Add、Contains、Remove 摊还 O(1)），插入顺序用并行表保留（Remove 打墓碑，墓碑过半时 一次性压缩，摊还仍 O(1)）。ElementAt 按插入次序 枚举有效项。 相等性沿用 Dict 的键规则： <list type="bullet"> <item>值类型（int、long、double、bool、enum）按值比较；</item> <item>string 按内容比较（Dict 的内建哈希/比较即内容感知）；</item> <item>其他引用类型按身份（同一实例）比较。</item> </list>
字段
  • Dict <T, int> idx;
  • List<T> order;
  • List<bool> dead;
  • int live;
构造
  • HashSet()
方法
  • bool Add(T v)
    若尚不存在则添加该项；已添加返回 true， 若已有相等项则返回 false。
  • bool Contains(T v)
    是否存在相等的项。
  • bool Remove(T v)
    移除相等的项（若存在），返回是否实际移除。 只打墓碑；墓碑超过一半时整体压缩一次。
  • void Compact()
    丢弃墓碑，重建 order 与 idx（均摊 O(1)/次操作）。
  • int Count()
    不同项的数量。
  • bool IsEmpty()
    集合是否为空。
  • void Clear()
    清空所有项。
  • List<T> Keys()
    全部有效项的快照（按插入次序）。修改快照不影响集合本身。
  • T ElementAt(int i)
    第 <paramref name="i"/> 个有效项（从 0 开始，按插入次序， 跳过已移除的墓碑）；越界抛 IndexOutOfRange。
LinkedListclass
双向链表。两端插入和删除均为 O(1)。适用于 值类型（int、double、bool）及引用类型。可用 Head 与 LinkedListNode{T}.Next 遍历。 末端访问器（First、Last、 RemoveFirst、RemoveLast）要求列表非空， 请先用 IsEmpty 或 Count 判断。

Stackclass
后进先出（LIFO）集合。由动态 <c>List</c> 实现， Push 和 Pop 均摊 O(1)。适用于值 类型（int、double、bool）及引用类型。 Pop 与 Peek 要求栈非空；请 先用 IsEmpty 或 Count 判断。

IEnumerableinterface
可枚举协议（C# 的 <c>IEnumerable<T></c> 等价物）：foreach 迭代协议 的工厂侧。返回的枚举器初始定位在首个元素之前，独立于其他枚举器。 实现类同时满足 foreach 的具体类协议钩子；把实现类引用转成 <c>IEnumerable<T></c>（泛型接口引用转换）后再 GetEnumerator， 经接口分发多态调用。
方法
  • IEnumerator<T> GetEnumerator();
    为该序列创建一个新枚举器。
IEnumeratorinterface
枚举器协议（C# 的 <c>IEnumerator<T></c> 等价物）：foreach 迭代协议 的消费侧。MoveNext 前进到下一个元素，Current 读取当前元素；两者都以 零参形式出现，与 foreach 降级器（GetEnumerator/MoveNext/Current 钩子） 的具体类协议同形，所以一个实现本接口的类既可被 foreach 直接迭代， 也可经接口引用多态分发。
方法
  • bool MoveNext();
    前进到下一个元素；越过序列末尾返回 false。
  • T Current();
    读取当前元素（MoveNext 返回 true 后才有效）。
