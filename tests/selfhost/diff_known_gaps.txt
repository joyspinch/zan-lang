    (programs capturing `object` never reached gen1 before: the C host
    rejected them at E3070/E3044/E3069). Three distinct faces, all probed
    2026-11-04: (1) two-arm `is` pattern with both pattern variables
    captured by the lambda segfaults the gen1-built binary; (2) `x as
    string` on an object-typed local holding a string renders "0" instead
    of the string; (3) a capture box reassigned inside the lambda is not
    seen outside (value-copy capture instead of shared box -- C11 prints
    N:re/N:re, gen1 N:re/gone). C11 side is green and leak-free; these are
    selfhost lowering bugs to fix before the gap line can be pruned.
