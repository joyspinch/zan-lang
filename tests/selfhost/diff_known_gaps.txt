# Known self-host gaps: cases where the self-hosted compiler (gen1) still
# disagrees with the C host. tests/run_selfhost_diff.cmake reports them
# instead of failing the gate, so the gap stays visible without blocking
# the tree. When a gap is fixed, delete its line here: the gate then holds
# the case to the C host's behaviour.
#
# Format: <case name> -- <why it still differs>

# A switch pattern over an `object`-typed (or base-class-typed) scrutinee
# needs a runtime class identity: the self-hosted IR backend stamps no
# per-object class id, so `case Dog d` / `case string s` over an `object`
# cannot be decided at runtime. The pattern test is refused with a
# diagnostic (fail-closed) instead of silently never matching.
cs_b05_pattern_var -- class/string pattern over an `object` scrutinee
cs_b06_switch_expr -- class pattern over an `object` scrutinee
pattern_value_types -- class pattern over a base-class scrutinee

# The enumerable protocol (GetEnumerator/MoveNext/Current) is not lowered by
# the self-hosted backend.
value_enumerable -- enumerable protocol not lowered

# A LINQ query over a non-List source yields an empty list instead of the
# query result.
linq_query -- LINQ over a non-List source yields an empty list
