# Cases for the self-host shipped-runtime gate (tests/run_selfhost_mt.cmake).
#
# Each case is a program that uses coroutines. The C host compiles it and
# runs it; the self-hosted compiler emits the IR, it is linked against the
# SHIPPED multi-worker runtime (toolchain/win-x64/zanrt_io_mt.o) the way the
# host links a win-x64 program, and the stdout must match the host's byte for
# byte. The shipped runtime's zan_co_ready / zan_co_sched_init are strong
# symbols, so they win over the self-host's weak fallback: the frames really
# are driven by the shipped scheduler, and its timer ready hook is the one
# that re-queues a delayed frame.
#
# Keep the list small: every case costs a gen1 build, a link and a run.
