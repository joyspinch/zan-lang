# Cases for the self-host differential gate (tests/run_selfhost_diff.cmake).
#
# Every case here is a conformance case: the C host compiles it, runs it and
# its stdout is the golden file next to it. The gate requires the self-hosted
# compiler (gen1) to reach the same stdout. A case that still differs is
# listed in diff_known_gaps.txt -- with the reason -- until it is fixed.
#
# Keep this list small and meaningful: each case costs a gen1 compile plus a
# link plus two program runs.

# the unary plus sign: the C host's parser used to reject `+x` outright, so
# the two backends diverged in the GRAMMAR, not in the lowering -- the
# differential gate compares program output, so a parser-level split is
# invisible to it. This case pins that both backends accept the prefix and
# agree on the value. The one-argument `operator +` overload is a different
# story: the host dispatches it and the self-host still returns the operand
# unchanged (A451), so that case stays out of this list on purpose.
unary_plus

# a byte[] handed to an extern's string parameter is the RAW buffer: the C

# a statement-initial ternary is an EXPRESSION, not a declaration. The

# Math.PI is a compile-time constant in the C host (a folded double) and

# the hardware vectors: the C host defines EVERY operation on the BYTE lanes
